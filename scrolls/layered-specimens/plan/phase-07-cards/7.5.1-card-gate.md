# 7.5.1 Operator: only disputed cards stay excluded

- **Phase:** 7, the DESIGN.md cards. **Row:** #5, alone.
- **Depends on:** row #4.
- **Model:** operator (no worker).
- **Covers:** README "What a card check compares".

## Files

| Action | Path | Folder type |
|---|---|---|
| edit (only when a disputed card names no question) | `scrolls/layered-specimens/plan/README.md` | plan document (markdown) |

The operator edits only the plan's markdown. A `generator-fix` entry left over is a `7.4.<n>` task, never an edit here.

## Steps

1. Open `packages/specimen-generator/test/harnesses/card-check-exclusions.harness.ts`.
2. Confirm no entry has reason `generator-fix`. If one remains, record a 7.4 task for it and dispatch it before going on.
3. For each entry with reason `disputed`, confirm its `question` names a question in README "Open questions for the user" and in the harness's `openQuestions` list. If a disputed card has none, ask the user, add the question to that table and to `openQuestions` before the phase ends.
4. Run `npm run ward -- --changed` with `timeout: 600000`. It runs the card check.
5. Run `npm run generate:specimens -- --check`. It exits 0.
6. Stage explicit paths, update the README tracker, and commit.

## Done when

No `generator-fix` entry is left, every `disputed` entry names a README open question, and steps 4 and 5 exit 0.
