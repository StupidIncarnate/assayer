## Contract

```ts
probeTableContract = z.object({
  probes: z.array(z.object({
    id: <branded string>,        // '<relPath>:<line>:<form>', plus ':<n>' when one line holds several
    file: <branded string>,      // the specimen file the construct sits in, relative to the specimen folder
    form: <branded string>,      // a key of reportVocabularyStatics.forms
    kind: <branded string>,      // that form's reported kind
    line: <positive int>,        // the line of the construct in the written file
    arms: z.array(<branded string>),   // the reported arm labels, every arm the construct has
    listed: z.boolean(),
    complement: z.object({ observed: <branded string>, otherwise: <branded string> }).optional(),
  })),
  leaves: z.array(z.object({
    id: <branded string>,
    file: <branded string>,
    line: <positive int>,
    cause: z.enum(['outcome', 'truthiness', 'nullish', 'member', 'presence']),
    path: <branded string>.optional(),   // the property path or environment name the leaf reads: 'options.label', 'STRICT'
  })),
  sources: z.array(z.object({ relPath: <branded string>, source: <branded string> })),
}).brand<'ProbeTable'>();
```

`sources` holds the probed text of every `.ts` file of the specimen that Assayer analyses, `entry.ts` first, then the
siblings sorted by `relPath`. The harness file and the test file are not in it. The run executes these texts, and
the known-value trace (task 6.1.6) reads the unprobed text of the same files.

The cause enum has five values. `outcome` is a comparison, a type check or a guard call whose boolean result is
recorded. `truthiness` is a bare value read as true or false. `nullish` is a `??` or `?.` operand. `member` is an
operand whose type member matters (an operand of `+`, `==`, `typeof`, a switch subject, a `.length` receiver).
`presence` is an `in` check.

Write in the header comment the recorder calls the probed source makes. Task 6.3.1 implements them and tasks 6.1.4
and 6.2.2 emit them. They are the whole interface between the two:

- `__arm(probeId, arm)`: the run took that arm.
- `__reach(probeId)`: the run reached a construct whose arm is a complement. `complement.otherwise` is taken on every
  reach that did not also record `complement.observed`. This is how `skipped`, `finishes`, `given`, `kept`,
  `present` and `no-match` are recorded without a statement of their own.
- `__leaf(leafId, value)`: returns `value` unchanged and records `<leafId>=<class>:<typeof>`, where `<class>` is the
  value's cause class from `edgeValueStatics.causes` (`zero`, `nan`, `negative`, `empty-string`, `false`,
  `undefined`, `null`, `empty`, `one`, `many`, `empty-object`, else `ordinary`) and `<typeof>` is the JavaScript
  `typeof` text. The `typeof` part keeps `1` and `'1'` apart in one union-typed leaf.
- `__read(inputName, value)`: returns `value` unchanged and records that the run read the entry input `inputName`
  (a parameter or a destructured name). Environment reads are recorded by the sandbox's `process.env`, not by this
  call.
- `__pass(id, kind)`: counts one loop pass (`kind` `'loop'`) or one function entry (`kind` `'call'`) against the
  deterministic caps (`executeStatics.limits`, task 6.1.3). Past the cap it throws the cap sentinel.

## Tests

- `VALID:` the stub parses to itself (whole object).
- `VALID:` a probe with a `complement` parses.
- `VALID:` a leaf with `cause` `presence` and a `path` parses.
- `INVALID:` a leaf cause `'colour'`.
- `INVALID:` a probe with line 0.
- `INVALID:` a source with an empty `relPath`.
