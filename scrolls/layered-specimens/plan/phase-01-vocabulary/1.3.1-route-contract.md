## Contract

```ts
routeContract = z.object({
  arms: z.array(armStepContract),   // the arms this route takes, sorted by file (`entry.ts` first, then the other files by path), then line, then kind, then arm (task 1.2.5)
  driven: z.boolean(),              // false when Assayer cannot steer some branch on it
}).brand<'Route'>();
```

A route is a SET of arms, not a sequence, and an arm that two passes of a loop both take appears once. A loop
route takes `runs` and both arms of an `if` inside it in one run (card `for…of › if`, route `items [2, 3]:
runs, else and then`). Write that in the `PURPOSE` header, together with: a route is identified by its arm
set plus the values its run read, so two routes can hold equal `arms` (README "The cause rule" step 4).

## Tests

- `VALID: {arms: [two steps], driven: true}` parses.
- `EMPTY: {arms: [], driven: true}` parses: a branchless entry's one route.
- `INVALID: {arms: []}` (missing `driven`) throws.
- `INVALID: {arms: [{ line: 0 }], driven: true}` throws.
- `VALID: {arms: [a step in 'entry.ts', a step in 'check-limit.ts'], driven: true}` parses.

`RouteStub` returns one `then` step, `driven: true`, and accepts overrides.
