## Contract

```ts
armStepContract = z.object({
  file: z.string().min(1).brand<'ArmStepFile'>(),   // the specimen-relative path of the file the branch sits in: 'entry.ts', 'check-limit.ts'
  kind: z.string().min(1).brand<'ArmStepKind'>(),   // a reported kind from reportVocabularyStatics
  line: z.number().int().positive().brand<'ArmStepLine'>(),
  arm: z.string().min(1).brand<'ArmStepArm'>(),     // a reported arm label
}).brand<'ArmStep'>();
```

The `PURPOSE` header says: one arm step is one arm one branch took in one run, named the way Assayer reports it. A specimen can hold branches outside `entry.ts` (cards `known/env-two-files`,
`consume/dead-export`, `boundary/sibling`), so a step names its `file` beside its `line`. The header also states the
one sort order every list of steps, branches and routes uses: `entry.ts` first, then the other files by path as
text, then `line`, then `kind`, then `arm`.

## Tests

- `VALID: {file: 'entry.ts', kind: 'if', line: 3, arm: 'then'}` parses.
- `VALID: {file: 'check-limit.ts', kind: 'if', line: 2, arm: 'else'}` parses.
- `INVALID: {file: ''}` throws.
- `INVALID: {line: 0}` throws.
- `INVALID: {arm: ''}` throws.
- `INVALID: {kind: ''}` throws.

`ArmStepStub` returns `{ file: 'entry.ts', kind: 'if', line: 3, arm: 'then' }` and accepts overrides.
