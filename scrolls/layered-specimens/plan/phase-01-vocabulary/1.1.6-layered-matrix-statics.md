## What to implement

```ts
export const layeredMatrixStatics = {
  levels: { cap: 2, objectAndArrayCap: 3 },
  plainest: { container: 'arrow-function', source: 'param', reader: 'if', comparison: 'gt' },
  readerLiteral: { number: 2, string: 'm', boolean: true },
  sourceLiteral: { number: 3, string: 'n', boolean: true },
  excluded: { sources: ['random'] },
  callSequence: { maxCalls: 3 },
  cover: { exactCap: 24 },
} as const;
```

There is no total cap and no per-folder cap (decision "Matrix size"). The header comment says what each group
means:

- `levels`: a piece holding another piece nests up to 2 deep, and 3 for objects and arrays (step 1).
- `plainest`: every position a specimen does not vary takes these (step 3). The reader is the `if` that reads a
  non-branching piece's value (step 5), comparing with `>` against `readerLiteral`.
- `readerLiteral`: the literal the plainest reader compares against.
- `sourceLiteral`: the literal in the call site `decide(3)` that the `literal` source writes. It is the value
  the reader's `then` arm takes (`3 > 2`), so the `else` arm becomes an unreachable exit (card
  `known/call-site-literal`).
- `excluded.sources`: `random` is not generated yet ("Where the value comes from" table).
- `callSequence.maxCalls`: the most calls in a row one case makes to reach a later state. Three covers every
  card in "Shared mutable state".
- `cover.exactCap`: past this many distinct candidates the fewest-runs search (task 6.1.2) switches from exact
  to greedy. It is the same cap `packages/core/CLAUDE.md` section 5.13 names ("Past 24 distinct candidates a
  pass falls back to greedy") and `packages/core/src/statics/arm-cover/arm-cover-statics.ts` holds as
  `exactCandidateLimit: 24`.

There is no cap on how many inputs the prediction engine derives for one specimen either. The only guard against
runaway code is the set of deterministic pass and depth counts in `executeStatics` (task 6.1.3): a run that loops
or recurses past them is refused by name. A refusal is rare, it lands in `REFUSED.md` with its reason, and the
count report counts it. The engine never cuts a list to fit.
