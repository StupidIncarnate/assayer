## Contract

The checked form of one `CompositionCard` from `declarations/kit.ts` (task 1.1.1), after the loader evaluates a
`*.compositions.ts` file. It is plain data, so it is a Zod schema. Use `z.lazy` for the recursive node.

```ts
leaf = z.union([
  z.object({ source: z.union([sourceKindContract, z.literal('binding')]), name: <branded string>, type: <branded string>, value: z.json().optional() }),
  z.object({ snippet: <branded string>, form: z.enum(['expression', 'statement']) }),
])
node = z.object({ piece: <branded string>, type: <branded string>.optional(), rename: z.record(<string>, <branded string>).optional(), slots: z.record(<string>, z.union([node, leaf, z.array(z.union([node, leaf]))])).optional() })
helper = z.union([{ name, tree: node }, { name, typeAlias }, { name, enumMembers: z.array(<branded string>) }])
sibling = z.object({ file: <branded string>, tree: node.optional(), helpers: z.array(helper).optional(), reexport: z.object({ name, from }).optional() })
stubCorrection = z.object({ type: <branded string>, property: <branded string>, values: z.array(z.json()) })
compositionCardContract = z.object({
  folder: <branded string>, description: <branded string>, tree: node.optional(), axis: axisValueContract.optional(),
  sameAs: <branded string>.optional(), helpers: z.array(helper).optional(),
  siblings: z.array(sibling).optional(), stubCorrection: stubCorrection.optional(),
  exportName: <branded string>.nullable().optional(),   // the card's own export name; null for `export {}`
}).brand<'CompositionCard'>()
```

Refines on the card:

- exactly one of `tree` and `sameAs` is set. Message: `a composition card sets exactly one of tree and sameAs. '<folder>' sets <both|neither>. Give the card its own tree, or name the card it repeats in sameAs.`
- the folder starts with `src/`. Message: `a composition card folder must start with 'src/'. '<folder>' does not. Write the folder as DESIGN.md's card writes it.`
- a sibling sets `tree`, `reexport` or `helpers` (at least one). Message: `sibling '<file>' of card '<folder>' holds nothing. Give it a tree, helpers or a reexport.`

A record nested in an object contract brands its values, owner plus key.

## Tests

- `INVALID: a card with both tree and sameAs` and `INVALID: a card with neither` assert the message word for word.
- `VALID: a sameAs card` parses.
- `VALID: a two-level tree` (`arrow-function` holding `if` holding a `param` leaf) parses.
- `INVALID: folder 'and/as-condition'` asserts the folder message word for word.
- `INVALID: a leaf with source 'external'` throws.
- `VALID: a card with one sibling that re-exports` parses.
- `INVALID: a sibling that holds nothing` asserts the sibling message word for word.
- `VALID: a card with stubCorrection {type: 'Box', property: 'count', values: [1, 2]}` parses.
- `INVALID: stubCorrection without values` throws.
- `VALID: a card with exportName 'Counter'` parses, and `VALID: a card with exportName null` parses.
- `INVALID: a card with exportName ''` throws.
