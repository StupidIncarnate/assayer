## What to implement

`todayStatics`, `as const`, with one group `gaps`: an array of rows sorted by `id`. Each row holds:

- `id`: the kebab-case id.
- `today`: one plain sentence saying what Assayer does today (README "Today gaps", column "What Assayer does today").
- `closedBy`: the phase that closes it, as `'phase-<n>'` (README column "Closed by").
- `match`: an array of alternatives. The row matches a specimen when any alternative holds. An alternative is
  an object, and it holds when every key in it holds. A key holds when any item in its list holds. Task 6.2.6
  reads these keys: `pieces`, `piecePositions`, `slotFills`, `axisValues`, `paramTypes`, `leafReads`, `causes`,
  `lintRules`, `buildErrors`, `buildErrorReasons`, `gaps`, `siblingFiles`, `twoParamLeaves`, `stubValues`. README "Today gaps" defines each.

Write every row of README "Today gaps", with `match` copied from its "Match" column. The README column says
"or" between alternatives. Three rows have two alternatives: `optional-property-presence`
(`[{ pieces: ['in-check'] }, { causes: ['present-undefined'] }]`), `compound-assign-untracked`
(`[{ pieces: ['nullish-assign', 'or-assign', 'and-assign'] }, { leafReads: ['compound-write'] }]`) and
`known-value-consumption-point` (`[{ lintRules: ['unreachable-exit'] }, { buildErrorReasons: ['contradicting-stub'] }]`).
Three rows have one alternative with several keys: `template-literal-env-chain`
(`pieces: ['template-literal']` and `axisValues: [['source', 'env-load'], ['source', 'env-call']]`),
`known-value-cross-file` (`siblingFiles: true`, `lintRules: ['unreachable-exit']`) and `guard-narrows-unknown`
(`pieces: ['type-guard-call', 'typeof-check']`, `paramTypes: ['unknown']`). Every other row has one
alternative with one key. The row `two-param-comparison` has `twoParamLeaves: true`, a boolean key like `buildErrors`. The row `derived-stub-values` has `stubValues: true`, a boolean key that holds when the prediction's `stubValues` list is not empty, and `closedBy: 'phase-26'`. A `slotFills` item is `[host, slot]` or `[host, slot, child]`.

Copy the ids exactly: `value-position-logical`, `edge-values`, `optional-property-presence`,
`gap-param-name`, `default-param-branch`, `default-param-ternary-passed`, `destructure-default-branch`,
`loop-dark-spot`, `compound-assign-untracked`, `loop-written-variable`, `call-sequence`, `try-dark-spot`,
`await-throw-point`, `promise-callback-arms`, `promise-executor-exits`, `optional-chain-nested`,
`enum-case-unread`, `switch-shape`, `never-read-lint`, `edge-merge-lint`, `env-in-function`,
`template-literal-env-chain`, `barrel-follow`, `p1-reason-token`, `unresolved-import-admits`,
`known-value-consumption-point`, `known-value-cross-file`, `guard-narrows-unknown`, `two-param-comparison`,
`derived-stub-values`. Sort them alphabetically in
the file. If README "Today gaps" holds a row not in this list, write that row too.

Header comment: a specimen whose plan matches a row is generated with `it.failing`, so it passes while Assayer
still lacks the feature and fails the day Assayer gains it. The core phase in `closedBy` removes the row in its
last task. A key holds when any item of its list holds; an alternative holds when all its keys hold; a row
matches when any alternative holds.
