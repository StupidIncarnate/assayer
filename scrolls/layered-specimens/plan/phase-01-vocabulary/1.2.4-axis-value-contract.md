## Contract

```ts
axisValueContract = z.object({
  axis: z.enum(<the keys of axisStatics.axes, in order>),
  value: z.string().min(1).brand<'AxisValueValue'>(),
}).brand<'AxisValue'>()
```

Build the axis enum from `axisStatics` (task 1.1.2), so the list exists once. A contract may import statics.
Add a `.refine` that the value is the axis's `default` or one of its `values`, with the message:
`axis value '<value>' is not a value of the '<axis>' axis. Use one of: <default and values joined by ', '>.`

## Tests

- `VALID: {axis: 'position', value: 'statement'}` (the default) parses.
- `VALID: {axis: 'level', value: '2'}` parses.
- `VALID: {axis: 'file-boundary', value: 'unresolvable-dynamic'}` parses.
- `INVALID: {axis: 'colour', value: 'red'}` throws (unknown axis).
- `INVALID: {axis: 'position', value: 'middle'}` throws the refine message above, word for word.

`AxisValueStub` defaults to `{ axis: 'position', value: 'statement' }` and accepts overrides.
