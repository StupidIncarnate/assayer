## Contract

The count report is what `--count` and every generation print. It has no `overBudget` field, because the
matrix has no cap.

```ts
z.object({
  total: z.number().int().min(0).brand<'CountReportTotal'>(),
  byFocus: z.array(row),      // sorted by name
  byAxis: z.array(row),       // name is the axis name; sorted
  byLayer: z.array(row),      // name is the level as text: '0', '1', '2', '3'; sorted
  byTopFolder: z.array(row),  // name is the first folder under src; sorted
  today: z.array(row),        // specimens per today id; empty until task 9.8.1 fills it from a dry-run build; sorted
  refused: z.number().int().min(0).brand<'CountReportRefused'>(), // specimens TypeScript or the engine refused
  estimatedMinutes: z.number().int().min(0).brand<'CountReportEstimatedMinutes'>(),
}).brand<'CountReport'>()
```

where `row` is `z.object({ name: z.string().min(1).brand<'CountReportRowName'>(), count: z.number().int().min(0).brand<'CountReportRowCount'>() }).brand<'CountReportRow'>()`. Brand every string and number field, owner plus key.
