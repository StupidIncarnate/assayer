## What to implement

One `as const` object `axisStatics` with a group `axes`, keyed by axis name, in this order. Each axis holds
`default` (the value every other specimen takes), `values` (every non-default value, in the order the
planner crosses them) and `folder` (the output folder segment for this axis, used by task 4.1.2). Values are
kebab-case strings, except `level`, whose values are the digits as strings. Take every value from the DESIGN.md
table cell named in the last column.
