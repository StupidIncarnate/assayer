## What to implement

```ts
export const specimenLayoutStatics = {
  files: {
    entry: 'entry.ts',
    test: 'entry.test.ts',
    harness: 'entry.harness.ts',
    tsconfig: 'tsconfig.json',
    stubsFolder: 'assayer/stubs/objects',
  },
  names: { entry: 'entry', entryClass: 'Entry' },
  segments: {
    alone: 'alone',
    positionPrefix: 'as-',
    exitSlots: 'exit',
    placedIn: 'in',
    moduleLevel: 'module',
    holds: 'holds',
    sequence: 'sequence',
    nested: 'nested',
  },
} as const;
```

The header comment says:

- every specimen is a folder. Its main file is `entry.ts`, which exports `entry` (or the class `Entry`), and
  its test is `entry.test.ts`. A companion harness is `entry.harness.ts`;
- a stub correction sits at the root of the repo Assayer analyses (root `CLAUDE.md`; DESIGN.md decision "Where a
  generated stub correction lives"): `smoke-repo/<stubsFolder>/<definitionRelPath>/<TypeName>.json`, where
  `<definitionRelPath>` is the specimen's `entry.ts` relative to `smoke-repo/`
  (`packages/syntax-repository/src/<folder>/entry.ts`). The folder path in the key keeps one specimen's correction
  away from every other's;
- the segments are the folder words README "Output layout" lists: `alone`, `as-<position>`, `exit/<slot>`,
  `in/<slot>`, `in/module` (level 0 at the module), `holds/<child>`, `sequence`, `nested`.
