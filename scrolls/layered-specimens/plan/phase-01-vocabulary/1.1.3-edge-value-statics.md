## What to implement

`edgeValueStatics`, `as const`, with four groups.

`edgeValues`: the fixed list of edge values per base type, from the DESIGN.md "Edge values" table. `NaN`
cannot be compared with `===`, so store it as the string token `'NaN'` and say so in a comment. Task 6.1.1
turns the token into the value.

| Type | Edge values |
|---|---|
| `number` | `0`, `'NaN'`, `-1` |
| `string` | `''` |
| `boolean` | `false` |
| `array` | `'empty'`, `'one'`, `'many'` |
| `object` | `'empty-object'` (`{}`, where the type allows it) |
| `nullable` | `'undefined'`, `'null'` (each only where the type allows it) |

A literal union or enum has no entry: each of its members is an edge value, read from the type.

`causes`: the cause class names, in this order: `ordinary`, `zero`, `nan`, `negative`, `empty-string`,
`false`, `undefined`, `null`, `member`, `empty`, `one`, `many`, `empty-object`, `left-out`, `missing`,
`present-undefined`, `missing-level`, `unset`, `rule-named`, `stub-value`, `call-count`. A cause class says
why a route exists: `ordinary` is the value derived from an arm's condition. `rule-named` is a value an
edge-value-merge rule names. `stub-value` is a value a stub correction supplies. `call-count` is a route
that exists because the case makes several calls in a row.

`ruleNamed`: the value an edge-value-merge rule names, per rule: `loose-equality: '0'` (on the true arm, for a
string member) and `mixed-plus: '1'` (for a string member).

`unknownRejects`: `['string', 'null', 'undefined']`, the values a type guard on `unknown` rejects (card
`retype/guard`).

The file's header comment writes the cause rule in plain words, steps 1 to 6 of README "The cause rule":

1. an ordinary value per arm combination, derived from the arms' own conditions, with each short-circuit cause
   of an arm as its own input;
2. one more input per edge value of each leaf operand, on the arm it lands on;
3. one input at a time takes an edge value, and every other input takes the first value, in route order, that
   still lets the edge-valued input be read;
4. a route is its arm set plus the values its run read, so an ordinary value that is also an edge value is one
   route;
5. a parameter nothing reads gets no edge-value routes;
6. a route Assayer cannot steer is listed once per arm combination, with no edge-value routes.

Add one sentence: fewest runs is the smallest set of driven routes that takes every reachable arm, unchanged.
