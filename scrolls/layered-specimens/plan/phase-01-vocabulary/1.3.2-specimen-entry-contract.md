## Contract

`specimenEntryContract` is one manifest row. It replaces `manifestEntryContract` when task 9.7.3 deletes it.

```ts
z.object({
  folder: z.string().min(1).brand<'SpecimenEntryFolder'>(),        // 'src/and/as-condition'
  files: z.array(z.string().min(1).brand<'SpecimenEntryFiles'>()), // every file of the specimen, sorted, relative to folder
  focus: z.string().min(1).brand<'SpecimenEntryFocus'>(),          // the piece the specimen is about
  axis: axisValueContract,                                         // the one thing it varies
  level: z.number().int().min(0).brand<'SpecimenEntryLevel'>(),
  uses: z.array(z.string().min(1).brand<'SpecimenEntryUses'>()),   // every piece in it, focus first
  card: z.boolean(),                                               // true for a DESIGN.md card (a composition)
  today: z.array(z.string().min(1).brand<'SpecimenEntryToday'>()), // today ids, sorted; non-empty means it.failing
}).brand<'SpecimenEntry'>()
```
