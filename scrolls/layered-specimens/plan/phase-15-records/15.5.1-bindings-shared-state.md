## Contract

`readStatementBindingsLayerTransformer` keeps its signature.

| Statement the reader meets | Binding afterward |
|---|---|
| `x op= rhs` whose class is `'shared'` | `apply(op, repeat(per 'call', receiver: <flow of the declaration's initializer>, op, args: [<change>]), <change>)` |

`<change>` is the right side read through `readValueExprLayerTransformer` with the bindings in effect, and it must hold
no `select`. The target `x` is an identifier or `this.<field>`; its declaration is the identifier's value declaration, or
the field's `PropertyDeclaration`. The initializer must be a literal.

The binding is created at the write statement, because the reader sees only the writer's own statements. A branch that
reads the variable earlier in the same call has no binding and stays undriven. Say so in the header comment.

## What to implement

1. For a write whose class is `'shared'`, build the binding in the table. A missing initializer, a non-literal
   initializer or an unreadable change drops the binding.
2. The binding is keyed by the declaration's position, so a read in the same function body finds it through the existing
   lookup, and a read of `this.<field>` finds it through the lookup of task 15.2.4.
3. Update the header comment: the shared class, the three shapes it covers (module `let`, class field, returned-closure
   capture), and the early-read rule above.

## Tests

- `VALID: module let calls = 0, then calls += 1 in the writer's body => apply(add, repeat per call receiver lit 0 args [lit 1], lit 1)`
- `VALID: this.calls += 1 in a method, field initializer 0 => the same shape, keyed by the field declaration`
- `VALID: let calls = 0 in the entry, calls += 1 in the returned no-parameter closure => the same shape`
- `VALID: the change is a parameter (calls += step) => args [param step]`
- `INVALID: a shared variable declared without an initializer => no binding`
- `INVALID: a shared variable whose initializer is a call => no binding`
- `INVALID: calls += compute() => no binding (unreadable change)`
- `EDGE: a read of the variable before the write in the same body => no binding for that read`
- `EDGE: the existing tests and the tests of tasks 15.3.2 and 15.4.1 pass unchanged`
