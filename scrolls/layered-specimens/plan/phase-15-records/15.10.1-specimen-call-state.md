## What to implement

1. One file with three entries. Each holds its state in a different place, and each starts from a fresh module per case
   (task 15.2.6), so the module `let` does not leak from one case to the next.

   ```ts
   let calls = 0;

   export const countCalls = (limit: number): string => {
     calls += 1;
     if (calls > limit) {
       return 'over';
     }
     return 'under';
   };

   export class Counter {
     private hits = 0;

     public hit(limit: number): string {
       this.hits += 1;
       if (this.hits > limit) {
         return 'over';
       }
       return 'under';
     }
   }

   export const makeCounter = (limit: number): (() => string) => {
     let uses = 0;
     return (): string => {
       uses += 1;
       if (uses > limit) {
         return 'over';
       }
       return 'under';
     };
   };
   ```

2. The test asserts, per entry, what the cards say. Write the expected values by reasoning from the cards.
   - `countCalls` and `Counter.hit`: one `if` (arms `then`, `else`). Five routes, from the card: `limit 0` with 1 call
     takes `then`; `limit NaN` with 1 call takes `else`; `limit -1` with 1 call takes `then`; `limit 1` with 1 call takes
     `else`; `limit 1` with 2 calls takes `else, then`. Every case carries `calls`. The `else, then` route takes both arms in
     one case, so the fewest-runs set holds 1 case, as the cards say. Assert 1.
   - `makeCounter`: the closure's `if` has the same five routes, driven through the entry's `limit` and the closure's call
     count (tasks 15.4.3, 15.5.1, 15.6.2 and 15.7.1 drive it).
   - no dark spot, no undriven entry, no gap and no lint.
3. If the probe shows the closure's branch as undriven, that is a defect in tasks 15.4.3 to 15.7.1. Report the admission's
   exact text. Do not remove `makeCounter`.
4. Registry line, declared by reading the file. Expect `access:method` for `hit`, `access:named` for the two functions,
   `branch:if`, and `access:constructor` only if the implicit constructor is an entry.
5. Run `npm run test:syntax`. Every other specimen must still pass: every core task of the phase landed by row #7,
