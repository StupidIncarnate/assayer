## Contract

A case with `calls` (task 15.1.2) is a call sequence: the interpreter applies the resolved entry `calls` times in a row
with the same arguments, and judges the last application. A case with no `calls` behaves exactly as today.

## What to implement

1. In `case-interpret-broker.ts`, apply the entry `calls ?? 1` times, one after another, each finished through
   `caseSettleBroker` before the next starts. Write the repetition as a recursive step or a promise-chain reduce, never a
   `while (true)`. Check the lint rules for an `await` inside a loop before choosing.
2. Reset the probe before every application. The case is judged by the events of the last application only, so
   `observedPath` and `trace` come from it. The earlier applications exist to move the state.
3. The environment bindings are set once before the first application and restored once after the last, as today.
4. An application that throws, or a generator that does not finish, errors the case. When `calls` is above 1, the message
   names the call: `threw before reaching an exit on call 2 of 3: <message>`. When there is one application the messages
   are byte for byte the ones the file writes today, so every existing test passes unchanged.
5. Update the header comment: the call sequence and the call-numbered error message.

## Tests

Use the fake entry and probe the existing test file builds.

- `VALID: calls 3 and an entry that returns a counter => the entry is applied three times and the case is judged on the third`
- `VALID: calls 2 => events of the first application are not in observedPath or trace`
- `VALID: calls 2 on an async entry => the first application finishes before the second starts`
- `VALID: no calls => one application, the same result as before`
- `VALID: calls 1 => one application`
- `ERROR: the second of three applications throws => errored, message 'threw before reaching an exit on call 2 of 3: boom'`
- `ERROR: a single application throws => the message is the unchanged one`
- `ERROR: the last application reaches no exit => errored, 'reached no exit in ...' as today`
- `EDGE: environment bindings are written once and restored once for a call sequence`
