## What to implement

Add exactly one route. A `BinaryExpression` whose operator token kind is `QuestionQuestionEqualsToken`,
`BarBarEqualsToken` or `AmpersandAmpersandEqualsToken` goes to `handleLogicalAssignLayerTransformer` (task 15.2.3).
Place it with the other expression routes, before the final default branch. Read the operator from the token kind, as the
handler does.

Every other binary expression, including `=` and `+=`, keeps falling through to the default branch. A compound
assignment is not a branch, and the walk descends its children as before.

If `BinaryExpression` is in `significant-syntax-kinds-statics.ts`, the dark-spot record the default branch would write
for it disappears for these three operators because the route marks the node `handled`. Do not remove any kind from that
list (`packages/core/CLAUDE.md` section 5.6).

## Tests

- `VALID: a ??= b => routed to the logical-assign handler`
- `VALID: a ||= b and a &&= b => routed to the logical-assign handler`
- `VALID: a += b => not routed there; the default branch descends its children`
- `VALID: a = b => not routed there`
- `VALID: a ?? b => not routed there (the existing short-circuit readers still own it)`
- `EDGE: a statement nested in an if arm => routed with the arm's guard path intact`
