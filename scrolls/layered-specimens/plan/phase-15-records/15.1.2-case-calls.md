## Contract

```ts
calls: z.number().int().positive().brand<'DerivedTestCaseCalls'>().optional(),
```

`calls` is present only on a case whose entry reads state that lives across calls. Its meaning: the case loads the
module fresh, then calls the entry `calls` times in a row with the same arguments, and judges the last call.
A case with no `calls` makes one call on the module the test file already loaded, exactly as today. The field has no
default, so every existing case serializes to the same bytes.

## What to implement

Add the field to the contract and describe it in the header comment in plain words, including the rule that `calls`
present means "fresh module".
