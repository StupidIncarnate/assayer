## Contract

```ts
pairCandidatesTransformer({ kind }: { kind: 'gt' | 'gte' | 'lt' | 'lte' | 'eq' | 'neq' }): { left: number; right: number; holds: boolean }[]
```

`left` and `right` are the values of the two number parameters of `left <kind> right`. `holds` says whether the comparison
is true for the pair. The list is in a fixed order, so the same call always gives the same list. `NaN` is the JavaScript
`NaN` number here. The caller turns it into the arrange value task 12.1.2 defines.

## What to implement

1. The right side has the **anchor** 2. The left side has an anchor and a boundary, by kind:

   | kind | left anchor (the comparison holds) | left boundary (the comparison fails, one step away) |
   |---|---|---|
   | `gt` | 3 | 2 |
   | `gte` | 2 | 1 |
   | `lt` | 1 | 2 |
   | `lte` | 2 | 3 |
   | `eq` | 2 | 3 |
   | `neq` | 3 | 2 |

2. The list, in this order, with duplicate pairs removed (the first one stays):
   - the anchor pair (left anchor, right 2);
   - the boundary pair (left boundary, right 2);
   - each edge value of the number type as the left side, with the right side at 2: `edgeValueStatics.number.zero`, `NaN`,
     `edgeValueStatics.number.negative`;
   - each edge value as the right side, with the left side at its anchor, in the same order.
3. `holds` comes from the language's own operator on the two numbers (`NaN > 2` is false). This places a chosen input on an
   arm. It never runs the code under test (rule P4).
4. PURPOSE block in plain words: why the right side is anchored, why the edge values of each side are separate cases, and
   that only number parameters are covered here.

## Tests

- `VALID: gt => (3,2) holds, (2,2) fails, (0,2) fails, (NaN,2) fails, (-1,2) fails, (3,0) holds, (3,NaN) fails, (3,-1) holds` (the eight routes of the card)
- `VALID: lt => anchor (1,2) holds, boundary (2,2) fails, and left edges 0, NaN, -1 with right 2`
- `VALID: eq => anchor (2,2) holds, boundary (3,2) fails`
- `VALID: neq => anchor (3,2) holds, boundary (2,2) fails`
- `VALID: gte and lte => the anchors and boundaries of the table`
- `EDGE: a pair that repeats an earlier pair (lt with left edge 0 and the anchor is not 0) => listed once`
- `EDGE: two calls with the same kind => identical lists`
