## Contract

```ts
valueExprEvaluateTransformer({
  expr,
  params,                 // ReadonlyMap<string, RepresentativeValue>, as today
  repeats,                // optional: { passes: ReadonlyMap<string, number>; calls: number; items: ReadonlyMap<string, readonly RepresentativeValue[]> }
}): { value: RepresentativeValue } | undefined
```

`repeats.passes` maps a loop's coverage id to the number of passes completed before the read. `repeats.calls` is the
number of calls made before the current one. `repeats.items` maps the name of an array parameter to the items the case
passes in.

Evaluation:

| Form | Value |
|---|---|
| `apply` | the language's `+`, `-` or `*` on the evaluated `receiver` and `args[0]`. `undefined` when either side does not evaluate. `add` of a string and a number joins them, as the language does |
| `repeat`, per `'pass'` | the evaluated `receiver`, then `op` applied once per completed pass of `loop`. The change is `args[0]`; when it is `element(collection)`, pass `k` applies the `k`-th item of `repeats.items` for the collection's parameter. A pass count above the item count is `undefined` |
| `repeat`, per `'call'` | the evaluated `receiver`, then `op args[0]` applied `repeats.calls` times |
| `element` | only meaningful inside a `repeat`; evaluated alone it is `undefined` |
| `repeat` or `element` with no `repeats` given | `undefined` |

Arithmetic follows the language, so `NaN`, `Infinity` and string joins all come out as the code would compute them.
This is evaluation of the program's own expression over chosen inputs. It is not running the code under test, so it is
allowed (rule P4 forbids recording an output, not computing a derived input).

The order of work is fixed: evaluate `receiver`, then fold the change. Do not loop more than the pass or call count
the caller gives. The caller bounds those counts (task 15.5.2), and the evaluator adds no cap of its own.

- `INVALID: repeat with no repeats input => undefined`
- `INVALID: repeat pass whose loop id is missing from passes => undefined`
- `INVALID: repeat pass over element(items) with passes above the item count => undefined`
- `INVALID: element on its own => undefined`
- `INVALID: apply whose receiver is an unbound param => undefined`
- `EDGE: multiply with a negative start and a fractional change => the language's result`
- `EDGE: the existing method, select and lit tests pass unchanged`
