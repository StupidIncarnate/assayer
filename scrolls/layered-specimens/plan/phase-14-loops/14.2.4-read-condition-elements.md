## What to implement

`readConditionLayerTransformer` reads an operand's root through `readPropertyPathLayerTransformer` and records
`operandParamName` when the root is one of the scope's parameters. A loop item is a local, so `item > 2` records no
parameter today. Add: when the root is an identifier whose name is a key of `context.elements` (task 14.1.2), record
`operandParamName: elements[name].param` and `operandPropertyPath: [...elements[name].path, ...<the chain's own path>]`.
So `item > 2` reads as `items` with `['[0]']`, `item.count > 2` as `items` with `['[0]', 'count']`, and
`price > 100` in a nested loop as `orders` with `['[0]', 'prices', '[0]']`. The name is the identifier's own name, the
sanctioned read of section 5.1. Every other operand is read as today.

## Tests

- `VALID: {item > 2 with elements { item: { param: 'items', path: ['[0]'] } }} => operandParamName items, path ['[0]']`
- `VALID: {item.count > 2} => items, ['[0]', 'count']`
- `VALID: {price > 100 with a nested binding} => orders, ['[0]', 'prices', '[0]']`
- `EDGE: {a local not in elements} => read as today`
