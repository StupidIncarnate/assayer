## What to implement

`discover` the neighbouring `happy-path/` specimens and copy their test shape.

`for-of-if.ts` exports two entries, one per card:

- `sumAbove = (items: number[]): number => { let total = 0; for (const item of items) { if (item > 2) { total += item; } } return total; }`
  (card `loop/for-of`). `total += item` is a compound write; no branch reads `total`, so it needs no phase 15 work.
- `findFirst = (items: number[]): string => { for (const item of items) { if (item > 2) { return 'found'; } } return 'none'; }`
  (card `loop/return-inside`).

The specimen holds no `do…while`. A `do…while` whose test can be true never ends unless its body changes the state the
test reads, and Assayer follows a variable written in a loop only from phase 15 on. A case that takes the `repeats` arm
would hang the run. The `do…while` handler is proved by the unit tests of task 14.2.1 (arms `repeats` and `stops`, an
unguarded body), and phase 15's loop-state specimen runs a terminating one.

The test asserts what is bespoke, from the cards and DESIGN.md, not from a run:

- `sumAbove`: a `loop` branch with arms `runs` and `skipped` and an `if` branch; no dark spot; the every-route list has
  seven cases (`[]`, `[2]`, `[0]`, `[NaN]`, `[-1]`, `[3]`, `[2, 3]`), the last taking `else` and `then` in one run; fewest
  runs 2;
- `findFirst`: the same seven cases; `[3]` and `[2, 3]` reach `found`, the rest reach `none`; two exits;
- determinism and formatting immunity.

Write the registry line by reading the file (brief rule 21); read the trait vocabulary, and declare only traits the file visibly has.
