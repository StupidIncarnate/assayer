## What to implement

Add exactly one route to `handleLoopLayerTransformer` (task 14.2.1), placed beside the `if` and `switch` routes, for these
node kinds: `Node.isForStatement`, `Node.isForOfStatement`, `Node.isForInStatement`, `Node.isWhileStatement` and
`Node.isDoStatement`.

The five kinds stay on `statics/significant-syntax-kinds`. The default branch of `dispatch-node` is what records an
unhandled kind as a dark spot, and a kind that has a route never reaches it, so listing the kinds does no harm.
Confirm in your reply that no `ForOfStatement` dark spot is produced, by a test over `walkFileTransformer`.

## Tests

- `VALID: {for (const item of items) {}} => handled by the loop handler (one loop branch, no dark spot)`
- `VALID: {while (x) {}} => one loop branch`
- `VALID: {do {} while (x)} => one loop branch, arms ['repeats', 'stops']`
- `VALID: {for (let i = 0; i < n; i += 1) {}} => one loop branch`
- `VALID: {for (const key in record) {}} => one loop branch`
- `EDGE: {a loop inside a function that sits inside a loop} => two loop branches, and the inner one's guard path is empty (a nested function resets the guard path)`
- `EDGE: {a labelled block that is not a loop} => unchanged default descent`
