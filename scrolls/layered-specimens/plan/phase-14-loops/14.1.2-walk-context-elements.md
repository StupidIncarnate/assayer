## What to implement

Add one optional field to the walk context: `elements?: Record<string, { param: string; path: string[] }>`. A key is a
local name the walk has bound to an element of an array parameter: a `for…of` head (`const item of items`) binds
`item` to `{ param: 'items', path: ['[0]'] }`, and a nested loop over a property of that item
(`for (const price of order.prices)`) binds `price` to `{ param: 'orders', path: ['[0]', 'prices', '[0]'] }`. The index
segment `'[0]'` is the one task 12.1.7 reads for `xs[0]`: a case builds the one-item array, so the item is element 0.

It flows down the walk like `bindings` (section 2). Say that in the contract's header comment in one sentence. Keep
`walk-context.stub.ts` unchanged: the field is optional, so the stub's default has none.
