## Contract

`TestGeneratedRunResponder({ argv, repoRoot }): Promise<GenerateRunResult>` (the existing `generateRunResultContract`: `{ exitCode, output }`).

## What to implement

1. **Refuse a bad command line before anything runs.** `argv` holds exactly one folder argument.
   - No argument: `test:generated needs one top folder, such as 'if/'. The whole suite in one process runs out of memory.`
   - Two or more: `test:generated takes one folder at a time, such as 'if/'. It was given <n>: <the arguments joined with ', '>.`
   - One argument that does not end in `/`, or that names no folder under `smoke-repo/packages/syntax-repository/src/` (check with `existsSync` from `#gateway/node/fs`): `test:generated cannot use '<argument>'. Name one folder under smoke-repo/packages/syntax-repository/src, ending in a slash, such as 'if/'.`
   Each refusal is exit code 1 with that text as `output`.
2. **Pick the worker count.** Read `capacityReadBroker({ diskPath: repoRoot, job: { peakMB: workers.max * workers.peakMBPerWorker } })` through `#gateway/npm/legendscribe__lockdown-kit-load-balancer__brokers`. `workers = clamp(suggestion, 1, runScaleStatics.workers.max)`.
3. **Take a lease** with `capacityLeaseBroker({ label: lease.labels.testGenerated, peakMB: workers * workers.peakMBPerWorker })` (task 8b.2.1). It waits while the machine is full.
4. **Run Jest** with `jestRunBroker({ repoRoot, folder, maxWorkers: workers })` (task 8b.2.5).
5. **Release the lease in a `finally`**, whatever Jest answered.
6. Answer `{ exitCode: <jest's code>, output: 'test:generated <folder>: jest exited with code <n>' }`.

Never run two at once: the smoke repo's concurrency guard (`smoke-repo/packages/syntax-repository/concurrency-lock.js`) refuses the second.

## Tests

The proxy mocks the three brokers and `existsSync`.

- `INVALID:` no argument gives the first refusal text word for word, and no broker is called.
- `INVALID:` two arguments gives the second refusal text.
- `INVALID:` `if` (no slash) and `nope/` (no folder) give the third refusal text.
- `VALID:` `if/` with suggestion 2 runs Jest with 2 workers under a lease labelled `assayer-test-generated` with peak 2048, and exits with Jest's code.
- `VALID:` a suggestion of 9 clamps to 4 workers; a suggestion of 0 clamps to 1.
- `ERROR:` when Jest rejects, the lease is still released and the rejection propagates.
