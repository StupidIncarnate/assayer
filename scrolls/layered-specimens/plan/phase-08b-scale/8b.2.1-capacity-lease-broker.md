## Contract

`capacityLeaseBroker({ label, peakMB }): Promise<{ release: () => Promise<void> }>`

Import the load balancer brokers from `#gateway/npm/legendscribe__lockdown-kit-load-balancer__brokers` and the numbers from `runScaleStatics` (task 8b.1.2).

## What to implement

1. Wait while `capacityReadBroker({ diskPath: cwd(), job: { peakMB } })` has `suggestion` 0. Wait `lease.waitMs` between reads, at most `lease.waitRounds` rounds. Past the last round, write this warning to stderr and go on: `capacity-lease: no free capacity after <seconds> seconds; running anyway as '<label>'.` where `<seconds>` is `waitRounds * waitMs / 1000`. The wait is never silent and never unbounded.
2. Take the lease: `leaseTakeBroker({ tool: lease.tool, label, ownerPid: pid, expectedPeakMB: peakMB })`. It returns the lease id.
3. Start an interval of `lease.beatMs`. Each tick calls `leaseBeatBroker({ leaseId })`. When the answer is `{ found: false }` (the lease went stale), take a new lease the same way and use its id from then on.
4. `release()` clears the interval, then calls `leaseReleaseBroker({ leaseId })` with the current id.

A caller must `await` something between its units of work, or the interval never fires. Task 9.2.1 does.

## Tests

The proxy mocks the gateway wrapper and the timers.

- `VALID:` a free machine takes the lease once and `release` releases it.
- `VALID:` a tick beats the lease.
- `VALID:` a beat that answers `found: false` takes a new lease, and `release` releases the new id.
- `VALID:` a zero suggestion waits, then a positive one proceeds.
- `ERROR:` after `waitRounds` rounds of zero the warning is written once and the lease is still taken.
