## What to implement

`TestGeneratedFlow({ argv, repoRoot }): Promise<GenerateRunResult>` calls `TestGeneratedRunResponder` (task 8b.3.1)
and returns its answer. A startup file may import only flows, contracts, statics and errors, so the responder is
reached through this flow. Task 8b.5.1 writes the startup and the bin entry in the next row.

The integration test calls the real flow with the real repo root, built the way
`flows/generate/generate-flow.integration.test.ts` builds `REAL_REPO_ROOT` (read it), and never starts Jest. It holds
the three refusal cases below, each asserted with `toStrictEqual` on the whole result.

## Tests

- `INVALID: { argv: [] }` gives exit code 1 and `test:generated needs one top folder, such as 'if/'. The whole suite in one process runs out of memory.`
- `INVALID: { argv: ['if/', 'ternary/'] }` gives exit code 1 and `test:generated takes one folder at a time, such as 'if/'. It was given 2: if/, ternary/.`
- `INVALID: { argv: ['nope/'] }` gives exit code 1 and `test:generated cannot use 'nope/'. Name one folder under smoke-repo/packages/syntax-repository/src, ending in a slash, such as 'if/'.`
