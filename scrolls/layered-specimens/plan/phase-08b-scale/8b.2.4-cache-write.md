## Contract

`generationCacheWriteBroker({ cacheRoot, key, verdict, prediction }): void`

## What to implement

Write `<cacheRoot>/<key>.json` holding `{ schema, key, verdict, prediction }` (the envelope task 8b.2.3 reads), pretty-printed with two spaces and a trailing newline. The write is atomic: create the folder with `ensureDirSync`, write `<key>.json.<pid>.tmp`, then `renameSync` it onto `<key>.json` (both from `#gateway/node/fs`). A reader never sees a half-written file, and two processes writing the same key leave one good file.

## Tests

- `VALID:` the file appears with the exact text, and no `.tmp` file remains.
- `VALID:` writing the same key twice leaves the second content.
- `VALID:` a missing cache folder is created.
- `ERROR:` a failed rename propagates its error and leaves no `.tmp` file claiming to be an entry (the temp name never ends in `.json`).
