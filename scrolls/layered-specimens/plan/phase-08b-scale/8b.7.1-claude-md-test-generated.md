specimens' tests. After task 8b.6.1 the script is the wrapper of task 8b.3.1: it refuses a run with no folder, takes one
top folder at a time, and takes a capacity lease from the load balancer. Rewrite those sentences so they state that,

  smoke repo's concurrency guard;

Change nothing else in `CLAUDE.md`. Write it by the file's own rules: one idea per sentence, no history words.
