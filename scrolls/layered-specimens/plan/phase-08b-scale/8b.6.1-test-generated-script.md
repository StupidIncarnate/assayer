## What to implement

In the root `package.json`, change the script to:

`"test:generated": "tsx --conditions=source packages/specimen-generator/bin/test-generated-entry.ts"`

The old value is `jest --config smoke-repo/packages/syntax-repository/jest.config.js`. Change nothing else in the file. `npm run test:generated -- if/` passes `if/` through to the entry as its one argument.

The other scripts that name the smoke repo (`generate:specimens`, `typecheck:generated`) stay as they are. No row runs `npm run test:generated` with no folder: the wrapper refuses it.

## Verify

`npm run ward -- -- package.json`, then `npm run test:generated` with no argument exits 1 and prints the refusal `test:generated needs one top folder, such as 'if/'. The whole suite in one process runs out of memory.`

## Done when

Both commands behave as stated.
