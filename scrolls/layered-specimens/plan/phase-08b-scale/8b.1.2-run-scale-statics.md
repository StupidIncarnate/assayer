## What to implement

`runScaleStatics` holds every fixed number and name phase 8b and the build broker use:

```ts
export const runScaleStatics = {
  lease: {
    tool: 'ward',
    labels: { generate: 'assayer-specimen-generator', testGenerated: 'assayer-test-generated' },
    beatMs: 10000,
    waitMs: 2000,
    waitRounds: 150,
  },
  workers: { max: 4, peakMBPerWorker: 1024 },
  cache: { folder: ['node_modules', '.cache', 'assayer-specimen-generator'], schema: 1 },
} as const;
```

The header comment says: the lease tool is `'ward'` because the load balancer's tool enum is `'ward' | 'siegelense'` (DESIGN.md decision "Leases on the load balancer"); a lease beat must arrive within 30 seconds, so `beatMs` is 10 seconds; waiting is a bounded number of rounds (`waitRounds` of `waitMs` each, 300 seconds in all), and past that bound the run proceeds and prints a warning, never silently; `workers.max` matches the hand-written `jest.config.js` default of 4; `cache.schema` changes when the cache file format changes.
