## Read first

The wrappers under `packages/@gateway/node/src/child_process/`. Choose the one that runs a program with its output going straight to this process's terminal and answers with the exit code. Report which one you chose.

## Contract

`jestRunBroker({ repoRoot, folder, maxWorkers }): Promise<number>`. `folder` is `if/`. The result is Jest's exit code.

## What to implement

Run `<repoRoot>/node_modules/.bin/jest --config smoke-repo/packages/syntax-repository/jest.config.js /src/<folder>` with `repoRoot` as the working directory and the environment variable `MAX_WORKERS` set to `maxWorkers` (the hand-written `jest.config.js` reads it). The positional argument is a Jest path pattern; the leading `/src/` keeps `if/` from matching a path such as `diff/`. Inherit the parent's standard streams. Resolve the exit code. A program that cannot start rejects with the wrapper's own error.

## Tests

The proxy mocks the child-process wrapper.

- `VALID:` the command, arguments, working directory and `MAX_WORKERS` are what is stated above.
- `VALID:` exit code 0 resolves 0.
- `INVALID:` exit code 1 resolves 1.
- `ERROR:` a start failure rejects.
