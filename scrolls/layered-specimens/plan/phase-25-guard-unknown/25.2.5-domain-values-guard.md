## What to implement

`domainValuesTransformer({ domain, type })` gains an optional input `narrowsTo?: { type: TypeDescriptor; arm: 'then' | 'else' }`. When it is present the function answers the values of that arm of a `narrows-to` predicate, and `domain` is the (open) domain the other predicates of the route left:

- `arm: 'then'`: the ordinary value of `narrowsTo.type` (`representativeValueTransformer`) first, then its edge values from core's edge statics, with no duplicate. For `number`: `7`, `0`, `NaN`, `-1`. For `string`: `'abc123'`, `''`. For `boolean`: `true`, `false`.
- `arm: 'else'`, declared `type.kind === 'unknown'`: the values the guard rejects that an `unknown` allows: the string ordinary value, the string edge value `''`, `null`, `undefined`, in that order.
- `arm: 'else'`, declared type a union: the ordinary value and edge values of each member whose runtime tag differs from `narrowsTo.type`'s tag (`typeofTagTransformer`), in member order. A member whose tag is not known stays out.
- A union operand's then arm uses the members whose tag equals `narrowsTo.type`'s tag.
- Otherwise the function answers what it answers today.

Every value comes from the declared types and the guard's type (rule P4), never from running the guard.
