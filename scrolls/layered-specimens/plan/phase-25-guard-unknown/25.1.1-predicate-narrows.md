## What to implement

Add the kind `'narrows-to'` to the `kind` enum of `predicateContract`, and one optional field:

```ts
narrowsTo: typeDescriptorContract.optional(),
```

(`typeDescriptorContract` comes from `../type-descriptor/type-descriptor-contract`; the worker confirms the import creates no cycle with `condition-leaf`, which imports both.) A `narrows-to` predicate says: on the then arm the operand is a value of the type `narrowsTo`, and on the else arm it is not. It is what a same-file type guard call (`isCount(value)` with `value is number`) reads as. `literal` stays absent for this kind. Extend the PURPOSE block with one paragraph.

The stub keeps its default. A test builds one with `PredicateStub({ kind: 'narrows-to', narrowsTo: { kind: 'number' } })`.
