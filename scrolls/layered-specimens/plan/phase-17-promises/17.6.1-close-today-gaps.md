   segment under `src/`) that holds a specimen listed under `promise-callback-arms` or `promise-executor-exits`. The cards give

2. Remove the rows `promise-callback-arms` and `promise-executor-exits` from `todayStatics.gaps`, and from the expected object
   in the test. Remove exactly those two.
3. Run `npm run generate:specimens`. The specimens that carried only these ids now generate as `it(`, not `it.failing(`.
4. Run `npm run test:generated -- <folder>/` for each folder from step 1, one at a time, with `timeout: 600000`. Every test in

   - the core change of this phase is incomplete;

The operator commits the statics change and the regenerated smoke repo together. **After this task the operator runs the

every top folder, one at a time, with `timeout: 600000`. Every folder must pass. A red folder becomes a fan-out row in this
phase, triaged the way phase 10 triages.

## The strict run: a hidden crash, or a match rule that is too broad

An `it.failing` test passes whenever its assertion fails, and that includes an observation that throws before it
asserts. A specimen also stays `it.failing` while any later id still matches it, so a later id whose `match` rule is
too broad can keep a specimen "passing" that Assayer in fact gets right, or gets wrong for a reason no id names. After
step 4, run `ASSAYER_SPECIMEN_STRICT=1 npm run test:generated -- <folder>/` once for each folder from step 1, one at a
time (task 8.2.2: under that variable every generated test is a plain `it`). Read only the specimens that still carry a
today id after this task:

- each must fail with a diff, and every difference must be one that a remaining id's `today` sentence explains;
- a specimen that passes under the strict run carries an id whose `match` rule is too broad: narrow that id's `match` rule in
  `today-statics.ts` (a file of this task) so it no longer matches the specimen, regenerate, and name the change in
  your reply;
- a specimen that errors instead of failing on a diff is a crash: report it with the error, as a regression;
- a difference that the id this task removes would explain means the core change is incomplete for that specimen:
  report it.

Never change a prediction to match Assayer's output (rule P4).
