## What to implement

The domain of a truthiness arm is what later guards on the same operand intersect with, and what task 12.3.3 reads to
place an edge value on an arm. Today the falsy arm of `number | undefined` names `0` only. Make it name every falsy point a
`RepresentativeValue` can carry:

1. Falsy points, in this order: the scalar points as today (`0`, `''`, `false`, a falsy literal member), read from
   `edgeValueStatics` rather than written inline, then `null` when the type is or includes a `null` or `undefined` member.
   `null` is the domain's nullish point; the case builder (task 12.4.1) turns it into `undefined` or `null` by the
   declared type.
2. The truthy arm excludes the same list.
3. A bare `number` is unchanged (`excluded: [0]` / `members: [0]`). `NaN` is not a domain point: no `RepresentativeValue`
   can hold it. Task 12.3.3 places `NaN` by evaluating the predicate on it, and says so in its header. Write that
   sentence in this file's PURPOSE block too.
4. A union with no falsy point keeps the representative reading it has today.

Write the PURPOSE block in plain words: what the domain names and why `null` stands for both nullish values.
