## What to implement

`case-interpret` applies a case's arrange bindings to the entry's arguments. It runs inside the nested Jest run, so it
is where a tagged value becomes a real one. Add one step before a binding's value is placed:

- `{ $assayer: 'undefined' }` becomes `undefined`.
- `{ $assayer: 'nan' }` becomes `NaN`.
- The conversion is recursive. An array item, and an object property at any depth, converts too. A property whose value
  is `{ $assayer: 'undefined' }` becomes a property that is present with the value `undefined` (the key stays), which is
  what `'x' in obj` reads (task 12.5.3).
- Every other value passes through untouched, by identity of content.

Keep the conversion in one `const` inside the broker file. Do not add a file. A scalar `param` binding carries
either a representative value or an `ArrangeSpecial`, so the placement code handles both.

The proxy changes only if the broker's imports do.

## Tests

- `VALID: {param binding { $assayer: 'undefined' }} => the entry receives undefined`
- `VALID: {param binding { $assayer: 'nan' }} => the entry receives NaN` (assert with `Number.isNaN` on a recorded argument, not `toBe`)
- `VALID: {object binding { label: { $assayer: 'undefined' } }} => 'label' in the received object is true and its value is undefined`
- `VALID: {array binding [{ $assayer: 'nan' }, 1]} => the first item is NaN`
- `VALID: {param binding 7} => unchanged`
- `EDGE: {a nested object with no tagged value} => the received object equals the arranged one`
- `INVALID: {the param binding value { $assayer: 'bogus' }} => arrangeBindingContract.parse throws` (this proves the binding union from 12.1.2 end to end)
