## What to implement

`discover` the neighbouring `happy-path/` specimens and copy the test's shape.

`edge-causes.ts` exports four entries, one per card, with distinct names:

- `truthiness = (count: number | undefined): string => { if (count) { return 'set'; } return 'missing'; }`
- `undefinedVsNull = (count: number | null | undefined): string => { if (count === undefined) { return 'missing'; } if (count == null) { return 'null'; } return 'value'; }`
- `nullishName = (name: string | undefined): string => name ?? 'anon'`
- `isSeven = (count: number): boolean => count === 7`

The test asserts what is bespoke to the file, written from the cards' every-route lists and not from a run:

- each entry's branch kinds and arm counts;
- each entry's every-route case list as a sorted list of `{ arms, arrange }` pairs. The card gives the expected input
  classes; the test states each class with a concrete value taken from `edgeValueStatics` or `representative-value-statics`
  (read both) and compares sorted lists (`.sort()` inline, no helper function). `truthiness`: two cases take `then`
  (a positive value and `-1`), three take `else` (`0`, `NaN`, `undefined`). `undefinedVsNull`: `undefined`, `null`, and four
  numbers. `nullishName`: `'x'`, `''`, `undefined`. `isSeven`: `7`, then four others;
- the fewest-runs flag count per entry (card `Fewest runs` values: 2, 3, 2, 2).

Do not assert the edge-value merge lint (phase 21). Write the registry line by reading the file (brief rule 21): read the
trait vocabulary at the top of the registry and the neighbouring lines, and declare only traits the file visibly has.

The verdict is clean (every case passes), so it sits in `happy-path/`. If a case does not pass, say so in `OPEN` instead
of moving the file.
