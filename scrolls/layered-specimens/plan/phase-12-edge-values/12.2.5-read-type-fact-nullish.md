## What to implement

Before the final `return { flavor: 'other', … }` of `readTypeFactLayerTransformer`, a type for which `readType.isNull()`
holds returns the same `other` fact with `nullish: 'null'`, and one for which `readType.isUndefined()` holds returns it
with `nullish: 'undefined'` (task 12.1.6). Read the flags, never `getText()`. A union reads its members through this
same function, so `number | null | undefined` gives two members with `nullish`. Update the PURPOSE block in one
sentence. The section 5.10 rule that `strictNullChecks` is always on is why these members exist at all.
