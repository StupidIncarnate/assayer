## What to implement

`deriveCasesTransformer` de-duplicates its feasible cases by a `signature` built from the exit, the arms and the whole
arrangement (the `seen` set in the `feasibleCases` step, "de-duplicated by (exit, arms, arrange)"). The arrangement
binds every parameter, read or not. So two buckets that differ only in a parameter the route never reads (`enabled
false` with `count 3`, and `enabled false` with `count 0`) give two cases where the cause rule gives one.

1. **What a route reads.** A parameter is read on a route when a leaf of a branch the route meets names it: its
   `operandParamName`, or a parameter its `operandFlow` refers to, or the returned comparison's leaf on a branchless
   route. A branch the route does not meet (`isBranchMetGuard` is false for its arms) reads nothing.
2. **The signature.** Build the signature from the exit, the arms, and only the bindings of the parameters the route
   reads, in parameter order. A binding of a parameter the route does not read leaves the signature unchanged.
3. **Which case stays.** The earliest case in enumeration order stays, with its full arrangement, so the case still
   binds every parameter it needs to be callable. Ordinary buckets come before pinned ones, so the ordinary case wins.
4. **A pinned edge value on an unread input** makes no case of its own: its signature equals the case it was built
   from (cause rule step 5 already gives an unread parameter no pins; this catches a pin on a parameter that a
   different route reads).

5. **An index read is steerable through its array.** The steerability gate (section 5.12) keeps a leaf with
   `operandPropertyPath` unsteerable, because an object member is driven only by the stub overlay. A path whose first
   segment is an index segment (`'[0]'`, task 12.1.7) on an array parameter is not an object member: task 12.6.2 pins
   the whole array for it. So such a leaf passes the first question of the gate ("is there an input a test case could
   set?"), the same as a plain parameter. Every other path keeps today's answer.
