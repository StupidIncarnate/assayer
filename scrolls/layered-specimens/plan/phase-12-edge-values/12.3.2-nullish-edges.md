## What to implement

For `predicateKind: 'non-nullish'` the satisfying arm today is "everything but `null`" and the violating arm is `null`.
Name the value classes the satisfying arm holds, so a `??` left arm lists "a normal value and a falsy value":

- Satisfying `members`: the truthy representative of each non-nullish scalar base member of the type, in member order,
  followed by each falsy point of those members (`0`, `''`, `false`, read from `edgeValueStatics`, never `null`).
  `string | undefined`
  gives `['abc123', '']`. `number | string | null` gives `[7, 'abc123', 0, '']`.
- Violating `members: [null]`, as today: the nullish point.
- A type with no scalar point (an object, an array) keeps `satisfying: {}` and `violating: { members: [null] }`.
- A type with no nullish member at all (`string`) keeps the reading it has today: the violating arm is empty
  (`members: []`), which marks the `??` right arm unreachable.

Read the representative from `representativeValueTransformer`, and the falsy points from `edgeValueStatics`.

Write the PURPOSE block in plain words: why the satisfying arm lists a value per class.
