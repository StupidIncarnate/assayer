## Contract

JSON holds neither `undefined` nor `NaN`, and the generated test file carries every arrange value as JSON. So two
special values travel as a tagged object:

```ts
{ $assayer: 'undefined' }   // the value undefined
{ $assayer: 'nan' }         // the value NaN
```

1. `arrangeValueContract` keeps accepting any JSON value. It gains one rule: the key `$assayer` is reserved. An object
   that has it must have exactly that one key, and its value must be `'undefined'` or `'nan'`. Anything else with that
   key fails with the message `The key '$assayer' is reserved for the special values 'undefined' and 'nan', and must be the only key of its object.`
2. Export `arrangeSpecialContract` from the same file: `z.object({ $assayer: z.enum(['undefined', 'nan']) })`, with
   its inferred type `ArrangeSpecial`. If lint refuses a second export in a contract file, define the same one-line
   object inline in `arrange-binding-contract.ts` and say so in `OPEN`.
3. In `arrange-binding-contract.ts`, the `param` binding's `value` becomes
   `z.union([representativeValueContract, arrangeSpecialContract])`. That is how a scalar parameter takes `undefined` or
   `NaN`. The `array` and `object` bindings need no change: their values are arrange values, so a property present as
   `undefined` (task 12.5.3) is `{ $assayer: 'undefined' }` nested inside.
4. Update both PURPOSE blocks and the USAGE lines with the two new values.

The existing `arrange-binding-contract.test.ts` stays valid because the new `value` type is a superset. The binding
union is tested end to end in task 12.2.1.

## Tests

In `arrange-value-contract.test.ts`:

- `VALID: {{ $assayer: 'undefined' }} => parses`
- `VALID: {{ $assayer: 'nan' }} => parses`
- `VALID: {{ label: { $assayer: 'undefined' } }} => parses as a nested property`
- `VALID: {[{ $assayer: 'nan' }]} => parses as an array item`
- `INVALID: {{ $assayer: 'null' }} => fails with the reserved-key message`
- `INVALID: {{ $assayer: 'nan', extra: 1 }} => fails with the reserved-key message`
- `VALID: {arrangeSpecialContract.parse({ $assayer: 'nan' })} => parses` and `INVALID: {arrangeSpecialContract.parse({ $assayer: 'x' })} => throws`
