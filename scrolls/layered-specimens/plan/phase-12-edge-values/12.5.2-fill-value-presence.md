## Read first

`fill-value-transformer.ts`: for an object type it builds only the REQUIRED properties (`owed`) and leaves every optional
property out.

## What to implement

Add an optional input `presence?: Readonly<Record<string, 'missing' | 'present-undefined' | 'value'>>`. It applies to the
properties of the object being filled at that level, keyed by property name. For an optional property named in `presence`:

- `'missing'`: left out, as today.
- `'present-undefined'`: present, with the value `{ $assayer: 'undefined' }` (task 12.1.2).
- `'value'`: present, with the value `fillValueTransformer` builds for the property's own type. If that type cannot be
  filled, the whole object is unfillable, as a required property would make it.

A property not named in `presence`, and every required property, behaves as today. A `presence` entry naming a REQUIRED
property or an undeclared one is ignored: this builder never removes a required property, and never adds one the type
does not declare. Nested objects are filled with no `presence`; the caller passes presence only for the level it reads.

The result for a non-object type ignores `presence`. Update the PURPOSE block in plain words: the three forms, and that
the caller decides which form a bucket needs. It is the one builder of the three forms for a whole-object fill; the object arranger (task 12.5.3) builds a single property's forms itself.

## Tests

For `{ label?: string; size: number }`:

- `VALID: {presence { label: 'value' }} => { label: 'abc123', size: 7 }` (use the real representatives; read `representative-value-statics`)
- `VALID: {presence { label: 'present-undefined' }} => { label: { $assayer: 'undefined' }, size: 7 }`
- `VALID: {presence { label: 'missing' }} => { size: 7 }`
- `VALID: {no presence} => { size: 7 }` (unchanged)
- `EDGE: {presence { size: 'missing' }} => { size: 7 }` (required property ignored)
- `EDGE: {presence { nope: 'value' }} => { size: 7 }` (undeclared property ignored)
- `ERROR: {presence { label: 'value' }, label's type is a callable} => undefined` (unfillable)
