## What to implement

`throughCallbackCasesTransformer` derives the callback's own cases over its element parameter and lays each steered
element value into the entry's array parameter as a single-element array. After row #5, the callback's own derivation
holds pinned cases for its element parameter (`item 0`, `item NaN`, `item -1`), some of which carry the tagged values
of task 12.1.2.

1. Lay every case of the callback's derivation into a one-item array, pinned ones included. A tagged value
   (`{ $assayer: 'nan' }`, `{ $assayer: 'undefined' }`) is laid in as it is: an `array` binding holding it, which task
   12.2.1's case interpreter turns into the real value.
2. Keep the existing `[]` case (the callback is `skipped`) and the existing many-item case, and make the many-item
   array hold one ordinary item per callback arm, in arm order, so one run takes every arm (README "The cause rule"
   step 3: `[2, 3]` for `item > 2`).
3. A callback case whose element parameter the callback never reads lays in no extra array: one case stands for it.
