## What to implement

1. Add one case to the reader. A `PropertyAccessExpression` whose symbol's value declaration is an `EnumMember` declared in
   the **same source file** reads as the member's constant value: `declaration.getValue()` from ts-morph (the checker's own
   evaluation), parsed through `representativeValueContract`. A string enum gives its string, a numeric enum its number, a
   `const enum` the same. A member whose value the checker cannot compute (`getValue()` is `undefined`) reads as nothing.
2. An enum declared in another file stays unread: the hermetic walk resolves an imported enum to nothing (section 5.10), and a
   cross-file read is a different mechanism. Decide "same file" by comparing the declaration's source file with the
   node's source file, not by a path.
3. A computed access (`Level['Low']`, `Level[name]`) stays unread. Only the property-access form is read.
4. Everything the function reads today stays as it is. Update the header comment: the new case, and the one-file limit.
