## Contract

```ts
armConditions: z.array(conditionNodeContract).optional(),
```

It is present only on a `switch` branch. It holds one condition per case arm, in the order of `arms`. The last arm, `default` or
`no-match`, has no entry: it holds when none of the case arms does.

## What to implement

Add the field and say in the header comment, in plain words, what it holds and why the last arm has none. Task 19.3.1 sets it.
Task 19.3.2 reads it. No code reads `BranchNode['kind']` in a `switch`, so no reader needs a change for the new field.
