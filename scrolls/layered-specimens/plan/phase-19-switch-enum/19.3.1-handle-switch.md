## Contract

Before this task every case clause is its own `switch` branch with the arms `then` and `else`. After it, a `switch` statement is
one branch.

**The branch the handler emits**, when the switch has at least one group:

| Field | Value |
|---|---|
| `coverageId` | `coverageIdTransformer({ scopePath, segment: 'switch:' + <discriminant projection> + ':' + <tokens> })`. The tokens are each group's labels' `caseToken`s joined with `\|`, the groups joined with `,`, and `,default` appended when a default clause exists. Structural only; never source text |
| `kind` | `'switch'` |
| `arms` | each group's `armLabel` in order, then `'default'` when the switch has a default clause, else `'no-match'` unless the switch is exhaustive (below) |
| `armConditions` | per group: one `eq` leaf per label (id `<coverageId>#leaf.<group>.<label>`), joined by a left-nested `or` when the group has several labels |
| `condition` | a left-nested `or` of the groups' conditions, in order. One group gives that group's condition |
| `guardPath` | `context.guardPath` |
| `startLine`, `endLine` | the statement's lines |

A leaf carries exactly what the leaf of a single case carries today: `operandParamName`, the environment fields
(`operandEnvVarName`, `operandEnvSteps`), `operandConstValue` for a welded discriminant, `operandType`, and the predicate `eq`
with the label's value, or `unrecognized` when the label has no readable value. A branch that holds an `unrecognized` leaf is
admitted undriven by `derive-cases`, as it is today.

**Exhaustive.** A switch with no default clause is exhaustive when the discriminant's type is a union whose every member is a
literal and each literal's value is one of the labels' values. An enum parameter is such a union. An exhaustive switch has no
`no-match` arm: no value takes it, and it must not become a route or an `unreachable-exit` lint.

**Guards and descents.**

- a group's clause statements descend under `{ branchCoverageId, arm: <armLabel> }` appended to the context's guard path;
- the default clause's statements descend under `{ branchCoverageId, arm: 'default' }`;
- a switch with **no group** (only a `default`, or no clause) emits no branch. The default statements descend under the
  enclosing guards, because nothing decides whether they run;
- completions: when the switch is in tail position and has a default clause, each group clause and the default clause whose
  last statement does not account for its ways out gets a guarded implicit exit, exactly as today, with the new guard steps.
  With no default clause the enclosing scope owns the one fall-off exit and this handler mints none (the existing comment in the
  file explains why a second probe would fire twice).

## What to implement

1. The handler, built on `desugared.groups`. Remove the per-clause branch loop and the per-clause `else` guard chain: one branch
   replaces them, and the arm labels replace `then`/`else`.
2. Header comment: the one branch, the arm labels, `armConditions`, exhaustive switches, and a switch with only a default.

## Tests

Parse real source with the helpers the file's test already uses. Compare whole results with `toStrictEqual`.

- `VALID: card switch/alone (mode: 'a' | 'b'; case 'a'; default) => arms ['case:a', 'default'], armConditions [eq a], clause guards case:a and default`
- `VALID: card switch/fallthrough (case 'a': case 'b': return; default) => arms ['case:a|b', 'default'], armConditions [or(eq a, eq b)]`
- `VALID: card switch/no-default (mode: 'a' | 'b' | 'c'; cases a and b) => arms ['case:a', 'case:b', 'no-match']`
- `VALID: an exhaustive switch ('a' | 'b' with both cases and no default) => arms ['case:a', 'case:b'] and no no-match`
- `VALID: card type/enum (Level.Low, Level.High, no default) => arms ['case:0', 'case:1']`
- `VALID: a switch on Number(process.env.CODE) with cases 1 and 2 and a default => arms ['case:1', 'case:2', 'default'], leaves carry the environment fields`
- `VALID: a welded discriminant (const mode = 'a') => the leaves carry operandConstValue`
- `VALID: a discriminant whose type is string with cases 'a' and 'b' and no default => arms ['case:a', 'case:b', 'no-match']`
- `VALID: a switch with only a default => no branch; the default statements descend under the enclosing guards`
- `VALID: a case label with no readable value (an imported enum member) => an unrecognized leaf and the arm label built from the token`
- `VALID: a switch nested in an if arm => guardPath carries the arm`
- `VALID: tail position with a default => one completion exit per clause whose last statement does not account for its exits`
- `VALID: tail position with no default => no completion exit`
- `EDGE: formatting immunity => single and double quotes, spacing and parentheses give identical coverage ids and conditions`
- `EDGE: the coverage id depends on every label (changing a label changes it) and on whether a default exists`
- `EDGE: a clause that falls into the next with statements stays its own group`
