## What to implement

1. The specimen holds the two cards' code with named entries:

   ```ts
   export const classify = (mode: 'a' | 'b' | 'c'): string => {
     switch (mode) {
       case 'a':
       case 'b':
         return 'early';
       default:
         return 'late';
     }
   };

   export const describeMode = (mode: 'a' | 'b' | 'c'): string => {
     switch (mode) {
       case 'a':
         return 'first';
       case 'b':
         return 'second';
     }
     return 'none';
   };
   ```

2. The test asserts what is bespoke to this file. Write every expected value by reasoning from the cards, never from a probe's
   output.
   - `classify`: one `switch` branch with arms `case:a|b` and `default`. Three every-route cases: `mode` `'a'` and `mode` `'b'`
     take `case:a|b`, `mode` `'c'` takes `default`. The fewest-runs set holds 2 cases, one of each arm.
   - `describeMode`: one `switch` branch with arms `case:a`, `case:b` and `no-match`. The union has a third member, so the switch
     is not exhaustive and the `no-match` arm exists. Three cases: `'a'`, `'b'`, and `'c'` for `no-match`. The fewest-runs set
     holds 3 cases.
   - no dark spot, no undriven entry, no gap and no lint: the file runs clean, so it sits under `happy-path/`.
