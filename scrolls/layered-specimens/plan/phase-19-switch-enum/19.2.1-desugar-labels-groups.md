## Contract

`DesugaredSwitch` gains `groups`, and keeps every field it has. The group shape is written inline, because a contract file
holds one export:

```ts
interface DesugaredSwitch {
  discName?: string;
  discNode: Node;
  caseInfos: SwitchCaseInfo[];   // unchanged: one per case clause
  groups: {                      // in source order
    clause: CaseClause;          // the clause that owns the statements the group runs
    labels: SwitchCaseInfo[];    // every case of the group, in source order
    armLabel: string;            // 'case:a' or 'case:a|b'
  }[];
  defaultClause?: DefaultClause;
}
```

**Grouping rule.** Walk the clauses in source order. A `case` clause with no statements joins the next clause's group, so
`case 'a': case 'b': return 'early';` is one group with two labels, and the group's `clause` is the last clause of the run
(the one with statements). A `case` clause with statements closes its group. A run of empty `case` clauses followed by
`default` joins the `default` clause: those labels form no group, because their values take the `default` arm. A trailing run
of empty `case` clauses with no clause after it closes as a group of its own. A clause that has statements but does not
end in `break`, `return`, `throw` or `continue` falls into the next clause's statements. That is not modelled: each clause
stays its own group, as before.

**Arm label.** `armLabel` is `'case:'` followed by the labels' values written with `String()` and joined with `'|'` in source
order. A label with no readable value (`literalValue` absent) is written with its `caseToken`, never with source text.
A string value that holds `'|'` is not escaped. It is a display label and nothing parses it.

## What to implement

1. **Labels.** The desugarer reads a `case` expression with its own check, `Node.isStringLiteral(...) || Node.isNumericLiteral(...)`.
   Replace that check with `readLiteralValueLayerTransformer({ node: caseExpr })`. A case on a same-file enum member reads its
   value, and a case on `true`, `false`, `null` or a parenthesized literal reads too, as in every other condition (section 5.12:
   the same syntax is read the same way everywhere). A case the reader cannot read keeps its current handling: `literalValue` is
   absent, the token is the structural projection of the expression, and the branch built from it carries an `unrecognized`
   predicate and is admitted undriven. Do not change `caseToken` or any other field.
2. **Groups.** Build `groups` from the clauses with the rule above, reusing the per-clause infos. `caseInfos` and `defaultClause` stay as
   they are. `branchCoverageId` on each `SwitchCaseInfo` is still computed. The handler of task 19.3.1 uses the switch's own id, so
   nothing reads that field afterwards. Leave the field and say so in your reply.
3. Update both header comments (the transformer's and the contract's).

## Tests

- `VALID: case 'a': case 'b': return 'x'; default: return 'y' => groups [{labels a, b; armLabel 'case:a|b'}], defaultClause set`
- `VALID: case 'get': return 1; case 'post': return 2; default: return 3 => groups [case:get, case:post]`
- `VALID: case 1: case 2: case 3: return 'low' => one group with three labels and armLabel 'case:1|2|3'`
- `VALID: case Level.Low (a same-file enum) => literalValue 0 and armLabel 'case:0'`
- `VALID: case 'get' and case 7 => unchanged output`
- `VALID: case true and case null => literalValue true and null`
- `VALID: a parenthesized literal ('get') => its value`
- `INVALID: case Sev.Low where Sev is imported => no literalValue, the token is the structural projection`
- `VALID: case 'a': then default (empty case before default) => no group; defaultClause set`
- `VALID: a trailing empty case with no clause after it => a group of its own`
- `VALID: a clause that falls into the next with statements => two groups`
- `VALID: a switch with only a default => groups []`
- `INVALID: case other where other is a parameter => armLabel 'case:' plus the structural token, no literalValue`
- `EDGE: every existing caseInfos, discName and defaultClause expectation passes unchanged`
