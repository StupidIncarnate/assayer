## What to implement

1. The specimen holds the card's code with a named entry:

   ```ts
   const checkLow = (count: number): void => {
     if (count < 0) {
       throw new Error('count must be 0 or more');
     }
   };

   const checkHigh = (count: number): void => {
     if (count > 100) {
       throw new Error('count must be 100 or less');
     }
   };

   export const guardCount = (count: number): string => {
     try {
       checkLow(count);
       checkHigh(count);
       return 'ok';
     } catch {
       return 'failed';
     }
   };

   export const guardFlag = (flag: boolean): string => {
     try {
       if (flag) {
         throw new Error('flagged');
       }
       return 'ok';
     } catch {
       return 'failed';
     }
   };
   ```

2. The test asserts what is bespoke to this file. Write every expected value by reasoning from the card, never from a
   probe's output.
   - `guardCount` has one branch, a `try` with arms `finishes` and `catches`. Its every-route set holds 5 cases: `finishes`
     for `count` 50, 0 and `NaN`, `catches` for `count` -1 and `catches` for `count` 101. Every case is driven. Assert the arm
     lists and the case count. Assert an arranged `count` only where a predicate pins it (-1 for the first throw point; a value
     above 100 for the second, which the cause rule gives as 101). The fewest-runs set of this entry holds 2 cases, one of each
     arm.
   - `guardFlag`: a `throw` under an `if` inside the try block is absorbed (tasks 16.3.1 and 16.3.3), so it owns no exit. The
     file has two branches, an `if` (arms `then`, `else`) and a `try` (arms `finishes`, `catches`). The `if`'s condition is the
     try's one throw point, so a route that takes `then` must take `catches`. Two every-route cases: `flag` false takes `else`
     and `finishes`, `flag` true takes `then` and `catches`. Both are driven and both are in the fewest-runs set.
   - `checkLow` and `checkHigh` are private functions the entry calls with its own parameter, so each is driven through
     `guardCount` as an entry with access `through-caller`. Each has one `if` with arms `then` and `else`, so two cases.
   - no dark spot, no undriven entry, no gap and no lint. The file runs clean, so it sits under `happy-path/`.
