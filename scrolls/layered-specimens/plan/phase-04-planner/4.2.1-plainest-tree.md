## Contract

`plainestTreeTransformer({ pieces, focus, typeArgument, position, fills }): PieceTree`

- `pieces`: every loaded piece, to find the container, the reader and the comparison by name.
- `focus`: the loaded piece the specimen is about.
- `typeArgument`: the type text that replaces the focus's type parameter. It is the focus's `defaultType` unless
  the caller varies the type axis.
- `position`: the position the focus takes (`statement`, `condition`, `exit`, `value`).
- `fills`: an optional `Record<slotName, PieceTree[]>` for the slots the caller already decided. Every other slot
  gets the plainest fill.

The transformer returns the tree only. It does not compute a level: tasks 4.3.1 and 4.4.1 do.

## What to implement

Read `layeredMatrixStatics.plainest` (task 1.1.6). Every position a specimen does not vary takes the plainest
choice (DESIGN.md step 3):

1. **Container.** The root is the `arrow-function` piece. A focus tagged `statement` goes in its block body. A
   focus tagged `expression` goes in the expression body when `position` is `exit`. When `position` is `value`,
   the focus goes in the `value` slot of the `log-call` host (task 3.1.16), `console.log(<focus>);`, followed by
   `return 'done';`, the shape of card `and/as-value`. Never put the focus in a `const` followed by a `return` of
   that const: Assayer reads a const that flows straight into a return as an exit (card `const/holds/ternary`),
   so that shape is the exit position, not the value position. A card that shows the `seen.push(...)` host
   (`ternary/as-value`) is a composition card and names `push-call` itself. When
   `position` is `condition`, the focus goes in the `cond` slot of an `if` that the block body holds. A focus
   tagged `parameter-list` goes in the `params` slot. A focus tagged `root` (the module) is itself the root.
2. **Hole.** Each unfilled expression hole gets a leaf with source `param`, named after the hole and typed by the
   hole's type with the type parameter replaced by `typeArgument`. A hole with an anchor gets a `literal` leaf of
   the anchor's value for that type.
3. **Statement slot.** An unfilled statement slot of the focus stays empty. The arm marker in the piece's code
   already writes the arm's own statement.
4. **Reader.** When the focus never branches in its position (no arms) and its code `binds` a name, call
   `readerLayerTransformer` (task 4.1.1) and append its node after the focus in the same block. When the layer
   returns `undefined`, add no reader.
5. **Parameters.** The container's `params` slot holds one `parameter` piece per `param` leaf in the tree, in the
   order the leaves are first read, each without a default.
6. **Level.** A `const` directly in the entry's body is level 0 (DESIGN.md step 1). The transformer places nothing
   deeper than the container, so every tree it returns is level 0.

## Tests

Build `LoadedPiece` objects in the test with the TypeScript factory. Assert the whole tree with `toStrictEqual`
after mapping each `piece` to its name (a test builds the expected tree by hand).

- `VALID: {focus: if, position: statement}` => card `if/alone`'s tree.
- `VALID: {focus: ternary, position: exit}` => card `ternary/alone`.
- `VALID: {focus: nullish, typeArgument: 'string | undefined', position: exit}` => card `nullish/alone`.
- `VALID: {focus: const, position: statement}` => card `const/in/arrow-body`, with the `gt` reader.
- `VALID: {focus: and, position: condition}` => card `and/as-condition` (an `if` whose `cond` holds the `and`).
- `VALID: {focus: and, position: value}` => card `and/as-value`'s tree: `console.log(ready && count > 2);` then
  `return 'done';`.
- `VALID: {focus: ternary, position: value}` => `console.log(flag ? … : …);` then `return 'done';`, never a `const`
  followed by a `return`.
- `VALID: {focus: gt}` where a hole has an anchor => that hole is a `literal` leaf.
- `VALID: {fills: {then: [..]}}` => the caller's fill replaces the plainest one.
- `EDGE: {focus: const, boundType: loop head}` => no reader.
- `EMPTY: {focus: module}` => the module is the root, with no container above it.
