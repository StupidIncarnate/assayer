## Contract

```ts
structureAxisVariantsTransformer({ pieces, focus, base }): {
  tree: PieceTree;
  axis: AxisValue;
  siblings: { file: string; tree?: PieceTree; reexport?: { name: string; from: string } }[];
  helpers: PlanHelper[];
  companion?: 'harness' | 'stub-agrees' | 'stub-missing-property' | 'stub-contradicts';
  compilerOptions?: Record<string, boolean>;
  callSequence?: number;
  sharedState?: 'module-let' | 'this-field' | 'closure-capture' | 'opaque-write';
}[]
```

`base` is the focus's alone tree (task 4.2.1). One entry per (declared axis, non-default value). Only the axes in the
focus's `axes` list are crossed.

## What each axis does

| Axis | Value | Change |
|---|---|---|
| `exit-kind` | `literal-union` | the entry returns `'big' \| 'small'` and a caller branches on it (card `return/literal-union-consumed`) |
| `exit-kind` | `promise` | the container becomes `async`, returning `Promise<string>` (card `return/promise`) |
| `exit-kind` | `void-side-effect` | the arms log instead of return, and the entry returns `void` (card `return/void-side-effect`) |
| `exit-kind` | `throw` | the then arm uses the `throw` arm kind, `throw new Error('then');` (card `return/throw`) |
| `file-boundary` | `sibling` | a `call` piece's helper moves to the sibling file `typeListStatics.files.sibling` and is imported (card `boundary/sibling`). A `property-read` piece's receiver type moves to a named type alias in `typeListStatics.files.types`, imported with `import type` |
| `file-boundary` | `barrel` | as `sibling`, plus `index.ts` with `reexport: { name, from: './is-big' }`. The entry imports from `./index` |
| `file-boundary` | `package` | the callee is `typeListStatics.packages.typed`: `import { isBig } from 'project-with-types';`, called `isBig(count)`, a function that ships its own types |
| `file-boundary` | `builtin` | the callee is a Node built-in, `import { isAbsolute } from 'node:path'` |
| `file-boundary` | `unresolvable-specifier` | the import path is `./missing`, which does not exist |
| `file-boundary` | `unresolvable-dynamic` | the entry is `async` and awaits `` import(`./${name}`) `` with `name` a parameter |
| `file-boundary` | `unresolvable-no-types` | the callee is `typeListStatics.packages.untyped`: `import { isBig } from 'project-without-types';`, a package that ships no usable types |
| `compiler-options` | `no-unchecked-indexed-access`, `exact-optional-property-types` | `compilerOptions` set to that flag. A piece crosses this axis only when it declares it. `exact-optional-property-types` applies only to a piece that reads an optional property |
| `companion-files` | `harness` | `companion: 'harness'`. Only for a base whose entry takes a callable or `unknown` parameter (a gap) |
| `companion-files` | `stub-agrees`, `stub-missing-property`, `stub-contradicts` | `companion` set. Only for a base with an object parameter. `stub-contradicts` is a known value: Assayer reports a P1 build error at the consumption point (task 6.1.6) |
| `shared-state` | `module-let`, `this-field`, `closure-capture` | the `let` moves to the module top level, becomes a class field read through `this`, or is declared in the entry and written by a no-parameter closure the entry returns. `callSequence` is `layeredMatrixStatics.callSequence.maxCalls` |
| `shared-state` | `opaque-write` | the entry writes `calls = <typeListStatics.opaqueWrite.text>` before the reader, so the reader depends on a value no analysis can fold. It stays undriven. No named state is generated (DESIGN.md decision "Named states") |

The two packages come from `typeListStatics.packages` (task 4.1.3). The transformer never names a package itself.

A value that does not apply to the base yields no entry (a companion with no gap and no object parameter, a
`compiler-options` value on a piece that does not declare it). `structureAxisVariantsTransformer` applies these
"only for" rules as the last step before it returns, as one `.filter` over its candidate entries, and its PURPOSE
block lists them. They live nowhere else.
