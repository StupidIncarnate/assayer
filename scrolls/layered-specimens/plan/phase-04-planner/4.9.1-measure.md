# 4.9.1 Operator: record the measured matrix size

- **Phase:** 4. **Row:** #9, alone.
- **Depends on:** 4.8.1.
- **Who:** the operator. No worker. It writes only the plan README.
- **Covers:** DESIGN.md decision "Matrix size" ("Every count or generate run reports the total, broken down per
  axis and per layer, so the user can watch it grow"), README "Measured sizes". There is no cap, so this task never
  stops the run.

## Files

| Action | Path | Folder type |
|---|---|---|
| edit | `scrolls/layered-specimens/plan/README.md` | plan document (markdown) |

The operator writes the measured count into README "Measured sizes". No worker is dispatched.

## Steps

1. Run `npm run generate:specimens -- --count` in the worktree. It always exits 0.
2. Copy its whole output into README "Measured sizes", under a heading that names the date and the commit.
3. Mark this task done and continue to phase 5, whatever the total is.

## Done when

README "Measured sizes" holds the output of `--count`.
