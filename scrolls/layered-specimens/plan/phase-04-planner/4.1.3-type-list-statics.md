## What to implement

Keep every existing key of `typeListStatics` (`number`, `string`, `boolean`, each with `known`, `samples`, `env`,
`external`, `externalArray`), because the old pipeline still reads them. Add these groups, each with a header
comment saying who reads it:

```ts
literalUnion: { type: "'a' | 'b'", members: ['a', 'b'], known: 'a' },
helpers: {
  enum: { name: 'Level', text: 'enum Level { Low, High }', members: ['Low', 'High'] },
  discriminatedUnion: {
    name: 'Shape',
    text: "type Shape = { kind: 'circle'; radius: number } | { kind: 'square'; side: number };",
  },
},
switchLabels: { number: 7, string: 'xyz' },
neighbourSuffix: 'x',
opaqueWrite: { text: 'Math.round(Math.random() * 10)', variable: 'calls' },
files: { sibling: 'is-big.ts', barrel: 'index.ts', types: 'types.ts' },
packages: {
  typed: { name: 'project-with-types', importName: 'isBig' },
  untyped: { name: 'project-without-types', importName: 'isBig' },
},
```

- `literalUnion`: the type a `type` axis value `literal-union` writes (task 4.3.2).
- `helpers`: the helper text the `enum` and `discriminated-union` type values add to a plan (task 4.3.2). The enum
  helper matches card `type/enum`, the union helper matches card `type/discriminated-union`.
- `switchLabels`: the label a generated `switch` uses per base type (`case 7`, `case 'xyz'`), as the "Type
  variation" table gives it. The prediction engine derives the no-match value from the label (task 6.1.1).
- `neighbourSuffix`: the string appended to a string literal to make its neighbour (`'xyz'` gives `'xyzx'`), read by
  task 6.1.1.
- `opaqueWrite`: the statement text task 4.3.3 writes before the reader for the shared-state value `opaque-write`.
  The result of `Math.random()` is a value no analysis can fold, so the reader stays undriven.
- `files`: the file names the file-boundary values `sibling`, `barrel` and a moved type alias use.
- `packages`: the two packages the file-boundary values `package` and `unresolvable-no-types` import (task
  4.3.3). Both are hand-written workspace packages of the smoke repo, named for what they show (tasks 9.1.7 and
  9.1.8): `smoke-repo/packages/project-with-types` ships `index.js` with its own `index.d.ts`, and
  `smoke-repo/packages/project-without-types` ships `index.js` and no types. Each exports
  `isBig(value: number): boolean`. A specimen writes `import { isBig } from 'project-with-types';`.
