## What to implement

Add one `describe('count mode')` beside the existing ones. Add:

- `VALID: {argv: [--count, --piece=if]} => exit 0 and a first line that names a count`. Split `output` on `\n`,
  take the first line, and assert it against the anchored regex
  `/^specimens: \d+, estimated \d+ minutes for the whole generated suite$/u` with `toMatch`. Assert `exitCode` with
  `toBe(0)`.
- `VALID: {argv: [--count, --piece=if]} => the blocks follow`. Assert that the output contains the headings
  `by axis:`, `by layer:`, `by focus:`, `by top folder:` and a line starting `by today id:`, each with `toMatch`
  on its own anchored multiline regex.

Task 4.7.1 already updated the expected accepted-flags string in the refusal test, so leave that alone. The test
asserts shape, never exact counts, because phases 2 and 3 and later core phases change the matrix.
