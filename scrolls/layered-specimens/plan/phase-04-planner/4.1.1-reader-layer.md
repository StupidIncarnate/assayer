## Contract

`readerLayerTransformer({ pieces, bound, boundType, shape, isLoopHead }): PieceTree | undefined`

- `pieces`: every loaded piece (to find `if`, `gt`, `eq`, `property-read` by name).
- `bound`: the name a non-branching piece declares (`size` in `const size = count`).
- `boundType`: the type text of that name (`number`, `string`, `boolean`, `'a' | 'b'`, `Level`).
- `shape`: `'value'` for a plain value, `'object-literal'` when the piece holds an object literal (the card
  `const/holds/object`), `'other'` for a function, class instance or array.
- `isLoopHead`: true when `bound` is the head of a `for…of`, `for…in` or `for` loop.

It returns a `PieceTree` node (an `if` piece) that the caller appends after the piece in the same block, or
`undefined` when no reader can follow the value.

## What to implement

Read `layeredMatrixStatics.plainest` and `layeredMatrixStatics.readerLiteral` (task 1.1.6). Return:

1. `undefined` when `isLoopHead` is true. A loop head is written once per pass, so Assayer cannot follow it
   (DESIGN.md step 5).
2. `undefined` when `shape` is `'other'`.
3. For `boundType` `number` or `string`: the `if` piece whose `cond` slot holds the `gt` piece. The `gt` node's
   `value` hole is a `binding` leaf named `bound`, its `limit` hole is a `literal` leaf of
   `readerLiteral[boundType]`.
4. For `boundType` `boolean`: the `if` piece whose `cond` slot holds a `binding` leaf named `bound` directly. `gt`
   does not accept a boolean.
5. For a literal union or an enum (`boundType` holds quotes, `|`, or names a helper enum): the `if` piece whose
   `cond` holds the `eq` piece, `value` the `binding` leaf, `limit` a `literal` leaf of the first member.
6. For `shape` `'object-literal'`: the same as rule 3 or 4, but the `value` hole holds a `property-read` node over
   the binding leaf, reading the object's first property whose type is `number`, `string` or `boolean`. When the
   object has none, return `undefined`.

The `if` node's `then` and `else` slots stay empty. The renderer writes each arm's own statement (task 5.1.1).

## Tests

Build `LoadedPiece` objects in the test with the TypeScript factory (`if`, `gt`, `eq`, `property-read`) and assert
the whole tree with `toStrictEqual`, mapping each `piece` to its name.

- `VALID: {boundType: number} => if over gt with literal 2`
- `VALID: {boundType: string} => if over gt with literal 'm'`
- `VALID: {boundType: boolean} => if over the binding leaf`
- `VALID: {boundType: "'a' | 'b'"} => if over eq with literal 'a'`
- `VALID: {shape: object-literal, first property size: number} => if over gt over property-read of size`
- `EMPTY: {isLoopHead: true} => undefined`
- `EMPTY: {shape: other} => undefined`
- `EMPTY: {shape: object-literal, no primitive property} => undefined`
