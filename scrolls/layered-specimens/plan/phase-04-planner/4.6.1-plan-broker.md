## Contract

`specimensPlanBroker({ declarationsRoot, only }): { plans: PiecePlan[]; report: CountReport }`

`only` is `{ piece?: string[]; axis?: string[] }`.

## What to implement

1. Load with `piecesLoadBroker` (task 2.3.1).
2. Check `only` against what loaded. An unknown piece throws
   `The piece 'nope' matches no piece declaration. The known names are: <sorted names>. Name one of them, or add declarations/pieces/nope.piece.ts.`
   An unknown axis throws
   `The axis 'nope' is not an axis. The known axes are: <sorted names from axisStatics>. Name one of them.`
3. Plan with `piecePlanTransformer` (task 4.5.1).
4. Count with `planCountTransformer` (task 4.4.2), passing an empty `todayIds` map and `refused: 0`.

## Tests

The proxy stages the loader's file reads (one piece, one composition file) the way `piecesLoadBroker`'s own proxy
does.

- `VALID: {only: {}}` => the plans of one piece, and a report whose `total` equals the plan count.
- `VALID: {only: {piece: ['if']}}` => only plans involving `if`.
- `VALID: {only: {axis: ['type']}}` => only plans varying `type`.
- `INVALID: {only: {piece: ['nope']}}` => the unknown-piece message, word for word.
- `INVALID: {only: {axis: ['nope']}}` => the unknown-axis message, word for word.
