## Contract

`piecePlacementsTransformer({ pieces, focus, typeArgument }): Placement[]` where

```ts
type Placement = {
  tree: PieceTree;
  level: number;
  kind: 'alone' | 'position' | 'placed' | 'holds' | 'sequence';
  segments: string[];
  position: Position;
};
```

## What to implement

**Level counting (DESIGN.md step 1).** A piece's level is the number of pieces holding it. A holder is a container
such as an `if` or a `for…of`, or an expression such as a ternary. Neither the module nor the entry itself counts as
a holder. The entry is the exported arrow function, function or class that a test reaches. A method body is a slot
of its class or object literal, not a piece of its own, so a method of an entry class counts as the entry's own
body, and a method of an object literal adds that object as one holder. So a `const` directly in the entry's body is
level 0, a `const` inside an `if` in that body is level 1, and the innermost of three nested ternaries is level 2.
Read the caps from `layeredMatrixStatics.levels`: `cap` (2) for most pieces, `objectAndArrayCap` (3) when the focus
or one of its holders is an object literal or an array literal.

For one focus piece, list:

1. **Alone.** `plainestTreeTransformer` with the focus's default position (`statement` for a statement piece,
   `exit` for an expression piece). Level 0, kind `alone`, no segments.
2. **Positions.** When the focus crosses the `position` axis, one entry for each position it declares arms or
   `leaves` for, other than the default. Kind `position`. A `condition` entry puts the focus in the `cond` slot of
   an `if`.
3. **Placed.** For each host piece and each host slot that accepts one of the focus's tags, the focus in that slot,
   the host placed the plainest way. A host slot whose position is `inherit` takes the host's own position. Then the
   same one holder up: a second host holding the first, up to the cap. The module root is level 0 and its segment is
   `module`. Kind `placed`, `segments` the slot segments from the outermost host.
4. **Holds.** For each slot of the focus, each other piece that fits it, at level 1 (DESIGN.md: "The last three
   cards go the other way: they fill the `const`'s own slot"). Kind `holds`, `segments` the child piece's folder.
5. **Sequence.** When the focus branches, two copies one after another in the container body, each reading its own
   parameter (card `ternary/sequence`). Kind `sequence`.

A host never holds itself in the same slot more than the cap allows. `ternary.else › ternary.else › ternary` is the
level-2 case (card `ternary/in/ternary-else/ternary-else`). Sort the output by `segments`, then `position`.

Return every entry. This transformer never trims by count: the matrix has no cap (DESIGN.md decision "Matrix size").

## Tests

Use small hand-built `LoadedPiece` sets (`if`, `ternary`, `gt`, `const`, `arrow-function`, `module`,
`object-literal`, `for-of`).

- `VALID: {focus: const} placed in if.then` => segments `['if-then']`, level 1.
- `VALID: {focus: const} in for-of body in if.then` => segments `['for-of-body', 'if-then']`, level 2.
- `VALID: {focus: const} at the module root` => segments `['module']`, level 0.
- `VALID: {focus: const} directly in the entry body` => the `alone` entry is level 0.
- `VALID: {focus: ternary} in ternary.else twice` => level 2.
- `VALID: {focus: const} in an object-literal method inside an if` => level 2 (the object and the if hold it).
- `EDGE: {focus: object-literal}` reaches level 3; `{focus: if}` stops at level 2.
- `VALID: {focus: const}` holds lists `ternary`, `arrow-function`, `object-literal`, each at level 1.
- `VALID: {focus: and}` position entries `condition` and `value` beside the default `exit`.
- `VALID: {focus: ternary}` sequence entry holds two ternaries.
- `EMPTY: a piece whose tag no slot accepts` => only its `alone` entry.
