## Contract

`planCountTransformer({ plans, todayIds, refused }): CountReport` (task 1.3.3).

- `todayIds`: a map from a folder to its today ids. Until task 9.8.1 fills it from a dry-run build, the caller
  passes an empty map and the `today` list is empty.
- `refused`: the number of plans TypeScript or the prediction engine refused. Plan-only counts pass `0`.

There is no budget and no `overBudget` field.

## What to implement

Count by:

- `total`: the number of plans.
- `byFocus`: the plan's `focus`.
- `byAxis`: the axis name only (`type`, `file-boundary`, `position`), values summed. A plan with no varied axis
  (an alone specimen, a card) counts under `alone` or `card`.
- `byLayer`: the plan's `level` as text (`0`, `1`, `2`, `3`).
- `byTopFolder`: the first segment after `src/` in the plan's folder.
- `today`: for each today id, the number of plans whose folder lists it.
- `refused`: the input.
- `estimatedMinutes`: `total` times `axisStatics.estimates.secondsPerTest`, divided by
  `axisStatics.estimates.workers`, divided by 60, rounded up.

Every list is sorted by name, then count.

## Tests

- `VALID:` three plans count correctly in every grouping.
- `VALID:` a card plan counts under `card`.
- `VALID:` `today` lists an id for the two plans whose folders carry it.
- `VALID:` `estimatedMinutes` rounds up (for example 9 plans at 8 seconds on 4 workers is 1 minute).
- `EMPTY:` no plans gives every list empty and `total` 0.
