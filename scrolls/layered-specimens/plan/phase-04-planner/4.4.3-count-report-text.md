## Contract

`countReportTextTransformer({ report }): string` turns a `CountReport` into the text `--count` prints.

## What to implement

The text has these parts, in this order, joined with `\n`:

1. First line: `specimens: <total>, estimated <estimatedMinutes> minutes for the whole generated suite`.
2. When `refused` is above 0, the line `refused by TypeScript or the engine: <refused>`.
3. One block each for `by axis`, `by layer`, `by focus`, `by top folder`. A block is a heading line `<heading>:`,
   then one line per item, `  <name>: <count>`, in the report's order. A blank line separates blocks.
4. The block `by today id` in the same form, listing each id and its count. When the report's `today` list is empty,
   the block is the single line `by today id: computed by a full generation (--count after task 9.8.1)`.

There is no budget line.

## Tests

- `VALID:` the full text of one small report with `toBe`, with a non-empty `today`.
- `VALID:` an empty `today` prints the single `computed by a full generation` line.
- `VALID:` a report with `refused` 2 prints the refused line, and one with `refused` 0 does not.
- `EMPTY:` a report with every list empty and total 0 prints the first line and the headings only.
