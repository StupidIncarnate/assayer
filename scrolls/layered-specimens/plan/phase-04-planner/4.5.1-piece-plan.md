## Contract

`piecePlanTransformer({ pieces, compositions, only }): PiecePlan[]`, sorted by folder. `only` holds the optional
`piece` and `axis` filters from the command line.

## What to implement

For each piece instance (task 2.1.2) that `only.piece` does not leave out:

1. Placements (task 4.3.1), each named with `specimenPathTransformer` (task 4.1.2).
2. Value axis variants (task 4.3.2) and structure axis variants (task 4.3.3), each named the same way. A shim is
   never placed (it loads as a piece with origin `shim`, task 2.2.1).

Then iterative shapes (task 4.3.4) once for all branching pieces. Then every composition card with a tree
(task 4.4.1). A `sameAs` card adds no plan, and its `sameAs` must name a card that has a tree, else:
`the composition card '<folder>' is the same as '<other>', which is not a card with a tree.`

`only.axis` keeps only plans whose axis is named. `only.piece` keeps only plans whose `focus` or any piece in the
tree is named.

Two plans with one folder are refused:
`two specimens share the folder '<folder>': <focus a> (<axis a>) and <focus b> (<axis b>). Give one of the pieces a different folder or slot segment.`

A card's folder that a systematic plan also produces is not a clash. The card wins and the systematic plan is
dropped, because the card is the hand-checked one. Task 9.2.1 also drops a systematic specimen whose rendered source
equals a card's.

There is no cap on the number of plans.

## Tests

On small hand-built pieces and one card:

- `VALID:` the folders of a one-piece matrix.
- `VALID:` `only.piece` narrows it.
- `VALID:` `only.axis` narrows it.
- `VALID:` a card and a systematic plan with one folder keep the card.
- `VALID:` a `sameAs` card adds no plan.
- `ERROR:` a clash, message word for word.
- `ERROR:` a `sameAs` naming a card without a tree, message word for word.
- `EMPTY:` no pieces and no cards gives `[]`.
