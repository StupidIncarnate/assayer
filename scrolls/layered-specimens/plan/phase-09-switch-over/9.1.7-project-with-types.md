These files are hand-written, not generator output. `smoke-repo/package.json` already lists `packages/*` as workspaces, so
the smoke repo picks the package up with no edit there. The name says what the package shows: a cross-package import
whose package ships its own types, which Assayer reads from the `.d.ts` file and never runs.

## What to implement

1. `package.json`: `{ "name": "project-with-types", "version": "1.0.0", "private": true, "main": "index.js", "types": "index.d.ts" }`.
2. `index.js` (CommonJS): `exports.isBig = (value) => value > 2;`.
3. `index.d.ts`: `export declare const isBig: (value: number) => boolean;`.

Task 4.1.3 names this package in `typeListStatics.packages.typed`, and task 4.3.3 writes specimens that run
`import { isBig } from 'project-with-types';`.
