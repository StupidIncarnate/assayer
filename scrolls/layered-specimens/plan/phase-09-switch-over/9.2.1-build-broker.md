## Contract

`specimensBuildBroker({ declarationsRoot, cacheRoot, fresh }): Promise<BuildResult>` (task 9.1.6). `cacheRoot` is the repo-relative folder `runScaleStatics.cache.folder` joined onto the repo root. `fresh` skips cache reads and still writes.

The broker is asynchronous for one reason: the capacity lease must beat while generation works (task 8b.2.1), and a beat needs the event loop. So the broker awaits between plans, as step 4 says.

## What to implement

1. Take one capacity lease: `capacityLeaseBroker({ label: lease.labels.generate, peakMB: workers.peakMBPerWorker })`. Do all later steps inside a `try`, and call `release()` in the `finally`.
2. Plan with `specimensPlanBroker` (task 4.6.1).
3. Render each plan with `specimenFilesTransformer` (task 5.4.1). Drop a systematic plan whose rendered `entry.ts` equals a card's `entry.ts`: the card is the hand-checked one.
4. Compute each plan's cache key with `cacheKeyTransformer` (task 8b.1.3), with the fingerprint from `fingerprintReadBroker` (task 8b.2.2). Unless `fresh`, read each key with `generationCacheReadBroker` (task 8b.2.3).
   - `hit`: use the cached `verdict` and `prediction`, parsed with their contracts.
   - `corrupt`: write `generation cache: <reason> Recomputing.` to stderr, then treat it as a miss.
   - `miss`: collect the plan.
5. Typecheck all collected plans with one call of `specimensTypecheckBroker` (task 5.2.2). A plan TypeScript refuses is refused with TypeScript's reason. Then, for each remaining collected plan one at a time, predict with `specimenPredictBroker` (task 6.4.1), write the cache entry with `generationCacheWriteBroker` (task 8b.2.4), and `await` a turn of the event loop (`setImmediate` from `#gateway/node/setImmediate`) so the lease beats. A prediction of `{ refused }` refuses the plan with that sentence.
6. A refused plan (from TypeScript or the engine) goes to `REFUSED.md` through `refusedReportTransformer` with its reason, and gets no other file.
7. For each kept plan: the header (task 8.1.2) built once as a draft to learn its line count; every line in the report moved down by that count; the header built again with the moved report; `entry.ts` is the header plus the body; `entry.test.ts` from `specimenTestFileTransformer` (task 8.2.2) with the moved report and today ids; the manifest row from `specimenEntryTransformer` (task 9.1.1).
8. Add `specimen-manifest.json`, `REFUSED.md` and `EXPECTED-FAILURES.md` (task 9.1.2).
9. Build the count report (task 1.3.3) from the kept plans, with `today` counts per id and the `refused` count.
10. Sort every list by path, exactly as the old broker did.

The output of a cache hit equals a fresh run's, because the key covers every input of the computation.

## Tests

The proxy stages a declarations folder of two pieces and one card, and mocks the lease, cache and typecheck brokers.

- `VALID:` the full file list and manifest.
- `VALID:` a refused plan lands in `REFUSED.md` only.
- `VALID:` a systematic duplicate of a card is dropped.
- `VALID:` a today id makes `it.failing` and an `EXPECTED-FAILURES.md` entry.
- `VALID:` a cache hit does not call the typecheck or predict brokers.
- `VALID:` `fresh` ignores a hit and still writes.
- `INVALID:` a corrupt entry writes the stderr line and recomputes.
- `ERROR:` the lease is released when a plan throws.
