## Contract

`buildResultContract`: a branded object `{ files: GeneratedFile[]; count: CountReport }`, with `BuildResult` its inferred type. `files` holds every file a generation writes: the source files, `specimen-manifest.json`, `REFUSED.md` and `EXPECTED-FAILURES.md`. `count` is the count report (task 1.3.3) with its `today` and `refused` fields filled.

The old `generation-result` contract stays until task 9.7.4, because the old pipeline still uses it. The write and check brokers read only `.files`, so they accept either (tasks 9.1.3 and 9.1.4).

## Tests

- `VALID:` a result with one file and a count parses.
- `INVALID:` a file with an empty `relPath` is rejected.
- `INVALID:` a result with no `count` is rejected.
- `EMPTY:` no files parses.
