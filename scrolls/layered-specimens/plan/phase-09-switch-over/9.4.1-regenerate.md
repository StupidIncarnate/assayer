# 9.4.1 Operator: regenerate and commit

- **Phase:** 9, build, switch over and clean up. **Row:** #4, alone.
- **Depends on:** row #3 (left uncommitted: this task commits it).
- **Model:** operator (no worker).
- **Covers:** README "How to run the plan" (row 9.4 is the switch-over commit), "Output layout".

| Action | Path | Folder type |
|---|---|---|
| regenerate | everything the generator writes under `smoke-repo/packages/syntax-repository/` and `smoke-repo/assayer/stubs/` (committed with rows 9.3 and 9.4) | generated output, never edited by hand |

No worker is dispatched.

## Steps

0. `npm install --prefix smoke-repo`, so `smoke-repo/node_modules` links `project-with-types` and `project-without-types` (tasks 9.1.7, 9.1.8). Run it again whenever a fresh worktree has no `smoke-repo/node_modules`.
1. `npm run generate:specimens -- --fresh`. It rewrites the smoke repo and prints the count report. Read the count, and read `REFUSED.md` for refusals that look wrong.
2. `npm run typecheck:generated`. It must exit 0.
3. `npm run ward -- --changed` with `timeout: 600000`. The `--check` integration test passes against the new output.
4. `npm run generate:specimens -- --check`, with no `--fresh`. Step 1 wrote the cache, so this run reads every specimen
   from the cache. It exits 0. This proves a cache hit writes the same bytes a fresh generation wrote.
5. `npm run generate:specimens -- --check --fresh`. It exits 0. This proves a fresh run still matches the committed
   output.
6. **Rows 9.3 and 9.4 are committed together.** Row 9.3 is never committed alone: its `--check` integration case fails
   until step 1 regenerates the smoke repo, so a row-9.3 commit would be red. After step 5, stage the explicit paths of
   rows 9.3 and 9.4 (the generator changes of tasks 9.3.1 to 9.3.4 and the whole regenerated smoke repo), mark both rows
   in the README tracker, and make one commit. Ward fails while the generator and its output differ, so they never land
   apart.

## Done when

One commit holds rows 9.3 and 9.4, and steps 2 to 5 exit 0.
