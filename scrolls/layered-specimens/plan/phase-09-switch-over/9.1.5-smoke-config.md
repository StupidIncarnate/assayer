## What to implement

1. In `package.json`, add `"exports": { "./*": "./src/*/entry.ts" }`. It declares each specimen's `entry.ts` as an entry point, so a specimen's `entry` export is never reported as "never read" (DESIGN.md decision "Does never read apply to exports?"). Also add `"dependencies": { "project-with-types": "*", "project-without-types": "*" }`, the two workspace packages tasks 9.1.7 and 9.1.8 create. Keep `name`, `version`, `private` and `scripts.typecheck`.
2. In `tsconfig.json`, add `"exclude": ["src/boundary/*/unresolvable-*/**"]` and a comment above it that says: those specimens import something that cannot resolve on purpose; Assayer reports the P1 build error; `typecheck:generated` would otherwise fail with TS2307 or TS7016. Keep `include: ["src/**/*"]` and every other key. (`tsconfig.json` accepts comments.)
