## What to implement

**The value rule.** For each branch leaf that reads the property, the demand holds the ordinary value of each of
the leaf's two arms, and nothing else: the first value `domainValuesTransformer` realizes for that arm's domain, the
same value `cause-arrange` gives that arm's ordinary case (README "The cause rule" step 1: `count > 2` gives `3` for
`then` and `2` for `else`). An arm whose domain names no point of its own takes `edgeValueStatics.plain` for the
property's type (task 26.1.4). No edge value and no extra representative value is added. Values are de-duplicated and
sorted, as today.

Three more forms, each written onto the demand fields of task 26.1.1:

- **Left out.** A leaf that reads an optional property's presence (`has-property`, or a truthiness leaf on an
  optional property) records `missing: true` for the arm the property's absence takes, in place of a value (card
  `nullable/optional-property-in`: `'x'` for then, missing for else).
- **An array property.** A property whose type is an array records `arrays`: one inner list per arm, the empty array
  for a `skipped` arm and the one-item array holding the item's ordinary value for each arm of the item's own branch
  (card `deep/array-of-objects-2`: `[]`, `[100]`, `[101]`).
- **An object member.** A property or parameter whose type has an object member records `objects`: the object member
  built from its properties' demands, each property no branch reads at `edgeValueStatics.plain` for its type (card
  `edge/typeof-object`: `{ size: 1 }`), and `values` holds the ordinary values of the other members (`'a'`).

## Tests

- `VALID: {count: number, leaf count > 2} => values [2, 3]` (card `reach/object-property`)
- `VALID: {country: string, leaf country === 'NZ'} => values ['NZ', <the else value>]` and the else value is the one `domainValuesTransformer` realizes first
- `VALID: {label?: string, has-property leaf} => values ['x'], missing true` (card `nullable/optional-property-in`)
- `VALID: {prices: number[] read by a loop whose item has price > 100} => arrays [[], [100], [101]]`
- `VALID: {a property no leaf reads} => unknown, as today`
- `EDGE: {two leaves on one property} => the union of their arm values, sorted`
