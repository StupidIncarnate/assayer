## What to implement

Add `unset: z.literal(true).optional()` to `envStubContract`: one arm of a branch is taken only when the variable is
not set (card `known/env-two-files`: `STRICT` is "unset for else"). Unset is not a value, so it is a flag beside
`values`. Say so in the PURPOSE block. The stub keeps its default.
