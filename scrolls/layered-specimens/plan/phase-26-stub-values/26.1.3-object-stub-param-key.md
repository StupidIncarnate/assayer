## What to implement

Today an object stub always names a declared type: its key is `<definitionRelPath>#<TypeName>`. A parameter whose
type is written inline (`box: { count: number }`) has no type name, so it has no stub, and the stub values Assayer
derives for it are never written. Add one optional field:

```ts
param: z.object({
  entry: z.string().min(1).brand<'ObjectStubParamEntry'>(),
  name: z.string().min(1).brand<'ObjectStubParamName'>(),
  element: z.literal(true).optional(),      // the stub is for each element of an array parameter
}).brand<'ObjectStubParam'>().optional(),
```

A stub with `param` is keyed `<relPath>#<entry>.<name>` (`src/reach.ts#entry.box`), with `[]` appended when
`element` is set (`src/loop.ts#entry.items[]`), and its `typeName` is that key's part after `#`. Say in the PURPOSE block that a human correction under `assayer/stubs/objects/` still keys on a declared type only.

## Tests

- `VALID: {key 'src/a.ts#entry.box', param { entry: 'entry', name: 'box' }} => parses`
- `VALID: {key 'src/a.ts#entry.items[]', param { entry: 'entry', name: 'items', element: true }} => parses`
- `INVALID: {param { entry: '', name: 'box' }} => throws`
- `VALID: {the stub, keyed on a type} => parses without param`
