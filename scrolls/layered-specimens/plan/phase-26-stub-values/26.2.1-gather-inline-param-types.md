## What to implement

`gatherTypeReadsTransformer` groups branch leaves by the declared type their root parameter names
(`leaf.operandTypeRef`). A parameter whose type is written inline has no type name, so its reads are dropped and its
stub values are never derived. Add a second kind of group, after the declared-type groups:

1. For each blob, each function its analysis lists, and each parameter of that function whose type descriptor is an
   object, an array of objects, or a union with an object member, and that has no `typeRef`: one group.
2. The group's `typeName` is `<entry>.<param>` (`entry.box`), with `[]` appended for an array of objects
   (`entry.items[]`). `definitionRelPath` is the blob's `relPath`. `declaredType` is the parameter's own object
   descriptor (the element's, for an array; the object member's, for a union). `readers` is `[relPath]`.
3. Its `leaves` are the leaves of that function whose `operandParamName` is the parameter and that carry no
   `operandTypeRef`. For an array of objects, the leaves are the ones that read the loop or callback item that the
   walk records as an element of that parameter (`operandParamName` is the item; read how `handle-loop` and
   `follow-calls` name it before writing, and name in your reply the field you used).
4. The group carries `param: { entry, name, element? }` (add this optional field to `gatherTypeReadsContract`, same
   shape as task 26.1.3's).

Groups keep their sort order: declared-type groups first, then parameter groups by `relPath`, then `typeName`.

## Tests

- `VALID: {entry(box: { count: number }) with if (box.count > 2)} => one group typeName 'entry.box', param { entry, name: 'box' }, the leaf`
- `VALID: {entry(items: { count: number }[]) with a for-of over items and if (item.count > 2)} => one group 'entry.items[]' with element true`
- `VALID: {entry(value: { size: number } | null | string)} => one group 'entry.value'`
- `EDGE: {a parameter typed with a declared type} => only the declared-type group, as today`
- `EMPTY: {a parameter of a scalar type} => no parameter group`
