## What to implement

`gatherEnvReadsTransformer` returns, per variable, the literals its branch leaves compare against, and
`envGuessedValuesTransformer` turns them into a guessed list. Add to each group two fields the stub-graph broker
writes in task 26.3.1:

- `values`: for each env leaf of the variable, the ordinary value of each of the leaf's arms, as the string the
  variable must hold for it: run the leaf's `operandEnvSteps` backwards with `envEncodeTransformer`, from the first
  value `domainValuesTransformer` realizes for the arm's domain (card `const/in/module`: `Number(SIZE) > 2` gives
  `'3'` and `'2'`). An arm that only an unset variable takes adds no value.
- `unset`: `true` when one arm of some leaf is taken only when the variable is unset (card `known/env-two-files`:
  `process.env.STRICT ? 5 : 10` takes `else` when `STRICT` is unset, and `''` also takes it, but the ordinary value of
  `else` is unset).

Add both fields to `gatherEnvReadsContract` (in `packages/core/src/contracts/gather-env-reads/`; read it first and
keep its existing fields). Keep `literals` as it is: the broker still uses it until task 26.3.1.

## Tests

- `VALID: {Number(process.env.SIZE) > 2} => values ['2', '3'], unset absent`
- `VALID: {process.env.STRICT ? 5 : 10} => values ['1'], unset true`
- `EDGE: {an env read no branch compares} => values [], literals as today`
