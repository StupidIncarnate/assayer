## What to implement

The `demanded` arm of `propertyDemandContract` holds `values: RepresentativeValue[]` and an optional `cardinality`.
Add three optional fields to that arm, each with a sentence in the PURPOSE block:

- `missing: z.literal(true).optional()`: the property is left out on one arm (card `nullable/optional-property-in`:
  `options.label` is "missing for else"). A left-out property is not a value, so it is a flag, not a member of
  `values`.
- `arrays: z.array(z.array(representativeValueContract)).optional()`: the values of a property whose type is an
  array, one inner list per arm (card `deep/array-of-objects-2`: `order.prices` is `[]`, `[100]` and `[101]`).
- `objects: z.array(z.record(z.string(), representativeValueContract)).optional()`: the values of a property or
  parameter whose type has an object member, one object per arm (card `edge/typeof-object`: `{ size: 1 }`).

The `PropertyDemand` interface above the contract gains the same three optional fields. The stub keeps its default
and has no new field.

## Tests

- `VALID: {demanded, values ['x'], missing true} => parses and keeps missing`
- `VALID: {demanded, values [], arrays [[], [100], [101]]} => parses`
- `VALID: {demanded, values ['a'], objects [{ size: 1 }]} => parses`
- `INVALID: {demanded, missing false} => throws`
- `VALID: {the stub} => parses with none of the three fields`
