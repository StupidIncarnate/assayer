   ```ts
   type Order = { customer?: { address?: { country: string } } };

   export const classify = (order: Order | undefined): string => {
     if (order?.customer?.address?.country === 'NZ') {
       return 'local';
     }
     return 'abroad';
   };

     order?.customer?.address?.country;
   ```

2. The test asserts what is bespoke to this file. Write every expected value by reasoning from the card and from the design,
   never from a probe's output.

     nonNullish order.customer.address, eq order.customer.address.country 'NZ')`. Six routes per the card: `order` undefined,
     `customer` missing, `address` missing, `country` 'US', `country` '' (all `else`) and `country` 'NZ' (`then`). The fewest-runs

     it (`'NZ'` for `then`).

     three on an `else` arm and one on all three `then` arms. Each branch's `guardPath` holds the `then` steps of the links
     before it.
