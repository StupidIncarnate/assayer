## Read first

`probe-visit-node-layer-transformer.ts`: an `optional` site rewrites a property access `a?.b` to
`__P.oc(thenId, elseId, a, (r) => r.b)`. The recursion visits children first, so an inner site is rewritten before the site
that contains it. Read the `optional` kind in `probe-site-contract.ts` and the `oc` signature of task 18.1.1.

## What to implement

An `optional` site spans one **segment** of a chain: a link (a property access, element access or call that carries `?.`) and
the non-link steps that follow it up to the next link (task 18.3.2 mints these spans). After the children are visited, the
segment node holds exactly one link, found by walking down `expression` from the segment node to the node that carries the
`?.` token. The receiver of the call is that link's `expression`.

1. **Accessor.** Rebuild the segment with the link's `expression` replaced by the parameter `r` and the `?.` token removed, and
   use it as the arrow function body: `a?.b.c` becomes `__P.oc(then, else, a, (r) => r.b.c)`, `a?.[i]` becomes
   `__P.oc(then, else, a, (r) => r[i])`, and `fn?.(x)` becomes `__P.oc(then, else, fn, (r) => r(x))`. The steps after the link
   run only when the receiver is present, as the language does.
2. **Chains.** When the link's receiver, after removing parentheses, is itself a call to `__P.oc` (an inner segment rewritten
   first), pass `true` as a fifth argument. Otherwise pass four arguments, exactly as today.
3. **Member calls stay as they are.** A call link whose callee is a property or element access (`obj.method?.()`) would lose
   `this` in the accessor. Leave such a node unrewritten. Task 18.3.2 does not mint a site for it.
4. A site over a node that holds no link, or whose site has no `elseId`, is left as it is, as today.
5. Header comment: the segment, the three accessor shapes, the chained argument and the member-call exception.
