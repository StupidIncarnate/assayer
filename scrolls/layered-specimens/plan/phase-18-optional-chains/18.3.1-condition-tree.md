## What to implement

A comparison or a bare operand whose operand expression is an optional chain is today one leaf on the final member
(`order?.customer?.address?.country === 'NZ'` is one `eq` leaf with the path `customer.address.country`). The chain
short-circuits, so the leaf alone leaves out the question "is each level there?". Read it as the chain does.

1. **Links.** Collect the chain's links: each property access, element access or call that carries a `?.` token, innermost
   first. A `?.()` call on a member access (`obj.method?.()`) is not a link, because the runtime rewrite would lose `this`. A condition with no link is unchanged.
2. **Positive predicates.** For a leaf whose predicate is true only when the value is present, build
   `and(nonNullish(receiver1), …, nonNullish(receiverN), <the final leaf>)`. The non-nullish leaves come from
   `readNullishLeafLayerTransformer` and the final leaf from the existing path. The positive predicates are `eq`, `gt`, `gte`,
   `lt`, `lte`, `truthy`, `includes`, `undefined-neq`, the `length-*` family, `typeof-eq` against any tag other than
   `'undefined'`, and `typeof-neq` against `'undefined'`.
3. **Negative predicates.** A chain that short-circuits is `undefined`, and these predicates are true of `undefined`: `neq`,
   `falsy`, `undefined-eq`, `typeof-eq` against `'undefined'`, and `typeof-neq` against any other tag. For each, build
   `not(and(nonNullish(receiver1), …, nonNullish(receiverN), <the exact complement leaf>))`. The complements are `neq` to `eq`,
   `falsy` to `truthy`, `undefined-eq` to `undefined-neq`, `typeof-eq` to `typeof-neq` and back, with the same literal. A
   predicate that has no exact complement in the list (an unrecognized one) leaves the leaf unchanged.
4. **Leaf ids.** Use the positional path scheme the file already uses: the branch id plus `#leaf` and `.<index>` segments. The
   `n` non-nullish leaves take the first `n` positions of the `and`, in chain order, the final leaf the last. A condition with
   no link keeps every id it has today. Parentheses consume no segment.
5. **Probe sites.** The non-nullish leaves carry no probe site: the final leaf's site already wraps the whole operand, and the
   instrumenter wraps a span once. Say so in the header comment.
6. **Connectives.** A chain inside `&&`, `||` and `!` is read the same way at its own position, because the reader recurses into
   those connectives and reaches the comparison.
7. Update the header comment: the chain rule, the two predicate tables, and why a negative predicate is wrapped in `not`.
