A chain on `order: Order | undefined` also holds a `non-nullish` leaf on `order` itself. Task 18.3.3 admits that leaf. This task

## Contract

```ts
isRootNullishLeafGuard({ leaf }: { leaf: ConditionLeaf }): boolean
```

True when all of these hold: the leaf has `operandParamName`; it has no `operandPropertyPath`; its predicate kind is
`non-nullish`; and its `operandType` is a union that holds `undefined` or `null` and at least one object type.

## What to implement

The guard, with a PURPOSE block in plain words: what the leaf is, and that it is what lets `stub-realize` bind a whole object
parameter to `undefined`.

## Tests

- `VALID: non-nullish on order, order: Order | undefined => true`
- `VALID: non-nullish on order, order: Order | null => true`
- `INVALID: non-nullish on order.customer (a property path) => false`
- `INVALID: truthy on order => false`
- `INVALID: non-nullish on count, count: number | undefined => false (no object type)`
- `INVALID: non-nullish on order, order: Order (no nullish member) => false`
