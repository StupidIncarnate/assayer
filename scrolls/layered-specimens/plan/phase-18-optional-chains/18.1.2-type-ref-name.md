- **Depends on:** phase 17.
- **Model:** default (the worker's default model; this task is fully specified).
- **Covers:** `packages/core/CLAUDE.md` section 5.1 (a type-reference name is a sanctioned `getText()` use); card `param › ?. › ?. › ?. › if` (`src/deep/optional-chain-3`).

`read-condition` records `operandTypeRef`, the NAME of the type the root parameter declares, only when the parameter's type node
is a plain type reference. For `order: Order | undefined` the type node is a union, so no name is recorded and the stub stitch
cannot join the `order.customer` read to `Order`. This task adds the one reader of that name that sees through a nullish union.
Tasks 18.2.1 and 18.2.2 call it.

## Contract

```ts
readTypeRefNameLayerTransformer({ typeNode }: { typeNode: TypeNode | undefined }): string | undefined
```

- A type reference gives its name (`Order`).
- A union whose members are exactly one type reference and any number of `undefined` or `null` keyword types gives that
  reference's name (`Order | undefined`, `Order | null`, `Order | null | undefined`). Parentheses are removed first.
- Anything else gives `undefined`: an inline type literal, a union of two references, a primitive, no type node.

Read the name with `getTypeName().getText()` on the reference, the sanctioned name read. Read the member kinds from the node
(`Node.isTypeReference`, `SyntaxKind.UndefinedKeyword`, a `LiteralType` holding `NullKeyword`), never from text.
