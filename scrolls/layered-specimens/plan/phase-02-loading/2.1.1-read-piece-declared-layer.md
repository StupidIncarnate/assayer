## Contract

`readPieceDeclaredLayerTransformer({ declared, origin, file }): PieceDeclared`, where `declared` is the
object the declaration file exports, typed `unknown` (it comes from the sandbox), `origin` is `'piece' | 'shim'`,
and `file` is the declaration's file name for error messages. `PieceDeclared` is the return type written
inline: `description`, `folder`, `tags`, `slots` (each with `accepts`, `position`, `segment?`, `arm?`, `under?`),
`arms`, `leaf`, `axes`, `levelCap`, `defaultType`, `reach`, `anchors`, and for a shim `form`, `builtin`,
`range`, `pin`.

## What to implement

Every wrong field throws a `DeclarationError` naming the file, the field and the fix. Messages, word for word
(`<...>` is filled in):

| Wrong | Message |
|---|---|
| not an object | `a piece declaration must export an object made by piece(...) or shim(...). This file exports <typeof value>.` |
| `description` empty | `description is missing. Write one plain sentence saying what the piece is.` |
| piece with no `folder` | `folder is missing. Write the folder name the piece uses in the output layout, such as 'nullish'.` |
| `tag` not a tag | `tag is '<tag>'. Use one of: statement, expression, parameter-list, loop-head, root.` |
| slot position | `slots.<slot>.position is '<value>'. Use statement, condition, exit, value or inherit.` |
| slot `arm` | `slots.<slot>.arm is '<value>'. Use return, log, yield, push or throw.` |
| `under` is not a string | `slots.<slot>.under must be the name of one of the piece's arms.` |
| `under` names no arm | `slots.<slot>.under is '<value>', and arms declares no arm of that name. Use one of: <arm names joined by ', '>.` |
| `under` and no arms at all | `slots.<slot>.under is '<value>', and arms declares no arm at all. Remove under.` |
| arm cause | `arms.<position>.<arm>.cause is '<value>'. Use outcome, truthiness, nullish, member or presence.` |
| arms position | `arms.<position> is not a position. Use statement, condition, exit or value.` |
| `leaf` | `leaf is '<value>'. Use outcome, truthiness, nullish, member or presence.` |
| axis | `axes names '<value>', which is not an axis. Use one of: <axis names from axisStatics joined by ', '>.` |
| arms without `iteratives` | `axes does not name 'iteratives', and arms declares branches in <positions joined by ', '>. Every piece with arms crosses the iteratives axis. Add 'iteratives' to axes.` |
| `levelCap` | `levelCap is <n>, and only an object or array literal may go 3 levels deep. Remove levelCap.` (a piece whose folder is not `object` or `array` with `levelCap: 3`; any `levelCap` other than 2 or 3 reads `levelCap is <n>. Use 2 or 3.`) |
| `reach` | `reach is '<value>'. Use one of: call, call-and-await, call-and-iterate, call-static, call-member, construct, construct-then-call, construct-then-read, construct-then-assign, module-load.` |

The `iteratives` rule reads the declared `arms` only: an `arms` position whose value is an array counts as
branches, and a position whose value is `'leaves'` does not. A shim never declares `arms`, so the rule never
fires for it. Keep every shim refusal the old layer has (form, builtin, range, pin).

## Tests

For each row of the table: an `INVALID:` test that builds the declared object in memory and asserts the whole
message with `toThrow(/^...$/u)` (escape regex characters). `VALID:` one statement piece (`if`, with `then`
and `else` slots that declare `under`), one expression piece (`gt`, arms `{ condition: 'leaves' }` and
`iteratives` in axes), one shim (`array-at`), each asserting the whole returned object with `toStrictEqual`.
`EDGE:` a piece with only `leaves` arms and no `iteratives` axis is accepted. `EDGE:` a piece with two
positions of arms, one `leaves` and one array, and no `iteratives` axis, is refused naming only the array position.
