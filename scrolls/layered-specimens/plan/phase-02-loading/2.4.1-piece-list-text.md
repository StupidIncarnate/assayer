## Contract

`pieceListTextTransformer({ pieces, compositions }): string`.

## What to implement

One line per piece sorted by name, then one line per shim sorted by name, then one last line. Plain text with
one trailing newline. No line holds a space inside a field.

- Piece line (`origin: 'piece'`): `piece <name> tags=<tags joined by ','> slots=<slots> arms=<arms> axes=<axes>`.
  - `<slots>`: each slot as `<slot>:<accepts joined by '|'>:<position>`, plus `@<arm>` when the slot declares
    `under`, joined by `,`. `-` when there is none.
  - `<arms>`: each position that declares arms as `<position>:<arm>/<arm>` or `<position>:leaves`, joined by
    `,`, positions in the order statement, condition, exit, value. `-` when there is none.
  - `<axes>`: the axis names joined by `,`. `-` when there is none.
- Shim line (`origin: 'shim'`): `shim <name>`.
- Last line: `compositions: <number of cards>`.

Example: `piece if tags=statement slots=cond:expression:condition,else:statement:statement@else,then:statement:statement@then arms=statement:then/else axes=level,iteratives`.

## Tests

- `VALID: two pieces and one shim and one card => the lines in order`.
- `VALID: a slot with under => '@<arm>' follows its position`.
- `VALID: an arms position of leaves => '<position>:leaves'`.
- `VALID: a piece with no slots, no arms, no axes => '-' in each field`.
- `EMPTY: nothing loaded => 'compositions: 0\n'`.
