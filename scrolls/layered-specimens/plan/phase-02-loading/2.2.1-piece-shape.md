## Contract

`pieceShapeTransformer({ sourceFile, checker, declared, origin, typeArguments }): LoadedPiece`. `declared` is

## What to implement

Pair the declared object with the syntax tree of `code`:

1. The holes are `code`'s parameters, typed by the checker, as `syntax-shape` reads them.
2. Each `$stmts('<name>')` call in `code` is a statement slot. Each `$params` parameter is a parameter-list
   slot. Each declared slot must match exactly one hole, marker or `$params`. Refuse a declared slot with no
   matching place: `slots names 'else', and code has no hole, $stmts('else') or $params of that name. Add it to code, or remove the slot.` Refuse a hole or marker no slot declares: `code has $stmts('body'), and slots does not declare 'body'. Declare it.`
3. Every `$arm('<name>')` in `code` must name an arm declared in some position: `code has $arm('maybe'), and no position of arms declares 'maybe'. Declare it, or remove the marker.` A declared arm with no marker is allowed (a loop's `skipped`, a switch's `no-match`, a default's `defaulted`).
4. `under` against the code. For each `$stmts('<slot>')` that follows an `$arm('<arm>')` call in the same block:
   - the slot declares `under` and it differs: `code puts $stmts('then') after $arm('then'), and slots.then declares under 'else'. Set under to 'then'.`
   - the slot declares no `under`: `code puts $stmts('then') after $arm('then'), and slots.then declares no under. Add under: 'then'.`
5. `segment` defaults to `<folder>-<slot name>`.
6. `binds` lists the names `code` declares at its own top level: each variable declaration, destructured name
   and parameter that is not a hole. Task 4.1.1 reads it to write the reader after a non-branching piece.
   `helpers` is the statement list of the `helpers` arrow's block body, or empty. `armMarkers` lists every
   `$arm` name in source order.
7. Type parameter, constraint and `allowedTypeArguments` as `syntax-shape` does. A generic piece must declare
   `defaultType`, and it must be one of `allowedTypeArguments`: `defaultType is 'bigint', which the type parameter's constraint does not allow. Use one of: <allowed joined by ', '>.` and `a generic piece must declare defaultType. Add the type its DESIGN.md card uses.`
8. A piece whose `tag` includes `statement` has a block body that returns nothing. A piece whose `tag` is only
   `expression` has an expression body, or is a container (its `code` holds `$Entry`).
9. `levelCap` defaults to `layeredMatrixStatics.levels.cap` (task 1.1.6) when the piece declares none.

**Shims.** A `*.shim.ts` loads as a piece with `origin: 'shim'`, `tags: ['expression']`, one slot per hole
(named by the hole, accepting `expression`, position `value`, form `hole`), `arms: {}`, `axes: []`. It keeps
every shim refusal `syntax-shape` has (receiver, getter arity, range with inputs). A shim is loaded and checked
but the planner never places it: the pieces table is the full list (decision "Containers the pieces table does
not name"). `.length` and `.at()` are pieces of their own (task 3.1.11), not shims. Write this as the header
comment.

## Tests

For each refusal above: an `INVALID:` or `ERROR:` test that builds a small declaration source in memory (a
TypeScript program over an in-memory host, as `syntax-shape-transformer.test.ts` does) and asserts the full
`DeclarationError` message with `toThrow(/^...$/u)`. `VALID:` one statement piece (`if`), one expression piece
(`gt`), one container (`arrow-function`), one shim (`array-at`, asserting `origin`, `tags`, the one `value`
slot, `arms: {}`, `axes: []`), each asserting the whole `LoadedPiece` minus its node fields with `toStrictEqual`.
`VALID:` a piece whose `$stmts('then')` follows `$arm('then')` and declares `under: 'then'`.
