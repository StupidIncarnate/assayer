## Contract

`piecesLoadBroker({ declarationsRoot }): { pieces: LoadedPiece[]; compositions: CompositionCard[] }`, each
sorted by name (compositions by `folder`). `pieces` holds pieces and shims; a shim has `origin: 'shim'`.

## What to implement

Do what `declarationsLoadBroker` does, with these differences:

1. Read `pieces/*.piece.ts`, `shims/*.shim.ts` and `compositions/*.compositions.ts` (`generatorLayoutStatics.declarations`,
   task 1.1.8). Do not read `containers/` or `syntax/`.
2. Typecheck all of them in one program and refuse on any diagnostic with the old message.
3. The sandbox's runtime kit answers `piece`, `shim`, `compositions` and every marker. `$arm`, `$stmts`, `$expr`
   and `$exportDefault` throw the same "is a marker" errors: nothing in a piece's `code` is run.
4. Each file must export exactly one const, named by `declarationExportNameTransformer` (kinds `piece`, `shim`,
   `compositions`, task 2.1.3).
5. A piece or shim goes through `readPieceDeclaredLayerTransformer` (task 2.1.1) and `pieceShapeTransformer`
   (task 2.2.1). Each card of a compositions file is parsed with `compositionCardContract` (task 1.3.4); a
   parse failure becomes a `DeclarationError` naming the file, the card's folder and Zod's message.
6. Two pieces with one name, or two cards with one folder, are refused:
   `two composition cards declare the folder '<folder>': <file a>, <file b>. Give each card its own folder.`
   `two pieces are named '<name>': <file a>, <file b>. Give each piece its own file name.`
7. A card whose `sameAs` names a folder no card declares is refused: `composition card '<folder>' repeats '<sameAs>', and no card declares that folder. Name an existing card in sameAs.`

Callers: the responder of task 2.5.1 (`--list-pieces`), and later the plan broker (task 4.6.1).

## Tests

Use the proxy to stage the file system the way `declarations-load-broker.proxy.ts` does. Cover:

- `VALID: one piece, one shim and one compositions file => all load, sorted`.
- `VALID: a piece whose slot declares under => the loaded slot carries under`.
- `ERROR: a TypeScript error in a piece` (message word for word).
- `ERROR: a piece importing anything but the kit`.
- `ERROR: a piece that throws while loading`.
- `ERROR: a wrong export name`.
- `ERROR: a piece with an unknown axis` (the message of task 2.1.1).
- `ERROR: an invalid card`.
- `ERROR: two cards with one folder`, `ERROR: two pieces with one name`, `ERROR: a sameAs naming no card`.
- `EMPTY: empty folders => { pieces: [], compositions: [] }`.
