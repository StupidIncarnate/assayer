## What to implement

Write each piece from its old `syntax` file plus its DESIGN.md row, with the kit's `piece`. Keep each old
file's `code` and anchors where they still say something true. One file, one export (`ifPiece`, `ternaryPiece`,
`eqPiece`).

| Piece | folder | tag | slots (accepts, position, under) | arms by position | leaf | axes | defaultType |
|---|---|---|---|---|---|---|---|
| `if` | `if` | statement | `cond` (expression, condition), `then` (statement, statement, under `then`), `else` (statement, statement, under `else`) | statement: `then`, `else` | | `level`, `iteratives`, `type`, `nullability` | `boolean` |
| `ternary` | `ternary` | expression | `cond` (expression, condition), `then` (expression, inherit, under `then`), `else` (expression, inherit, under `else`) | exit: `then`, `else`; value: `then`, `else` | | `position`, `type`, `nullability`, `level`, `iteratives` | `boolean` |
| `eq` | `eq` | expression | `value` (expression, value), `expected` (expression, value) | condition: `leaves` | `outcome` | `type`, `level`, `nullability` | `number` |

`if`'s code keeps the shape of the old file: the `else` falls through to the code after it, and the two
statement slots sit under their arms.

```ts
code: <T>(cond: T): void => {
  if (cond) {
    $arm('then');
    $stmts('then');
  }
  $arm('else');
  $stmts('else');
},
```

Every slot that runs under an arm declares `under`: the `cond` slot of `if` and `ternary` runs always, so it
declares none. `ternary` crosses `nullability` like `if`, because its condition is a truthiness check (DESIGN.md
axis table row "Nullability": truthiness). `eq`'s `type` axis covers number, string, boolean and a literal union (DESIGN.md "Type
variation": `count === 7`, `name === 'xyz'`, `flag === false`, `mode === 'a'`). Every piece with arms crosses
`iteratives`; `eq` has only leaves and does not.
