## What to implement

Port each container with the same markers. None has arms, so no slot declares `under` and none declares `iteratives`.

| Piece | folder | tag | slots (accepts, position) | axes |
|---|---|---|---|---|
| `async-function` | `async-function` | statement | `params` (parameter-list), `body` (statement, statement) | `exit-kind` |
| `generator-function` | `generator` | statement | `params` (parameter-list), `body` (statement, statement). A `yield` is a value position | `exit-kind` |
| `class` | `class` | statement | `constructor-params` (parameter-list), `constructor-body`, `method`, `static-method`, `getter`, `setter` (statement, statement), `field`, `static-field` (expression, value) | `level`, `shared-state` |

The `setter` slot is reached by assigning the property: its `reach` is `construct-then-assign` (task 1.1.1).
Each statement slot keeps the `arm` the old container gives it. Task 3.1.27 adds the `constructor-param-property` slot and the shared-state comment.
One file, one export (`asyncFunctionPiece`, `generatorFunctionPiece`, `classPiece`).
