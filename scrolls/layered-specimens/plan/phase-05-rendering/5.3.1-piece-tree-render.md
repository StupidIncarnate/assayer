## Contract

`pieceTreeRenderTransformer({ tree, helpers, exportName }): { text: string; params: { name: string; type: string }[] }`

`exportName` is the plan's `exportName` (task 1.4.2). Absent, the entry is exported as `entry` (or the class
`Entry`). A string names the export instead (`export class Counter`, `export const result = …`). `null` exports
nothing and adds `export {};`.

`helpers` are the plan's helpers. A type alias is written `type <name> = <typeAlias>;`, an enum
`enum <name> { <members> }`, a tree helper `const <name> = <rendered tree>;`. All of them come before the pieces' own
helpers. It replaces `fillTreeRenderTransformer` and `specimenAssembleTransformer` at row 9.6.

## What to implement

Render the root with `renderPieceLayerTransformer` (task 5.2.1). Write the file in this order: the plan helpers, the
pieces' own helpers (in the order first used), the top-of-file declarations, then the root container with the entry
exported (`export const entry`, `export function entry`, `export class Entry`). Add `export {};` when the file
exports nothing (a module specimen, card `const/in/module`). Put the `bodyStart` statements first in the entry's
body. When an arm kind is `push`, put `const seen: string[] = [];` first and `return seen;` last in the container
body.

Print with the TypeScript printer. Join top-level statements with one blank line, as `specimen-assemble` does today.
End with one newline. Build every statement from syntax-tree nodes or parsed snippets, never by joining code
strings.
