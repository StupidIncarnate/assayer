## What to implement

Keep every other existing key. Change two existing values in `compilerOptions`, at lines 12 and 13 of the
statics file: `noUnusedLocals: false` and `noUnusedParameters: false`. Add a header comment above them that says
why: a specimen that declares a value nothing reads (cards `shape/if-if/sequence/three-args-one-unused` and
`consume/never-read`) is a case Assayer must report with its `never-read` lint. With either flag on, the
generator's own typecheck refuses that specimen, so Assayer never sees it. The smoke repo's hand-written
`tsconfig.json` sets neither flag, so the generator and `npm run typecheck:generated` agree.

Then add two groups, each with a header comment:

```ts
expectedDiagnostics: {
  'unresolvable-specifier': [2307],
  'unresolvable-no-types': [7016],
  'unresolvable-dynamic': [],
},
corePathSegments: ['packages', 'core', 'index.ts'],
```

- `expectedDiagnostics`: the TypeScript diagnostic codes a specimen of that file-boundary value produces on purpose.
  Code 2307 is "cannot find module". Code 7016 is "could not find a declaration file for module". A dynamic
  `import()` of a template string is typed `any`, so it produces none. The typecheck broker (task 5.2.2) skips a
  diagnostic only when its code is in the list for the group's file-boundary value. Any other diagnostic still
  refuses the specimen.
- `corePathSegments`: the path segments, from the repo root, of the file the `@assayer/core` import resolves to, so
  a harness file typechecks (task 5.2.2).

## Tests

Update the existing whole-object `toStrictEqual` to the new object, with `noUnusedLocals: false` and
