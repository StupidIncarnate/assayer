## Contract

`renderPieceLayerTransformer({ tree, names, params, decls, helpers }): ts.Node`

It renders one `PieceTree` node and records what the file needs in the maps it is given: `names` (taken
identifiers), `params` (entry parameters), `decls` (top-of-file declarations, and `bodyStart`) and `helpers`
(helper statements by name).

## What to implement

1. A leaf renders through `sourceLeafLayerTransformer` (task 5.1.2). A snippet renders by parsing its text.
2. A node renders each slot's children first, in slot order (a statement slot renders several statements in a row,
   an expression slot exactly one). It then calls `swapSlotsLayerTransformer` (task 5.1.1) with the rendered
   children, the slot's `armKind` and the node's `position`.
3. A nested node is printed and parsed again before it is placed, so no syntax-tree node from another source file
   ends up inside this one.
4. Each piece's `helpers` statements are added to `helpers`, keyed by the name each declares, once. Two uses of one
   `call` piece add its helper once.
5. A slot's `under` field names the arm the slot runs under. The renderer reads it only to tell the swap layer which
   arm statement the slot's `$arm` marker writes. It never changes where a child is placed.
