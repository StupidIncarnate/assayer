## What to implement

`derive-cases` is the one gate that decides whether a branch can be steered (section 5.12). A `default` branch has a leaf
`undefined-neq` on its parameter, and `is-predicate-constraining` correctly says a comparison with `undefined` steers
nothing on a parameter. The branch is steered by structure instead, so:

1. **Exempt `default` branches from the leaf gate.** A branch of kind `default` is steerable when its parameter is in the
   applied list (task 13.3.2). Ask no other question of its leaf. A `destructure-default` branch goes through the normal gate
   (its leaf is a `length-gt` or a `has-property` read, task 13.8.1).
2. **Given and defaulted.** For a bucket that takes the `default` branch's `then` arm (`given`), cause-arrange has already
   arranged the parameter with a value from its type; leave it. For a bucket that takes `else` (`defaulted`), replace that
   parameter's binding in the arrangement by `{ kind: 'param', param, value: { $assayer: 'undefined' } }`. Passing
   `undefined` triggers the default whether the parameter is last or not, so the one rule covers both. Never leave the
   parameter at the value cause-arrange picked.
3. **Edge values given.** The pinned buckets of task 12.3.3 already put `0`, `NaN`, `-1`, `''`, `false` and `null` on the
   `given` arm (`undefined-neq` is true for each) and `undefined` on the `defaulted` arm when the type allows it. A pinned
   `undefined` bucket and the `defaulted` bucket are the same case once their arrangements are equal, and the existing
   de-duplication keeps one. `null` is given and passes through (card `nullable/default-and-null`).
4. **A branch inside the default.** A `ternary` whose guard path holds the `default` branch's `else` step is met only on
   `defaulted` routes (`is-branch-met`), so the `given` bucket never names it (card `ternary/in/default-param`: 3 arm
   combinations, not 4). Add a test; no code is expected.
5. **A contradicting combination is not a route. This step is required.** In card `nullable/default-and-null` the
   default `'none'` is never `null`, so `defaulted` with `label === null` contradicts itself, and the card lists 4
   routes, not 5. For a bucket that takes a `default` branch's `defaulted` arm, when the branch carries `defaultValue`
   (task 13.1.1), seed that parameter's domain in the bucket with exactly `{ members: [defaultValue] }` and check every
   other leaf the bucket holds on that parameter against it, with the same `isDomainEmptyGuard` check a welded leaf
   uses (`packages/core/CLAUDE.md` section 5.12). A bucket where any such check is empty is not a route: drop it before
   cases are built. A `default` branch with no `defaultValue` (its initializer is not a literal) drops nothing.
   The test below asserts the four routes; the task is not done until it passes.
6. **Element values of a destructured array.** For a `destructure-default` branch whose leaf is `length-gt i` on an array
   parameter `P` whose element type is a scalar: after the ordinary buckets, add for each edge value `e` of the element
   type (`edgeValueStatics`, in order, then the tagged `undefined` when the element type allows it) one case that takes the
   `present` arm with a pin `{ operand: P, value: <an array of length i + 1 whose item i is e and whose other items are the
   element type's ordinary value> }` (the array pin of task 12.4.1). The other branches in the bucket keep the arms of the
   first ordinary bucket that takes `present`. Cards `array/destructure-default` (`[5]`, `[0]`, `[NaN]`, `[-1]`, `[5, 6]`).
7. Update the PURPOSE block in plain words.

## Tests

Assert whole case lists with `toStrictEqual`, written from the cards.

- `VALID: {default branch on count: number, no other branch} => one ordinary given case, given cases with 0, NaN and -1, and one defaulted case whose binding is { $assayer: 'undefined' }` (card `default-param/alone`: five cases, fewest runs 2)
- `VALID: {default branch plus a ternary on count in the default} => defaulted cases for count 3, 2, 0, NaN, -1; given cases for 'x' and ''` (card `ternary/in/default-param`: seven)
- `VALID: {label: string | null with a default 'none', if (label === null)} => defaulted-else, given-null-then, given-'x'-else, given-''-else` (card `nullable/default-and-null`: four; no defaulted-then route)
- `VALID: {count: number = 7, if (count > 10)} => no defaulted-then route, because 7 > 10 is false`
- `VALID: {destructure-default on values[0], values: number[]} => values [], [5], [0], [NaN], [-1], [5, 6]` (card `array/destructure-default`: six)
- `EDGE: {default branch whose parameter is not applied (truncated)} => the branch is undriven, not dropped`
- `EMPTY: {no default branch} => behaviour unchanged`
