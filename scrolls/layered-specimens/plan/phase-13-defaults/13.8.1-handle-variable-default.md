## What to implement

For each variable declaration whose name is a destructuring pattern and whose initializer is present, read the pattern with
`readParameterDefaultsLayerTransformer({ node: <the pattern> })` (task 13.7.1). Each `form: 'element'` readout becomes one
branch of kind `destructure-default`, `arms: ['present', 'defaulted']`, in the readout order.

- **Coverage ID:** `coverageIdTransformer({ scopePath: context.scopePath, segment: 'destructure-default:<path>.<name or index>' })`
  built from the readout's `position` (names of properties and indices, never text).
- **Condition (the source must be a parameter or a property path of one).** Read the initializer with the readers
  `read-condition` uses for an object-member operand (`read-property-path`), to get the root parameter and its path:
  - an array element at index `i`: a leaf on the source array, predicate `length-gt` with literal `i`. `present` holds
    when the array has an element at `i`, so `then` is `present` and `else` is `defaulted`. The existing array
    cardinalities (`[]`, one item, many) steer it, which is what the design card says ("Assayer already reaches both
    arms through its empty-array and one-item cases").
  - an object element named `n` under path `p`: a leaf on the root parameter with `operandPropertyPath` `[...p, n]` and
    predicate `has-property` literal `n` (task 12.1.3). `then` is `present`. The stub overlay arranges it at run time
    (section 9). A property present as `undefined` also triggers a default; this phase does not arrange that form for a
    destructuring default, and the header comment says so.
  - a source that is not a parameter or a property path of one (a call result, a local the walk did not follow): the leaf
    is `unrecognized`, so the branch is admitted undriven by the usual gate and its routes are declared, never dropped.
- **Defaulted arm.** The element's initializer descends under the guard step `{ branchCoverageId, arm: 'else' }`, built
  with `walkContextTransformer({ context, guardSteps: [step] })`, so a ternary in a destructuring default is met only on
  that arm. Record the `defaulted` arm as a fall-through arm with the initializer's span.
- **Parameter patterns** (`({ count = 0 }: Box) => …`) are task 13.8.2's; this handler reads variable declarations only.
  Say so in the PURPOSE block.
- Keep every fact `handle-variable` already emits (value uses, bindings, descents).

Write the PURPOSE block addition in plain words.

- `EDGE: {const [first = 0] = load()} => the branch exists and its leaf is unrecognized`
- `EMPTY: {const [a] = values} => no branch`
