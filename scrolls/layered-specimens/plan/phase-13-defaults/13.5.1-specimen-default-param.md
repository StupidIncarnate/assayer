- `plain = (count: number = 7): number => count`
- `ternaryDefault = (count: number, label: string = count > 2 ? 'big' : 'small'): string => label`

  defaulted) and fewest runs marks two;
- `ternaryDefault`: a `default` branch and a `ternary` branch whose guard path holds the default's `defaulted` step; seven
  cases, fewest runs three;
- `nullPasses`: a `default` branch and an `if`; four cases, `null` is given and takes the `then` arm;
- the defaulted case's arrange for the parameter is the tagged `undefined`;
