## What to implement

1. For each readout with `form: 'parameter'` (task 13.2.2), emit one branch of kind `default`, `arms: ['given', 'defaulted']`.
   - Coverage ID: `coverageIdTransformer({ scopePath: scoped.scopePath, segment: 'default:<name>' })`, where `<name>` is
     the parameter's identifier name. Formatting never moves it.
   - Condition: one leaf on the parameter, predicate `undefined-neq`, operand type the parameter's type, `operandParamName`
     the parameter. It holds when the caller passed a value (`given`), and fails when the argument is `undefined`
     (`defaulted`). Only `undefined` triggers a default, never `null`, so the leaf is `undefined-neq` and not a nullish
     check. Build it with `build-condition-leaf`.
   - `guardPath: []` (the function's own scope), `startLine` and `endLine` the parameter's span.
   - `defaultValue` (task 13.1.1): when the initializer is a string, number, boolean or `null` literal, its value read
     through `getLiteralValue()` (or the literal's kind for `true`, `false` and `null`). Any other initializer, such as a
     ternary, sets no `defaultValue`.
2. The initializer of that parameter descends under the guard step `{ branchCoverageId, arm: 'else' }` (`else` is the
   second label, `defaulted`), built with `walkContextTransformer({ context: preludeContext, guardSteps: [step] })`, never a
   local path. A ternary in the default (card `ternary/in/default-param`) is therefore met only on the `defaulted` arm.
   Pattern-element defaults (`form: 'element'`) keep descending under `preludeContext`, unguarded, as today.
3. Record the `defaulted` arm as a fall-through arm (`fallthroughArmContract`, guard path `[step]`, the initializer's
   span), so a default no value can enter is reported. The `given` arm owns no code and records nothing.
4. The branch is a branch of this function's scope: claim it the way the concise-ternary readout's branch is claimed, so
   it lands in the scope's own branch list, ordered before the body's branches (defaults run before the body).
5. **Remove the `branchingDefault` marking.** Delete `paramInitializers`, the `params` map that sets
   `branchingDefault: true` (lines 168 to 176), and the comment above it. `params` becomes `declaredParams`. Task 13.3.2
   stops `applied-params` reading the field, and task 13.4.2 removes it from the contract.
6. Update the PURPOSE block and the comment on the defaults in plain words: a default is a branch with a given arm and a
   defaulted arm.
