## Read first

The transformer's `arms` type guard (`'arms' in node`, written in task 8.2.1) and `report-vocabulary-statics.ts`.

## What to implement

1. Replace the `'arms' in node` type guard by the typed field `branch.arms` from `@assayer/shared/contracts`
   (`BranchNode['arms']`). Delete the guard and every comment about it.
2. A branch with `arms` reports its two labels. A branch without `arms` (`if`, `ternary`) reports `then` and `else`, as
   before. The branch's reported labels are sorted by the order `report-vocabulary-statics.ts` lists them for that kind
   (for `default`: `given`, `defaulted`), so the order in which core stores the pair never decides equality.
3. A route's arm step reports a label. A step named `then` reports `arms[0]`, and a step named `else` reports `arms[1]`,
   when the step's branch has `arms`. Without `arms` it reports `then` or `else`.
4. The other three guards in this file (a lint's `trace`, a gap's `param`, a build error's `reason` and `trace`) are
   replaced by task 25.1.2. Leave them.

## Tests

- `VALID: {an if branch} => arms [then, else]`
- `VALID: {a default branch with arms ['given', 'defaulted']} => arms [given, defaulted]`
- `VALID: {a destructure-default branch} => arms [present, defaulted]`
- `VALID: {a route step { arm: 'else' } on a default branch} => 'defaulted'`
- `VALID: {a route step { arm: 'then' } on a default branch} => 'given'`
- `EDGE: {arms stored in the reverse order of the vocabulary} => the same reported order`
