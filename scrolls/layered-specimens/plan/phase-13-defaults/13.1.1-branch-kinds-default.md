## Contract

1. `kind` becomes `z.enum(['if', 'switch', 'ternary', 'default', 'destructure-default'])`. Update the comment above it: a
   kind is added when its handler lands. Task 14.1.1 adds `loop` the same way.
2. New optional field `arms`: a pair of labels, `z.tuple([label, label])` with `label = z.string().min(1).brand<'BranchNodeArm'>()`.
   It is the report's names for the branch's two arms, in the order `[the arm taken when the condition holds, the arm
   taken when it does not]`. Inside Assayer a guard step still names its arm `then` or `else`: `then` is the first label,
   `else` the second. A branch with no `arms` reports `then` and `else`. `default` uses `['given', 'defaulted']` and
   `destructure-default` uses `['present', 'defaulted']`.
3. New optional field `defaultValue`: `representativeValueContract` (from `../representative-value/representative-value-contract`).
   A `default` or `destructure-default` branch carries it when the default's initializer is a literal (`= 'none'`,
   `= 7`), read through `getLiteralValue()`, never through source text. It is the value the parameter holds on the
   `defaulted` arm, so `derive-cases` can drop a route that the default contradicts (task 13.4.1).
4. Extend the PURPOSE block with those sentences, in plain words.
5. The stub keeps its default (`kind: 'if'`, no `arms`, no `defaultValue`), so no test that builds a default branch changes.

## Readers of `BranchNode['kind']`

No non-test file in core, shared, desktop, app or cli switches on the kind, so no reader needs a new case. Two files copy a
branch field by field and would drop `arms`: `compose-cross-file-predicates-broker.ts` (line 134) and
`compose-predicates-transformer.ts` (line 91) (each line number is the line of `return branchNodeContract.parse({`, where the file rebuilds a branch field by field). Both rebuild a branch only when `rebasePredicateConditionTransformer`
rebased a callee's predicate signature into a caller's opaque `if (pred(x))` leaf. A `default` or `destructure-default`
branch never has such a leaf, so both return it whole (`return branch`). Confirm by reading both and name the result in
your reply. Do not edit them.
