## What to implement

```ts
export const entry = (count: number | undefined): string => {
  if (count) {
    return 'set';
  }
  return 'missing';
};
```

- the file's `gaps`, `darkSpots` and `undriven` are empty.

neighbouring lines (`specimen-registry.ts:440`): `access:named`, `branch:if`, and the `param:` traits `syntax-traits.ts` gives a `number | undefined` parameter. Read the traits the registry already uses for
