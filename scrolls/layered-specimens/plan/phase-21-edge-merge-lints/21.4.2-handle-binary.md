## What to implement

`handle-binary-layer-transformer.ts` handles `BinaryExpression`. It calls `readOperatorUseLayerTransformer({ node })` (task 21.2.6), returns the use in the handler result's `operatorUses` (through `handlerResultLayerTransformer`, task 21.3.2), and descends every child with the same context, so nested expressions and functions are still found. It never recurses itself and never climbs.

The route in `dispatch-node-layer-transformer.ts` is task 21.5.1, in the next row, so the tree stays green: until the route exists, nothing calls this handler.

## Tests

- `VALID: {value == 0} => one loose-equality use, children descended`.
- `VALID: {a || b} => one or-default use`.
- `VALID: {a - b} => no use, children descended`.
- `VALID: {a + (b == c)} => the outer mixed-plus use is returned, the nested one is found by the descent`.
- Formatting immunity: a reformatted copy gives the same uses.
