## What to implement

Each use of the matching kind fires at most one lint. `startLine` and `endLine` are `use.line`. `name` is the entry whose span holds `use.line`, or `*module*` when none does. The messages are product text; tests assert them word for word.

| Use kind | Fires when | Rule | Message |
|---|---|---|---|
| `loose-equality` | the non-missing base kinds of both operand types together are at least two (`string` and `number`, say), and neither operand is the literal `null`. `x == null` and `x != null` never fire | `edge-merge-loose-equality` | `edge-value merge (loose equality): <a> <op> <b> converts its operands to one kind before it compares, so '' and 0, or '0' and 0, are equal. Write ===.` |
| `typeof-object` | the operand's type has a `null` member | `edge-merge-typeof-object` | `edge-value merge (typeof object): <x> null takes the <arm> arm, the same arm as an object. Add <x> !== null.` with `<arm>` = `then` for `===` and `else` for `!==` |
| `mixed-plus` | an operand's type has both `string` and `number` members | `edge-merge-mixed-plus` | left operand mixed: `edge-value merge (mixed plus): <a> '1' with <b> 2 gives '12', not 3. Convert both sides first.` Right operand mixed (and the left is not): `edge-value merge (mixed plus): <a> 2 with <b> '1' gives '21', not 3. Convert both sides first.` |
| `global-isnan` | `use.anyOperand` is true | `edge-merge-global-isnan` | `edge-value merge (global isNaN): isNaN is true for a string such as 'abc'. Write Number.isNaN.` |

`<a>`, `<b>` and `<x>` are the operand names the use carries. A literal operand shows as its value: `0`, `'abc'` with single quotes, `true`. Example for card `edge/loose-equality`: `edge-value merge (loose equality): value == 0 converts its operands to one kind before it compares, so '' and 0, or '0' and 0, are equal. Write ===.` Example for card `edge/mixed-plus`: `edge-value merge (mixed plus): base '1' with extra 2 gives '12', not 3. Convert both sides first.`
