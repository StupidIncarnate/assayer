## What to implement

`settleHandlerLayerTransformer` merges `handled.operatorUses ?? []` and each child's `looseOperatorUses ?? []`. A handler that opens a scope hands the list to the completed scope record as `operatorUses`; otherwise the facts carry `looseOperatorUses`. Order: the handler's own first, then the children's in descent order.

The channel is `operatorUses` on a handler result (task 21.2.4), `looseOperatorUses` on walk facts (task 21.2.2) and `operatorUses` on a scope record (task 21.2.3). Follow how `fallthroughArms` / `looseFallthroughArms` travel in the same file, and how task 20.3.x carries `unreadBindings` beside them. Write the key into an output object only when its list is not empty, so no existing expectation moves.
