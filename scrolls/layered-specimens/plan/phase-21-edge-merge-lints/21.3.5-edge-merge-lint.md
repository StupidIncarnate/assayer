## Contract

```ts
export const edgeMergeLintTransformer = ({
  functions,
  uses,
}: {
  functions: readonly FunctionAnalysis[];
  uses: readonly OperatorUse[];
}): LintEntry[]
```

## What to implement

Call `truthinessRulesLayerTransformer({ functions, uses })` (task 21.2.2) and `operatorRulesLayerTransformer({ uses, entries })` (task 21.2.3), where `entries` is one `{ name, startLine, endLine }` per function: `name` from `entry.name`, `startLine` from `entry.line`, and `endLine` from the last of the function's branches and exits (the worker reads which fields the analysis holds). Return both layers' lints in one list, sorted by `startLine`, then `rule`, then `name`, with exact duplicates removed. The parent holds no rule of its own.

## Tests

- `VALID: {a truthiness lint and an operator lint} => both, sorted by line}`.
- `VALID: {two lints on one line} => ordered by rule name`.
- `EDGE: {the same lint produced twice} => once`.
- `EMPTY: {a file where no rule fires} => []`.
