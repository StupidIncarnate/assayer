## What to implement

Add to `scopeRecordContract` the field `operatorUses: z.array(operatorUseContract).optional()`, beside `fallthroughArms`, with a comment: the `==`, `||`, `+`, `typeof` and `isNaN` uses of this scope, claimed from the loose channel on the way up. `scope-record.stub.ts` needs no change. The field is optional and a producer writes it only when it has something to record, so no existing expectation that compares a whole object moves.
