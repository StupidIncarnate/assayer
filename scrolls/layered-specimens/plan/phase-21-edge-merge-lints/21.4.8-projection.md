## What to implement

`analysisProjectionTransformer` projects the walk into `functions`. This task makes it also return the edge-merge lints of the file as `edgeMergeLints`:

1. Collect `scope.operatorUses` (tasks 21.3.3 and 21.3.4) of every walked scope, including scopes the projection does not keep as entries: an operator in a private helper is the repo's code too.
2. Call `edgeMergeLintTransformer({ functions, uses })` (task 21.3.5) with the projected `functions` and the collected uses.
3. Return the lints on the result as `edgeMergeLints` (task 21.2.5), only when the list is not empty. A failed walk returns none, as it returns no functions.
