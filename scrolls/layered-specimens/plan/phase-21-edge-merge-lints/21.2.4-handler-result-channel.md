## What to implement

Add to the `HandlerResult` interface the optional member `operatorUses?: OperatorUse[]`, next to `fallthroughArms`, with a doc comment in the style of its neighbours: the operator uses this node made, loose and claimed by the enclosing scope. Optional, because a handler writes it only when it found one. Import the type with `import type` from `../operator-use/operator-use-contract`. (Task 20.2.3 adds `unreadBindings` to the same interface; the two additions sit side by side.)
