## What to implement

`analyzeFileBroker` calls `deriveCasesTransformer` once per entry (the call near line 99). For an entry whose scope
record holds an operator use of kind `mixed-plus` (task 21.2.3) whose operand is a parameter of a type with both a
`string` and a `number` member, pass `ruleNamed: [{ operand: <that parameter>, value: edgeValueStatics.ruleNamed.mixedPlus }]`,
one item per such parameter, in parameter order. An entry with no such use passes nothing. Read the operand's name from
the use's own fields (task 21.1.3, the operator-use contract), never from source text.
