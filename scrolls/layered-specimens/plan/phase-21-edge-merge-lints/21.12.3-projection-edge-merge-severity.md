## What to implement

Task 8.2.1 maps each lint rule to the config toggle it rides, and reads that toggle's default from
`assayerConfigContract.parse({})`. Before this phase no `edge-merge-*` rule existed, so the map held only
`unreachable-exit`, `dead-surface` and `never-read` (all `deadSurface`). Add the six rules, each to its key of
`edgeValueMerge` (the table of task 21.1.2): `edge-merge-truthiness` to `truthiness`, `edge-merge-or-default` to
`orDefault`, `edge-merge-loose-equality` to `looseEquality`, `edge-merge-typeof-object` to `typeofObject`,
`edge-merge-mixed-plus` to `mixedPlus`, `edge-merge-global-isnan` to `globalIsNaN`. The severity is that key's value
in `assayerConfigContract.parse({}).edgeValueMerge`: `warn` for each, by the config's own default.

## Tests
