## What to implement

`assayer-flow.integration.test.ts` drives `AssayerFlow` over the built CLI through `assayerCliHarness`
(`packages/cli/test/harnesses/assayer-cli.harness.ts`), as its `detail command` describe does. Add a
`describe('unit command passes the edge-value merge toggles')` with two cases, each seeding a scratch repo through the
harness with one file holding card `edge/truthiness`'s code (`if (count)` on `count: number | undefined`):

- `ERROR: {config edgeValueMerge { truthiness: 'error' }} => the run fails with the edge-merge-truthiness lint`: the
  result is the thrown report, so the exit is non-zero. Assert the lint line word for word.
- `VALID: {config without edgeValueMerge} => the run reports the lint and passes`, because the default is `warn`.

The CLI integration tests spawn the built CLI, so the operator runs
`npm run build --workspace=@assayer/shared --workspace=@assayer/core --workspace=@assayer/cli` before this row
(README "Builds, deletions, the brief and hand-written files").
