## What to implement

Every lint goes through one gate, `run-report-layer-responder.ts:54`:

```ts
const linted = deadSurface === 'error' && runs.some((run) => run.lints.length > 0);
```

`deadSurface` `'off'` and `'warn'` print the same report and do not fail the run. Only `'error'` fails it.

This task keeps those semantics, per rule:

1. `RunReportLayerResponder` takes one more **optional** parameter, `edgeValueMerge?: { truthiness: string; orDefault: string; looseEquality: string; typeofObject: string; mixedPlus: string; globalIsNaN: string }`. It is optional so the callers change in later rows (tasks 21.3.1 and 21.4.1) and task 21.6.1 makes it required. While it is absent, no edge-merge lint fails the run.
2. The `deadSurface` gate counts only the lints whose `rule` is not one of the six `edge-merge-*` rules (`dead-surface`, `unreachable-exit`, `never-read`):

   ```ts
   const linted = deadSurface === 'error' && runs.some((run) => run.lints.some((lint) => !(lint.rule in edgeMergeToggleKeys)));
   ```
3. Each edge-merge rule fails the run only when its own toggle is `'error'` and some run holds a lint with that rule. Keep the rule to key map as one `const` object inside the responder file:

   | Rule | Key |
   |---|---|
   | `edge-merge-truthiness` | `truthiness` |
   | `edge-merge-or-default` | `orDefault` |
   | `edge-merge-loose-equality` | `looseEquality` |
   | `edge-merge-typeof-object` | `typeofObject` |
   | `edge-merge-mixed-plus` | `mixedPlus` |
   | `edge-merge-global-isnan` | `globalIsNaN` |

4. `'off'` and `'warn'` print the same report and do not fail, exactly as `deadSurface` does. Nothing is dropped from the report under any value.
5. Update the PURPOSE block of the responder: name the new toggles beside `darkSpots`, `deadSurface` and `inputGaps`.

## Tests

For each of the six rules, with `RunResultStub({ lints: [LintEntryStub({ rule: <rule> })] })`:

- `ERROR: {<rule> lint, its toggle 'error'} => throws the report`.
- `VALID: {<rule> lint, its toggle 'warn'} => returns the report`.
- `VALID: {<rule> lint, its toggle 'off'} => returns the same report text as 'warn'`.
- `VALID: {<rule> lint, every other toggle 'error', deadSurface 'error'} => returns the report` (one rule's toggle never gates another's).
- `VALID: {an unreachable-exit lint, deadSurface 'error', every edgeValueMerge key 'error'} => throws`, and with `deadSurface: 'warn'` it returns.
- `VALID: {an edge-merge lint, edgeValueMerge absent, deadSurface 'error'} => returns the report`.

Write the six rules as an `it.each` over a list written out in the test file.
