## Contract

```ts
export const operatorUseContract = z.object({
  kind: z.enum(['or-default', 'loose-equality', 'typeof-object', 'mixed-plus', 'global-isnan']),
  line: z.number().int().positive().brand<'OperatorUseLine'>(),
  operator: z.enum(['==', '!=', '===', '!==']).optional(),
  left: operandContract,
  right: operandContract.optional(),
  anyOperand: z.literal(true).optional(),
}).brand<'OperatorUse'>();
```

with `operandContract = z.object({ name: z.string().min(1).brand<'OperatorUseOperandName'>(), type: typeDescriptorContract, literal: representativeValueContract.optional() }).brand<'OperatorUseOperand'>()`. `name` is the identifier or property chain of the operand, `operand` when the operand has no name, or the literal's own value for a literal operand. `line` is the start line of the operator expression. `operator` is set for `loose-equality` and `typeof-object` only. `anyOperand` is set for `global-isnan` only, when the checker types the argument as `any`. Export the `OperatorUse` type.

Write the PURPOSE block in the project's style: what the record is, who produces it (task 21.2.6 reads one node; tasks 21.4.2 to 21.4.7 call it), who reads it (tasks 21.2.7, 21.2.8, 21.3.5). The stub defaults to a `loose-equality` use of `value == 0` on line 1.
