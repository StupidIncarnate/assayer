## What to implement

Add exactly one route to `dispatch-node-layer-transformer.ts`: a node of kind `BinaryExpression` goes to `handleBinaryLayerTransformer`. It is the only place that decides which handler owns a node kind. A binary expression reached by descent is read once. Check that no expression is read twice: `read-conditional-exit` and the condition readers consume their expressions before a descent, and the site tasks 21.4.3 to 21.4.7 read the rest.
