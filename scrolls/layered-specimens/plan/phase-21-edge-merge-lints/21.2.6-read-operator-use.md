## Contract

`OperatorUse` is the contract of task 21.1.3, at `packages/core/src/contracts/operator-use/operator-use-contract.ts`:

```ts
{
  kind: 'or-default' | 'loose-equality' | 'typeof-object' | 'mixed-plus' | 'global-isnan';
  line: number;                 // the line of the operator expression
  operator?: '==' | '!=' | '===' | '!==';   // loose-equality and typeof-object only
  left: { name: string; type: TypeDescriptor };    // `name` is the identifier or property chain; `operand` when the operand has no name
  right?: { name: string; type: TypeDescriptor; literal?: RepresentativeValue };
  anyOperand?: true;            // global-isnan only: the argument's type is `any`
}
```

```ts
export const readOperatorUseLayerTransformer = ({ node }: { node: Node }): OperatorUse | undefined
```

## What to implement

Read one node and answer an `OperatorUse` or `undefined`. Never scan, never climb, never read source text. Read node kinds, resolved symbols and `getLiteralValue()` only.

- `BinaryExpression` with operator token kind `EqualsEqualsToken` or `ExclamationEqualsToken`: kind `loose-equality`, `operator` `==` or `!=`. When either side is the `null` literal (kind `NullKeyword`), answer `undefined`.
- `BinaryExpression` with operator token `EqualsEqualsEqualsToken` or `ExclamationEqualsEqualsToken` where one side is a `TypeOfExpression` and the other side's `getLiteralValue()` is `'object'`: kind `typeof-object`, `left` is the operand of the `typeof`.
- `BinaryExpression` with operator token `PlusToken`: kind `mixed-plus`.
- `BinaryExpression` with operator token `BarBarToken`: kind `or-default`; `right.literal` is the right side's `getLiteralValue()` when it is a literal.
- `CallExpression` whose callee is the identifier `isNaN` and whose symbol has no declaration in this file (the global): kind `global-isnan`; `anyOperand: true` when the checker types the first argument as `any`. When the argument is not `any`, answer `undefined`.

An operand's `name` is the identifier's name, or the property chain `a.b` of identifiers (`read-property-path`), else `operand`. A numeric or string literal operand's name is its value (`0`, `'abc'`). Types come from the checker through `read-type-fact` and `type-descriptor`. `line` is the expression's start line.

The proxy is empty: this is a pure layer.

- `EMPTY: {x == null} => undefined`, `{x != null} => undefined`.

- Formatting immunity: a reformatted copy (spacing, quote style, redundant parentheses) answers the same `OperatorUse`.
