## What to implement

Each rule reads only the type graph facts the analysis already holds. It states a fact, never a guess, and it never runs the code (P4).

**Truthiness.** For each branch of each function, walk the condition tree. A leaf fires when all of these hold:

- its `predicate.kind` is `truthy` or `falsy`;
- it names an operand (`operandParamName`, plus `operandPropertyPath` joined with `.` when present);
- the operand's type is a union that has a missing member (`undefined` or `null`) and a falsy member (`number`, `string`, `boolean`).

The falsy member is the first of `number`, `string`, `boolean` the type holds. The missing member is `undefined` when the union has it, else `null`. The arm is `else` for a `truthy` leaf and `then` for a `falsy` leaf; a leaf under an odd number of `not` nodes takes the other arm. One lint per branch and operand. `startLine` and `endLine` are the branch's `startLine`. `name` is the function's `entry.name`. Rule `edge-merge-truthiness`. Message, word for word:

`edge-value merge (truthiness): <x> <falsy> takes the <arm> arm, the same arm as <x> <missing>. Write <hint> to tell them apart.`

with `<falsy>` = `0` for `number`, `''` for `string`, `false` for `boolean`, and `<hint>` =

| Falsy member | `<hint>` |
|---|---|
| `number` | `<x> !== undefined, or <x> > 0` |
| `string` | `<x> !== undefined, or <x> !== ''` |
| `boolean` | `<x> !== undefined` |

(When the missing member is `null`, `undefined` in the hint reads `null`.) Example for card `edge/truthiness`: `edge-value merge (truthiness): count 0 takes the else arm, the same arm as count undefined. Write count !== undefined, or count > 0 to tell them apart.`

**Or-default.** For each `uses` item of kind `or-default` whose `left.type` has a falsy member (`number`, `string` or `boolean`). The missing members of the left type do not matter. `startLine` and `endLine` are `use.line`. Rule `edge-merge-or-default`. `name` is the entry whose line span holds `use.line`. Message:

`edge-value merge (or-default): <x> <falsy> is replaced by <d>. Write ?? to keep it.`

with `<d>` = the right operand's literal rendered with single quotes for a string (`'anon'`), bare for a number or boolean, and `the right-hand side` when it has no literal. Example for card `edge/or-default`: `edge-value merge (or-default): name '' is replaced by 'anon'. Write ?? to keep it.`
