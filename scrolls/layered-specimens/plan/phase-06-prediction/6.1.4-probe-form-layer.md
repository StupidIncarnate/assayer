## Contract

`probeFormLayerTransformer({ node, context }): { form: string; probes: ProbeRow[]; leaves: LeafRow[]; rewritten: ts.Node } | undefined`

- `node`: one syntax-tree node of the entry text.
- `context`: `{ file, position: 'statement' | 'condition' | 'exit' | 'value'; canReject: boolean; unread: boolean }`.
  The parent (task 6.2.2) sets `position` from where the node sits, `canReject` for a `.then`/`.catch` call from its
  receiver, and `unread` when the node sits in the initializer of a local that nothing reads.
- It returns `undefined` for a node that no form recognises. `ProbeRow` and `LeafRow` are the elements of
  `ProbeTable` (task 1.4.3).

Every rewrite keeps the code's meaning: each operand is evaluated exactly once, in the same order, and `__leaf` and
`__read` return their argument unchanged.

## The table of forms

| Form | Recognised node | Rewrite |
|---|---|---|
| `if` | `IfStatement` | `__arm(id,'then')` first in the then block. An else block gets `__arm(id,'else')`. A missing else becomes `else { __arm(id,'else'); }` |
| `ternary` | `ConditionalExpression` | each arm `(__arm(id,'then'), a)` and `(__arm(id,'else'), b)` |
| `and`, `or` | `&&`, `\|\|` NOT in a condition | `((t) => t ? (__arm(id,<A>), right) : (__arm(id,<B>), t))(__leaf(leafId, left))` for `&&` with A `evaluates-right`, B `stops-at-left`. For `\|\|` the test is `t` with the arms swapped (`stops-at-left` on a truthy `t`) |
| `nullish` | `??` NOT in a condition | `((t) => t != null ? (__arm(id,'left'), t) : (__arm(id,'right'), right))(__leaf(leafId, left))` |
| `optional-chain` | each `?.` NOT in a condition | `((r) => r == null ? (__arm(id,'absent'), undefined) : (__arm(id,'present'), r<access>))(__leaf(leafId, receiver))`. A chain of several `?.` links is one probe per link |
| `switch` | `SwitchStatement` | `__arm(id,'case:<label>')` at the first clause of each group of clauses that share statements (`case:<a>\|<b>` for a group). `__arm(id,'default')` in the default clause. `__reach(id)` first, complement `no-match`, when there is no default and the switch is not exhaustive (below the table). A label is the literal's value read from the syntax tree (`7`, `xyz`, and an enum member's value, `0` for `Level.Low`: README "The report vocabulary"), never its spelling |
| `loop` | `for`, `for…of`, `for…in`, `while` | `__reach(id)` before the loop, `__arm(id,'runs')` first in the body. Complement `skipped`. `__pass(id,'loop')` first in the body |
| `loop` (`do…while`) | `DoStatement` | `__pass(id,'loop')` first in the body. The condition becomes `((r) => (__arm(id, r ? 'repeats' : 'stops'), r))(cond)`. No complement, no `skipped` arm: the body always runs once |
| `array-callback` | `.map`, `.filter`, `.forEach` call | `__reach(id)` on the call, `__arm(id,'runs')` first in the callback. Complement `skipped` |
| `promise-callback` | `.then`, `.catch` call | the same as `array-callback`, but only when `context.canReject` is true. `.finally` has no probe (it runs on both arms). A callback on a receiver that never rejects (`Promise.resolve(...)`, a `promise-resolve` piece) gets no probe and no arm (DESIGN.md: `Promise.resolve` never rejects, so there is no skipped arm). The callback's own body is still probed |
| `try` | `TryStatement` | `__reach(id)` first in the try block, `__arm(id,'catches')` first in the catch block. Complement `finishes` |
| `default-param` | a parameter with an initializer | the initializer becomes `(__arm(id,'defaulted'), init)`. `__reach(id)` first in the body. Complement `given` |
| `destructure-default` | a binding element with an initializer | the same, complement `present` |
| `logical-assign` | `??=`, `\|\|=`, `&&=` | the right side becomes `(__arm(id,'assigned'), rhs)`. `__reach(id)` before the statement. Complement `kept` |
| `return-comparison` | a `return` or a concise body whose expression is a comparison | `((r) => (__arm(id, r ? 'return-true' : 'return-false'), r))(<comparison>)` |

**An exhaustive switch.** A switch with no default clause is exhaustive when the discriminant's type is a union whose every member is a literal (an enum, a literal union, `(typeof modes)[number]` of an `as const` list, or a discriminated union's `kind`) and each member's value is one of the labels' values. An exhaustive switch has no `no-match` arm: no value takes it, so it is never a route, never in `unreachedArms`, and never an unreachable-exit lint. This is the rule core task 19.3.1 applies; cards `type/enum`, `type/discriminated-union` and `retype/as-const` list no `no-match` arm. The probe form of an exhaustive switch writes no `__reach` and no `no-match` complement, and its probe's `arms` lists the label groups only.

Every function entry (an arrow, a function expression, a function declaration, a method) calls
`__pass(id,'call')` first in its body. An expression-bodied arrow becomes `(...) => (__pass(id,'call'), expr)`.

## Leaves, in every position

A leaf records a value so that two runs with the same arms but a different cause are different routes (README cause
rule step 1). The layer wraps these in `__leaf(leafId, <expr>)`:

1. **Outcome leaves.** Every comparison (`===`, `!==`, `==`, `!=`, `>`, `>=`, `<`, `<=`), every `typeof`/`instanceof`
   comparison and every call of a same-file type guard, wherever it appears: in a condition, as an operand of
   `&&`/`||`, in a `return` or in a value position. Cause `outcome`. The wrapped value is the boolean result.
   `x in obj` is an outcome leaf with cause `presence` and `path` `obj.x`.
2. **Operand leaves.** The non-literal operand of a comparison, of `+`, of `==`, a switch subject, a `.length`
   receiver, and the left operand of `&&`, `||` and `??`. Cause `truthiness` for a bare read tested as true or
   false (`if (x)`, `!x`, `x ? a : b`, the left of `&&` and `||`), `nullish` for the left of `??` and for a `?.`
   receiver, `member` otherwise.
3. **`??`, `||`, `&&` and `?.` inside a condition** are connectives or leaves, never a probe. `a && b` in a condition
   adds two leaves. `a ?? b` in a condition wraps `a` as a `nullish` leaf. `x?.y` in a condition wraps `x` as a
   `nullish` leaf. The condition is the test of an `if`, a ternary, a loop or a `do…while`, a switch subject, and
   anything under a `!`.
4. **Reads of inputs.** Every read of an entry parameter or destructured parameter name, anywhere in the entry, is
   wrapped `__read('<name>', <identifier>)`, so the run knows which inputs it read. A leaf operand that is such a
   read is `__leaf(leafId, __read('<name>', x))`. A write target is not a read.
5. **Paths.** A leaf whose expression is a property read of an input records `path` (`job.priority`, `options.label`).
   A leaf over `process.env.KEY` records `path` `KEY`.

**Unread locals.** A `const` or `let` that nothing in the file reads has no probe and no leaf in its initializer,
and its initializer's reads are not recorded (`context.unread`). Its ternary is not a branch, and the parameters it
reads owe no edge routes (card `consume/never-read`; README cause rule step 5).

A recognised node whose form no piece in `uses` declares is an error, never ignored:
`the rendered specimen has a <form> on line <n> of <file>, and no piece it uses declares one. The renderer wrote code its pieces do not describe.`

The id of a probe or leaf is `<file>:<line>:<form>`, plus `:<n>` when one line holds several. A probe's `arms` is the
full arm list from `reportVocabularyStatics`. A switch's arms come from its labels.

## Tests

- `VALID:` card `type/enum`'s switch (`Level`, cases `Low` and `High`, no default) => arms `case:0`, `case:1`, no `no-match`, no `__reach`.
- `VALID:` card `switch/no-default` (`'a' | 'b' | 'c'`, cases a and b) => arms `case:a`, `case:b`, `no-match`.

One `VALID:` per form, each asserting the probe row and the rewritten text with `toBe`.

- `VALID:` card `and/as-condition` gives one `if` probe and leaves for `ready` (truthiness) and `count > 2`
  (outcome), and no `and` probe.
- `VALID:` card `and/as-exit` gives one `and` probe, a `ready` leaf and an outcome leaf for `count > 2`.
- `VALID:` card `and/as-value` is the same inside `console.log(...)`.
- `VALID:` card `nullish/in/if-condition/gt` (`count > (limit ?? 10)`) gives a `nullish` leaf over `limit` and no
  `nullish` probe.
- `VALID:` `x?.y` in an `if` condition gives a `nullish` leaf and no `optional-chain` probe.
- `VALID:` card `ternary/sequence` gives two ternary probes.
- `VALID:` card `callback/then` (`Promise.resolve(count).then(...)`) gives the callback's ternary probe and no
  `promise-callback` probe. A `.then` on `load(count)` where `load` is an async function that throws gives one.
- `VALID:` a `do…while` gives `repeats` and `stops` and no complement.
- `VALID:` card `consume/never-read` gives no probe for the unread `label` initializer.
- `VALID:` card `eq/alone` gives a `return-comparison` probe.
- `ERROR:` an unrecognised form, message word for word.
