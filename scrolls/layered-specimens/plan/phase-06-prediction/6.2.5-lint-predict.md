## Contract

```ts
lintPredictTransformer({ plan, files, traceResults }): {
  rule: string;
  startLine: number;
  trace: { file: string; line: number }[];
}[]
```

Sorted by `startLine`, then rule. `traceResults` is the output of task 6.1.6 for this specimen. `files` is the
unprobed specimen files. The transformer builds one TypeScript program over `files` and gives its checker to the
edge-merge layer.

## Rules

- **`unreachable-exit`.** Only from a task 6.1.6 result with `channel: 'lint'`. The lint sits at the result's
  `consumption.line`, with its `trace`. The transformer never predicts an unreachable exit from "no input reached the
  arm" (DESIGN.md decision "When is an arm unreachable?"). A result with `channel: 'build-error'` is not a lint: it
  is a build error (task 6.2.4). A `refused` result never reaches this transformer, because the predict broker
  refuses the specimen first (task 6.4.1).
- **`never-read`.** One lint, `trace: []`, for each declaration nothing reads, at the declaration's line:
  - a parameter of the entry that its body never references. A parameter property of a class constructor
    (`private readonly url`) is a field, not a parameter, so the rule does not apply to it.
  - a `const` or `let` that nothing references.
  - an export that is not read. An export is read when any file of the specimen imports it, or when `entry.ts` (the
    declared entry point, task 9.1.5) re-exports it. `entry.ts`'s own exports are always read. An export of a sibling
    file that nothing imports gets the lint (card `consume/dead-export`: `isHuge`).
  Read all three from the generator's own parse of `files`. A name declared and never referenced again is unread.
- **Edge-value merge.** The lints of `edgeMergeLayerTransformer` (task 6.1.5), with `trace: []`. A lint inside a
  declaration that is never read is not reported, because that code owes no test.
