## Contract

`showTextTransformer({ entries }): string` where each entry is one of:

- `{ folder, files: { relPath, content }[], report, today: string[] }` (the stub values ride in `report.stubValues`)
- `{ folder, refused: string }`

## What to implement

Print a JSON array, one object per entry in the given order, with two-space indentation and a trailing newline. A
predicted entry has the keys `folder`, `files`, `report`, `today` in that order. A refused entry has the
keys `folder` and `refused`. Keys never reorder, so the output is deterministic.

## Tests

- `VALID:` one predicted entry, the full text with `toBe`.
- `VALID:` one refused entry, the full text with `toBe`.
- `VALID:` two entries keep their order.
- `EMPTY:` no entries prints `[]` and a newline.
