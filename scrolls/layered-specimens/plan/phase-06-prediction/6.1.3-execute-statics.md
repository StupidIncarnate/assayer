## What to implement

```ts
export const executeStatics = {
  limits: { passCap: 10000, generatorStepCap: 10000, callDepthCap: 1000 },
  opaque: { randomCycle: [0, 0.5, 0.99], capSentinel: 'assayer-specimen-cap' },
} as const;
```

The header comment says:

- There is no timeout. A wall-clock timeout makes the prediction depend on machine speed, so the same specimen could
  predict differently on two machines. Every limit here is a count, so the same code always stops at the same step.
- `passCap`: the most passes one loop id may record in one run (`__pass(id, 'loop')`).
- `callDepthCap`: the most entries one function id may record in one run (`__pass(id, 'call')`). A recursive
  function reaches it, and so does a function called by a runaway loop.
- `generatorStepCap`: the most values the broker takes from a returned generator.
- `opaque.randomCycle`: the values the sandbox's `Math.random` answers in turn, so `Math.round(Math.random() * 10)`
  covers 0, 5 and 10. The broker offsets the cycle by the input's position, so successive inputs see different
  answers.
- `opaque.capSentinel`: the text the broker throws when a cap is hit. A run that throws it has the outcome `capped`,
  and the specimen is refused by name (task 6.4.1).
