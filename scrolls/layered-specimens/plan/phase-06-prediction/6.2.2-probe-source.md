## Contract

`probeSourceTransformer({ files, uses, inputNames }): ProbeTable` (task 1.4.3)

- `files`: `{ relPath, content }[]`, the unprobed text of every `.ts` file of the specimen that Assayer analyses
  (`entry.ts` and its siblings). The harness file, the test file and the JSON files are not passed.
- `uses`: the plan's piece names (the forms the specimen may contain).
- `inputNames`: the entry's parameter names and destructured names, the names `__read` records.

Lines in the result are lines of the unprobed text. Task 9.2.1 adds the generated header's line count when it
compares the prediction with the written file.

## What to implement

Walk each file once, top down, with the TypeScript factory. For each node, work out the context and call
`probeFormLayerTransformer` (task 6.1.4):

1. **Position.** `condition` for the test of an `if`, a ternary, a loop or a `do…while`, a switch subject, and any
   sub-expression under a `!`, `&&`, `||`, `??`, `?.` or parentheses inside one of those. `exit` for a `return`
   expression, a concise arrow body and a `throw` argument. `value` for any other expression (an argument, an
   initializer, a `yield` operand). `statement` for a statement.
2. **`canReject`.** For a `.then` or `.catch` call, walk to the start of the receiver chain. If the chain starts at a
   call of `Promise.resolve`, the receiver cannot reject, so `canReject` is false. For any other start (a call of an
   async function, `new Promise(...)`, a function returning a promise) it is true.
3. **`unread`.** A `const` or `let` declared in a file and referenced nowhere in that file or in a file that imports
   it is unread. Its initializer subtree gets `unread: true`. The declaration of an exported name is never unread
   (a declaration is read when something imports it, task 6.2.5). Walk the references with the TypeScript checker
   of a program over `files`.
4. **Rewrite.** Replace the node with the layer's `rewritten` node and keep walking the new node's children, so
   an `if` inside a probed arm is probed too. Do not walk into a node the layer already wrapped twice.
5. **Collect.** Gather every probe and leaf. Sort probes by `(file, line, kind)`, with `entry.ts` first and the
   siblings after in `relPath` order. Give each its id (`<file>:<line>:<form>`, plus `:<n>` for a second probe on one
   line, in left-to-right order). Print each file's rewritten tree with the TypeScript printer into `sources`.

A probe or form the layer reports as unrecognised throws the layer's error. A node the layer returns `undefined` for is
walked into and otherwise left unchanged.

Module-level code (a top-level `if`, a top-level `const` read) is walked the same way. Card `const/in/module` has an
`if` at the top level, so its probe's file is `entry.ts` and its position is `statement`.

**An exhaustive switch.** Write the switch's probe with the form task 6.1.4 gives an exhaustive switch: no `no-match`
arm. A switch with no default clause is exhaustive when the discriminant's type is a union whose every member is a literal (an enum, a literal union, `(typeof modes)[number]` of an `as const` list, or a discriminated union's `kind`) and each member's value is one of the labels' values. An exhaustive switch has no `no-match` arm: no value takes it, so it is never a route, never in `unreachedArms`, and never an unreachable-exit lint. This is the rule core task 19.3.1 applies; cards `type/enum`, `type/discriminated-union` and `retype/as-const` list no `no-match` arm.

## Tests

- `VALID:` card `retype/as-const` (`mode: (typeof modes)[number]`, cases `'a'` and `'b'`) => the switch probe's arms are `case:a` and `case:b`, with no `no-match`.

One `VALID:` per card shape, asserting the probe rows (id, kind, line, arms, listed, complement) and the leaf rows
with `toStrictEqual`, and the text of the first rewritten source with `toBe`:

- Card `and/as-condition`: one `if` probe, leaves for `ready` and `count > 2`, no `and` probe.
- Card `and/as-exit`: one `and` probe (listed), an outcome leaf.
- Card `ternary/sequence`: two ternary probes on different lines.
- Card `ternary/as-value`: one ternary probe inside `seen.push(...)`.
- Card `loop/for-of`: a `loop` probe with complement `skipped`, an `if` probe, a `__pass` in the body.
- Card `callback/then`: the callback's ternary probe and no `promise-callback` probe.
- Card `callback/then-catch-finally`: probes for `load`'s `if`, `.then` (runs, skipped), the ternary and `.catch`.
- Card `consume/never-read`: no probes and no leaves.
- Card `const/in/module`: a top-level `if` probe.
- Card `state/module-let`: the `if` probe, no probe for `calls += 1`.
- Card `known/env-two-files`: a ternary probe in `entry.ts` and an `if` probe in `check-limit.ts`, both in `sources`.
- Card `nullable/default-and-null`: a `default-param` probe and an `if` probe.
- `ERROR:` a `switch` in the text with `uses` that declares none, message from task 6.1.4 word for word.
- `EMPTY:` a file with no branching gives no probes and an unchanged source.
