## Contract

`fewestRunsCoverTransformer({ routes }): number` is the number of driven routes in the smallest subset in which every
arm that some driven route takes is taken at least once.

## What to implement

Write it from the rule in the root `CLAUDE.md` ("the smallest subset of every route in which each reachable arm is
taken by at least one case"). Never read or import `packages/core`'s `fewest-runs` transformer (rule P4: the two
must be able to disagree).

1. Keep only driven routes. Undriven routes never run, so they never count (card `callback/returned-closure`:
   "Fewest runs: none").
2. Routes with equal arm sets are one candidate. Edge-value routes repeat arm sets, so most routes collapse here.
3. Try subset sizes from one upward and return the first size that covers every arm. Past
   `layeredMatrixStatics.cover.exactCap` (24) distinct candidates, use greedy instead: repeatedly take the candidate
   that covers the most uncovered arms, ties broken by the sorted arm list. The result is deterministic either way.
4. A branchless entry has one route with no arms. It returns 1. No driven routes returns 0.

## Tests

Use the cards as fixtures, each a `VALID:` with routes written by hand from the card:

- `and/as-condition`: 6 routes (three arm sets of one `if`), result 2.
- `shape/if-if/sequence/two-args`: 7 routes over four arm combinations, result 2.
- `shape/if-if-if/nested/three-args`: 8 routes, result 4.
- `loop/for-of`: 7 routes (`[]` takes skipped, `[2, 3]` takes runs, else and then), result 2.
- `edge/mixed-plus`: 9 routes with no arms, result 1.
- `callback/returned-closure`: 2 undriven routes, result 0.
- `EMPTY:` no routes, result 0.
- `EDGE:` 25 routes that each take one arm no other route takes, result 25 (greedy past the cap).
- `EDGE:` the same routes in two orders give the same result.
