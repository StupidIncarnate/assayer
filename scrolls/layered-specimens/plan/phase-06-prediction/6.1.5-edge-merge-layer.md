## Contract

`edgeMergeLayerTransformer({ sourceFile, checker }): { rule: string; startLine: number }[]`

`sourceFile` is the generator's own parse of one specimen file, and `checker` is the TypeScript checker of a program
that holds the specimen's files (task 6.2.5 builds it). The layer reads declared types from the checker. It never
reads Assayer, and it never runs the code (rule P4). The result is sorted by line, then rule.

## Rules

Each rule fires only when its condition holds on the declared types, as DESIGN.md's lint table says. The line is the
line of the expression's first token.

| Rule | Fires when |
|---|---|
| `edge-merge-truthiness` | an `if` condition, a ternary condition, a `!x` or a loop condition tests a bare value `x` whose declared type holds both a missing member (`undefined` or `null`) and a falsy non-missing member (`number`, `string` or `boolean`) |
| `edge-merge-or-default` | `x \|\| d` where `x`'s declared type holds a `number`, `string` or `boolean` member (a falsy value that is not missing) |
| `edge-merge-loose-equality` | `a == b` or `a != b`, except when either side is the literal `null` (`x == null` is exempt: merging `null` and `undefined` is its purpose) |
| `edge-merge-typeof-object` | `typeof x === 'object'` (or `==`) where `x`'s declared type holds `null` |
| `edge-merge-mixed-plus` | `a + b` where one operand's declared type holds both `string` and `number` members |
| `edge-merge-global-isnan` | a call of the global `isNaN` whose argument's declared type is `any`. `Number.isNaN` never fires |

"Always truthy" is not a rule here. A bare read of a value that cannot be falsy is an unreachable arm, and task 6.1.6
reports it as `unreachable-exit` when a known value proves it.

## Tests

One `VALID:` per rule, parsing the card's code with the TypeScript factory:

- `edge/truthiness` (`count: number | undefined`) fires `edge-merge-truthiness` on the `if` line.
- `edge/or-default` fires `edge-merge-or-default`.
- `edge/loose-equality` fires `edge-merge-loose-equality`.
- `edge/typeof-object` fires `edge-merge-typeof-object`.
- `edge/mixed-plus` fires `edge-merge-mixed-plus`.
- `isNaN(value)` with `value: any` fires `edge-merge-global-isnan`.
- `optional-param/alone` (`label?: string`, `if (label)`) fires `edge-merge-truthiness`.

Guards:

- `EMPTY:` `if (flag)` with `flag: boolean` fires nothing (no missing member).
- `EMPTY:` `x == null` fires nothing.
- `EMPTY:` `isNaN(value)` with `value: number` fires nothing (TypeScript accepts it, and it is not `any`).
- `EMPTY:` `Number.isNaN(value)` fires nothing.
- `EMPTY:` `typeof x === 'object'` with `x: { size: number }` fires nothing.
- `EMPTY:` `a + b` with `number` operands fires nothing.
- `EDGE:` two rules on one line come back sorted by rule.
