## What to implement

Build with the TypeScript node factory and printer, as the old test-source transformer does. The file is:

```ts
import { join } from 'path';

import { specimenObserveBroker } from '@assayer/specimen-generator/observe';

describe('src/and/as-condition', () => {
  it('VALID: {and in condition} => if on line 2 with 3 routes, 2 fewest runs', async () => {
    const observation = await specimenObserveBroker({
      smokeRoot: join(__dirname, '..', '..', '..', '..', '..'),
      folder: 'src/and/as-condition',
    });

    expect(observation).toStrictEqual({ ...the predicted report... });
  });
});
```

- The number of `'..'` segments is the folder's segment count plus 2 (the folders `syntax-repository` and `packages`, then `smoke-repo`). `src/and/as-condition` has 3 segments, so 5.
- The report object comes from `reportLiteralLayerTransformer`.
- When `today` is not empty, write `(process.env.ASSAYER_SPECIMEN_STRICT === '1' ? it : it.failing)(` instead of `it(`, and put one comment line above it naming each today id. Jest reports an `it.failing` test as passed while its assertion fails, and as failed once the assertion passes. That is how a known gap never turns the generated suite red, and how a core fix announces itself (README).
- An `it.failing` test also passes when the observation throws before the assertion runs, so it hides a crash in Assayer or in the observe broker. The strict switch exists for that: with `ASSAYER_SPECIMEN_STRICT=1`, every specimen runs as a plain `it`, so the operator sees each known-gap specimen's real diff or its real error. Every close task runs its folders once that way (README "How the operator tells an expected failure from a regression"). The switch is a global environment variable, read the same way by every generated test; it is not a per-test knob.
- The title is `VALID: {<focus> <axis value>} => <kinds and lines of listed branches>, <n> routes, <n> fewest runs`, plus `, <rules>` when lints are predicted. The title text is built from the report and the plan's focus and axis value, which the caller passes as the `title` string; this transformer prints it.

## Tests

- `VALID:` a plain report gives `it(`, full text with `toBe`.
- `VALID:` a report with today ids gives `(process.env.ASSAYER_SPECIMEN_STRICT === '1' ? it : it.failing)(` and the comment lines.
- `VALID:` a folder with 4 segments gives 6 `'..'` segments.
- `EMPTY:` a report with every channel empty.
