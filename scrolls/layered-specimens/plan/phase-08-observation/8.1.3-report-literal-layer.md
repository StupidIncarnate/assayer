## Read first

The specimen report contract (task 1.4.1). Its key order is the order this layer writes.

## Contract

`reportLiteralLayerTransformer({ report }): ts.ObjectLiteralExpression`, built with the TypeScript node factory from `#gateway/npm/typescript`. Task 8.2.2 prints it inside the test file.

## What to implement

Write the report as an object literal with every key in the contract's order: `branches`, `routes`, `fewestRuns`, `caseFailures`, `lints`, `undriven`, `darkSpots`, `gaps`, `buildErrors`. An empty list is `[]`. A number is a numeric literal, a string is a string literal, a boolean is `true` or `false`. A lint is `{ rule, startLine, trace }` with `trace` a list of `{ file, line }`. A build error is `{ file, line, reason, trace }`. A gap is `{ name }`. Write nothing the contract does not hold.

## Tests

Print each result through the TypeScript printer and compare the text with `toBe`.

- `VALID:` a report with one `if` branch and two routes.
- `VALID:` a report with a lint that has a two-step trace.
- `VALID:` a report with a gap and a build error.
- `EMPTY:` a report with every channel empty.
