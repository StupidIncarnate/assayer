## What to implement

Rewrite three passages of `packages/core/CLAUDE.md` so they state what is true after rows #1 to #5. Write plainly, in the present tense, with no word about earlier behavior.

1. Section 4, "Drive a branch whose operand is read from the environment". The list of steps Assayer can run backwards gains "a template string with one substitution". The sentence "A step with no inverse, such as `parseInt(x, 10)` or a template string, ends the chain" becomes "A step with no inverse, such as `parseInt(x, 10)` or a template string with two or more substitutions, ends the chain". Add one sentence: a template string with one substitution is the step `template`; `env-encode` strips its literal head and tail, and a wanted value without them has no inverse.
2. Section 5.10, the second bullet after "Two consequences of the hermetic walk follow". Its list of what driving reaches and its closing sentence on a step with no inverse change in the same way as in item 1.
3. Section 9, the paragraph "Environment-variable reads are the object twin of the above". Replace "This runs regardless of whether the read is drivable: a branch inside a function is admitted as undriven, because only an entry that runs when its module loads is driven by the environment (`envDrivable` in `cause-arrange`), yet its literal is still recorded as a real stub demand." with: "Every environment read is driven, wherever it sits: a case sets the variable before it runs the entry, so a read inside a function body is driven like one at module load. Its literal is recorded as a stub demand either way."

Then search the file for the word `envDrivable` and for "undriven" next to "environment". No passage may still describe the removed flag. Use `discover` with `grep: "envDrivable"` and `grep: "template string"`.
