## What to implement

`cause-arrange-transformer.ts` takes `envDrivable: boolean` (parameter at lines 129 and 136) and reads it at line 237. It decides whether an environment-read operand may be steered: only an entry that runs when its module loads is. A test can set a variable before it calls a function, so every entry is env-drivable.

Make the parameter optional (`envDrivable?: boolean`) and read it as `envDrivable !== false`. An absent value means true. Nothing else changes. Callers that still pass `false` or `true` keep working until rows #2 to #5 remove the parameter. Rewrite the PURPOSE block lines that describe `envDrivable`, in the present tense: an absent flag means every entry is env-drivable.

Readers and callers of `cause-arrange` (unchanged by this task): `derive-cases-transformer.ts`.
