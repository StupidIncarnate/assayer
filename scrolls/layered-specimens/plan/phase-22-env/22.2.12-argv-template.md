## What to implement

`argvReadValueTransformer` runs a command-line read's steps forward to learn the value the operand holds when a case runs. No case can set argv. Its `switch` has no `template` case, and the `default` arm treats an unknown kind as `map`. Add:

```ts
case 'template':
  return skipping ? { known, skipping } : { known: [`${step.head}${String(value)}${step.tail}`], skipping };
```

Update the PURPOSE block.
