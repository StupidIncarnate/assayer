## What to implement

`readLiteralValueLayerTransformer` reads a string, number, boolean or `null` literal through `getLiteralValue()`. It
reads no part of a template: a `TemplateHead`, a `TemplateMiddle` or a `TemplateTail` node returns nothing today. Task
22.2.8 reads `` `size ${process.env.SIZE}` `` as one env step, and needs the head text `'size '` and the tail text `''`
as values.

Add three node kinds, read by `Node.isTemplateHead`, `Node.isTemplateMiddle` and `Node.isTemplateTail`, each returning
the node's `getLiteralText()` value: the cooked text TypeScript itself computes, never the node's source text, so an
escape such as `\n` reads as one newline character. A `NoSubstitutionTemplateLiteral` (`` `abc` ``) reads as its
string, the same as `'abc'`. Every other kind is unchanged. Update the PURPOSE block in plain words.

## Tests

- `VALID: {the head of `size ${x}`} => 'size '`
- `VALID: {the tail of `${x}!`} => '!'`
- `VALID: {a template middle} => its text`
- `VALID: {`abc` with no substitution} => 'abc', the same as 'abc'`
- `EDGE: {an escape in a head} => the cooked character, not the backslash`
