## What to implement

`handleTernaryLayerTransformer` descends into `condition` with `walkContextTransformer({ context, tail: false })`. Add
`condition: true` to that call. The two arm descents (`armDescents`) keep the context they are built from, so an arm
inherits `inCondition` from the ternary's own context. A ternary that itself sits in a condition therefore keeps its
arms in that condition, and a ternary in a value position keeps its arms in a value position.

Update the PURPOSE block with one sentence about the condition descent.

## Tests

- `VALID: {count > 2 ? 'big' : 'small'} => the condition descent has inCondition true`
- `VALID: {same ternary in a value position} => both arm descents have inCondition absent`
- `EDGE: {ternary handed a context with inCondition true} => both arm descents keep inCondition true`
