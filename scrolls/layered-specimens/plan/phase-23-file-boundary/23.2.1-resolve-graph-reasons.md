## What to implement

`compile-resolve-graph-broker.ts` builds four lists of errors. Each gets one reason. The message text of every error stays unchanged.

| List in the broker | Message | `reason` |
|---|---|---|
| `rawErrors` | `` cannot resolve import '<specifier>' `` | `cannot-resolve-specifier` |
| `dynamicErrors` | `cannot resolve dynamic import() with a computed specifier (use a static import with a literal specifier)` | `dynamic-or-computed-specifier` |
| `noTypeErrors` | `` import '<specifier>' has no usable types for '<name>' (install its type declarations) `` | `no-usable-types` |
| `globalErrors` | `` global '<name>[.<member>]' has no usable types (install its type declarations) `` | `no-usable-types` |

Update the PURPOSE block's USAGE line: errors are `{ relPath, line, column, message, reason }`. The dedup and the sort at the end compare whole error objects, so `reason` takes part in them and the order stays deterministic.


## Tests

One `VALID:` per row of the table, each asserting the whole error object, word for word, with its `reason`. The existing tests keep their message assertions and gain the `reason` key.
