## What to implement

Task 23.1.1 adds the optional `importedName` input, which makes the broker follow a barrel to the file that defines the name, and the result field `definedName`. Pass the name the caller imports (`importedName` of the call's `import` callee link) and use `definedName` wherever the code looks the callee up by name in the sibling's analysis. A call with no imported name (a namespace member) passes none and behaves as before. Update the PURPOSE block's mention of the sibling read.
