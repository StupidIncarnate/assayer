## What to implement

`known-from-afar.ts` holds exactly this code (line numbers matter to the test):

```ts
const label = (size: number): string => {
  if (size > 2) {
    return 'big';
  }
  return 'small';
};

const measure = (size: number): string => label(size);

export const fromCall = (): string => measure(5);

export const tag = (mode: 'a' | 'b'): string => {
  if (mode) {
    return 'set';
  }
  return 'empty';
};

export const modeLength = (mode: 'a' | 'b'): string => {
  if (mode.length) {
    return 'long';
  }
  return 'blank';
};
```

The test follows the specimen tests beside it (`welded-arg` is a model). Written by reading the file, with `file` = the `relPath` the test passes, it asserts three lints and nothing else unclean (`gaps`, `darkSpots`, `undriven` empty):
