## What to implement

Add one optional field to `lintEntryContract`:

```ts
trace: z.array(
  z.object({
    file: z.string().min(1).brand<'LintEntryTraceFile'>(),
    line: z.number().int().positive().brand<'LintEntryTraceLine'>(),
  }).brand<'LintEntryTraceStep'>(),
).optional(),
```

`trace` lists every step from the consumption point down to the dead arm, as `{ file, line }` pairs, in order: the consumption point, each call or import hop, and the branch whose arm is dead. `file` is the repo-relative path of the file the line is in. The field is absent for a lint that no known value caused (`dead-surface`, `never-read`, a guard contradiction, an edge-merge lint). It is optional so every existing lint object keeps its exact shape. Add a paragraph to the PURPOSE block saying so, in the present tense.

The stub gets no `trace`. A test builds one with `LintEntryStub({ trace: [...] })`.
