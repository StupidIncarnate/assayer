## What to implement

`ConstOperandReadout` holds `value` for a scalar constant and `length` for an array-literal constant. Add the optional field `known: z.object({ values: z.array(representativeValueContract).min(1), line: z.number().int().positive() })` (branded like its neighbours): every literal value the constant can hold, in source order, and the start line of the operand being read. When `known.values` has exactly one value the reader also sets `value`, as today. Extend the PURPOSE block. The stub gets no `known`.

## Tests

- `VALID: {known with one value and a line} => parses`.

- `VALID: {value only} => parses, no known key`.
- `INVALID: {known.values []} => throws`.
- `INVALID: {known.line 0} => throws`.
