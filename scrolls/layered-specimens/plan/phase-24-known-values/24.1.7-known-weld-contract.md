## What to implement

Declare the type the known-value tasks share:

```ts
export type KnownWeld = {
  values: RepresentativeValue[];
  origin: { line: number };                    // the line of the call that first passes the value in
  hops: { file?: string; line: number }[];     // each call that passes it on
};
```

`RepresentativeValue` is imported from `@assayer/shared/contracts`. It is types-only, the shape the walk and the
derivation hand each other inside one process and never persist, so it has no Zod schema, no test and no stub
(`packages/core/CLAUDE.md` section 8: a type several layer files share lives in `contracts/`). Write the meaning of
each field in the header.
