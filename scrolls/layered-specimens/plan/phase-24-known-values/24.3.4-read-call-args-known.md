## What to implement

`read-call-args-layer-transformer.ts` projects each call argument into `param-ref`, `literal`, `callback`, `fn-ref` or `opaque` (contract: task 24.1.5). Extend it:

1. A `literal` argument records `line`, the argument's start line.
2. An identifier argument bound to a same-file `const` whose initializer is a ternary of literals (or nested ternaries of literals) becomes `{ kind: 'literal-set', values, line }`, with the values in source order, de-duplicated, and `line` the identifier's start line. Use `readConstOperandLayerTransformer` (task 24.2.1) for the values, so the two readers cannot disagree. A set of exactly one value stays a `literal`.
3. Every other argument is read as today. Literals are read with `getLiteralValue()`, never from text.

## Tests

- `VALID: {measure(5)} => [{ kind: 'literal', value: 5, line: <the line> }]`.
- `VALID: {applyLimit(limit) with const limit = cond ? 5 : 10} => a literal-set [5, 10] with the identifier's line`.
- `VALID: {const limit = 5; f(limit)} => a literal with the identifier's line`.
- `EDGE: {an identifier bound to a let} => opaque, as today`.
- `EDGE: {a ternary with a non-literal arm} => opaque, as today`.
