## Contract

```ts
export const packageEntryPointsReadBroker = async ({
  filePath,
  candidateFilePaths,
}: {
  filePath: string;
  candidateFilePaths: readonly string[];
}): Promise<{ packageJsonPath: string; entryFilePaths: string[] } | undefined>
```

All paths are absolute. `filePath` is any file of the package. `candidateFilePaths` is every analyzed file path of the repo. The result lists the candidates the package's declared entry points name, sorted, with no duplicates. It returns `undefined` when no `package.json` exists at or above `filePath`.

## What to implement

1. Climb from `dirname(filePath)` upward and take the nearest `package.json`. The climb passes the repo root, exactly as the owner-tsconfig climb does, and stops at the filesystem root. It uses recursion, not a loop.
2. Parse the JSON. Core reads only `exports` and `main`. A file that fails to parse is an error whose message names the path, says the JSON is invalid, and says to fix the file: `assayer: <packageJsonPath> is not valid JSON. Fix the file, or remove it.`
3. Turn `exports` into a list of target path templates, relative to the package folder:
   - a string is one target;
   - an object whose keys all start with `.` is a map of subpaths. Each value is resolved the same way;
   - any other object is a map of conditions (`import`, `require`, `default`, `types` and so on). Every value is resolved, in key order;
   - an array resolves every member;
   - `null` resolves to nothing.
   A subpath key and a target may each hold one `*`. A target with `*` matches a candidate when the candidate path, relative to the package folder, starts with the text before the `*` and ends with the text after it. Without `*`, a target matches the one candidate whose relative path is equal.
4. `main` is one more target with no `*`. A missing `exports` and a missing `main` give an empty list.
5. A target names a file with an extension (`./src/a.ts`). A target that names a built file (`./dist/a.js`) matches nothing, so the candidate list stays the source files.

## Tests

- `VALID: {exports string} => the one matching candidate`.
- `VALID: {exports subpath map with "./*": "./src/*.ts"} => every candidate under src that ends in .ts`.
- `VALID: {exports conditions import and require} => the union of both targets`.
- `VALID: {main only} => the one matching candidate`.
- `VALID: {package.json two folders above the file} => climbs past the nearest folder`.
- `EMPTY: {no exports and no main} => []`.
- `EMPTY: {exports null} => []`.
- `EDGE: {target names ./dist/a.js} => []`.
- `EDGE: {candidate listed twice} => listed once, sorted`.
- `EMPTY: {no package.json above the file} => undefined`.
- `ERROR: {package.json holds invalid JSON} => throws the message above, word for word`.
