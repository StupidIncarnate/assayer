```json
  "version": "1.0.0",
  "private": true,
  "exports": { ".": "./dead-export.ts" }

```


`dead-export.ts` is not written here: task 20.8.1 writes it, with its test and its registry line, in the next row.
Until then the folder's `package.json` names an entry file that does not exist yet. That is harmless: no test reads
this folder until task 20.8.1, and the catalogue check reads only the registry and the specimen files.

Add the registry line for `sad-path/dead-surface/dead-export/helpers.ts`, written by reading the file, in the shape of
the neighbours (`specimen-registry.ts:373-374`): `access:named` and the `param:` trait `syntax-traits.ts` gives a
`number` parameter. Never derive a trait from the analyzer's output. A file with a registry line and no colocated test
is allowed: the catalogue check walks the registry against the files, and `test:syntax` runs only test files.
