## What to implement

Add to the `HandlerResult` interface the optional member `unreadBindings?: UnreadBinding[]`, next to `fallthroughArms`, with a doc comment in the style of its neighbours: the parameters and locals this node declared that nothing reads, loose and claimed by the enclosing scope. It is optional because a handler writes it only when it found one. Import the type with `import type` from `../unread-binding/unread-binding-contract`.
