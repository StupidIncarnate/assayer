## What to implement

Add to `scopeRecordContract` the field `unreadBindings: z.array(unreadBindingContract).optional()`, beside `fallthroughArms`, with a comment: the parameters and locals of this scope that nothing reads, claimed from the loose channel on the way up. The field is optional and a producer writes it only when it has something to record, so no existing expectation that compares a whole object moves. `scope-record.stub.ts` needs no change.

## Tests

- `VALID: {no unreadBindings} => parses, no such key`.
- The existing cases stay.
