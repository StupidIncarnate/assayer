## What to implement

`runUnitBroker` builds the run's lints from `caseSet.lints`, which comes from the `analysis` the overlays produce (`run-unit-broker.ts:117`), and copies them into the result at line 149 (`lints: caseSet.lints,`) and into the shim artifact. Export lints need the resolved index and the package's entry points, which only the run has. So the broker adds them to `analysis.lints` before `caseSetProjectionTransformer` runs, and both result paths carry them.

1. Read the resolved index the compile wrote. `runUnitBroker` takes `cacheDir` but no namespace, and core has a write
   broker for the index (`brokers/resolved-index/write/resolved-index-write-broker.ts`, which writes
   `<configDir>/.assayer/cache/resolved/<namespace>.json`) and no read broker. So, in `run-unit-broker.ts`: list
   `<cacheDir>/resolved/` with `readdir` from `#gateway/node/fs__promises`, sorted by name; read each `*.json` with
   `readFile` and parse it with `resolvedIndexContract` (from `@assayer/shared/contracts`); take the first, in name
   order, whose edges name `relPath` as a `from` path or a local target. A run with no such file (no prior compile, or
   a file the index does not hold) gets no export lints. The generator's observation (task 8.3.1) compiles a
   per-specimen mirror and runs every file of it with `cacheDir` the mirror's `.assayer/cache`, so this read finds the
   mirror compile's index, and a sibling file's export lints arrive on that sibling's own run. The proxy stages the folder listing and the file reads.
2. Build `exports` for this file from `analysis.functions`: every entry whose `entry.access.kind` is `named` (name `entry.access.exportedName ?? entry.name`) or `default` (name `default`), each with `line: entry.line`.
3. Call `packageEntryPointsReadBroker({ filePath: absPath, candidateFilePaths })` (task 20.1.2), with every analyzed file of the repo as a candidate (the resolved index's `from` paths and local targets, joined to `repoRoot`). Convert its `entryFilePaths` back to repo-relative paths.
4. Call `exportReachTransformer` (task 20.2.6), then `neverReadLintTransformer({ unread: [], unreadExports })` (task 20.2.5).
5. Append the result to `analysis.lints`: `{ ...analysis, lints: [...analysis.lints, ...exportLints] }`. Do this after `harnessRealizeBroker` and before `caseSetProjectionTransformer`.

A file whose package has no `package.json` has no entry points, so every export that no file imports is unread. A file that is itself an entry point has none.

The proxy gains a staging method for the package-entry-points broker and one for the resolved index, following the pattern of the proxies already composed there.
