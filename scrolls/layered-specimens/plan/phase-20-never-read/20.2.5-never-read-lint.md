## Contract

```ts
export const neverReadLintTransformer = ({
  unread,
  unreadExports,
}: {
  unread: readonly UnreadBinding[];
  unreadExports: readonly { name: string; line: number }[];
}): LintEntry[]
```

`UnreadBinding` comes from task 20.1.3. `unreadExports` comes from task 20.2.6. The result is sorted by `startLine`, then `name`, and has no duplicates.

## What to implement

Return one `LintEntry` per item, built with `lintEntryContract.parse`, rule `never-read`.

- For an unread binding: `name` is the binding's name, `startLine` and `endLine` are its lines, and the message is exactly:
  `` `<name>` is declared on line <startLine> but never read. Delete it, or use it. ``
- For an unread export: `name` is the export's name, `startLine` and `endLine` are its line, and the message is exactly:
  `` `<name>` is exported on line <line>, but nothing imports it and no declared entry point of its package reaches it. Delete it, or import it where it is used. ``

The two messages are product text. Tests assert them word for word. An unread parameter and an unread local read the same.

## Tests

- `VALID: {one unread parameter} => the lint with the first message`.
- `VALID: {one unread local spanning lines 2 to 4} => startLine 2, endLine 4`.
- `VALID: {one unread export} => the lint with the second message`.
- `VALID: {bindings and exports together} => sorted by startLine, then name`.
- `EDGE: {the same name twice on the same line} => one lint`.
- `EMPTY: {nothing unread} => []`.
