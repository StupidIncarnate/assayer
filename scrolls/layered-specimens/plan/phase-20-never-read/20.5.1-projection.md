# 20.5.1 Merge the lints and drop branches that only feed an unread value

- **Phase:** 20, the never-read lint (core). **Row:** #5, in parallel with 20.5.2 and 20.5.3. No task of the row depends on another task of the row.
- **Depends on:** 20.2.4, 20.2.5, 20.4.1, 20.4.2.
- **Model:** default (the worker's default model; this task is fully specified).
- **Covers:** DESIGN.md decision "Declared but never read" ("a branch that only feeds it is not tested"); card `consume/never-read` ("Expected branches: none"); root `CLAUDE.md` "An obligation attaches only where a value is consumed".

## What to implement

1. For each scope the projection keeps, read `scope.unreadBindings` (tasks 20.2.2 and 20.3.2). Drop from that scope, before the projection builds the entry, every branch, exit and fall-through arm whose `startLine` lies inside the line span of an unread `local` binding of the same scope. A value nobody reads owes no test, so a branch that only feeds it owes none. An unread `parameter` drops nothing, because no branch sits inside a parameter's line.
2. Collect the never-read lints of all kept scopes with `neverReadLintTransformer({ unread, unreadExports: [] })` (task 20.2.5) and return them on the projection result as `neverReadLints` (task 20.2.4), only when the list is not empty. Export lints are not built here; task 20.5.3 builds them at run time, where the resolved index is available.
3. Keep every other behavior of the projection unchanged.


## Tests

- `VALID: {card consume/never-read} => no branches for the entry, one never-read lint for label`.
- `VALID: {an unread parameter} => the lint, no branch dropped`.
- `VALID: {an unread local holding a ternary, and a second read ternary} => only the unread one's branch is dropped`.
- `EDGE: {an unread local inside a nested function} => its branches are dropped from that function's scope only`.
- `EMPTY: {nothing unread} => the projection is unchanged and neverReadLints is []`.
