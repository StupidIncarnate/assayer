## What to implement

`settleHandlerLayerTransformer` turns one handler's answer into walk facts and completes the scope the handler opened. Merge `handled.unreadBindings ?? []` and each child's `looseUnreadBindings ?? []` into one list. When the handler opens a scope, the completed scope record takes the list as `unreadBindings` and the facts it returns carry none for it. When it opens no scope, the facts carry the list as `looseUnreadBindings`. Order: the handler's own first, then the children's in descent order.

The channel is `unreadBindings` on a handler result (task 20.2.3), `looseUnreadBindings` on walk facts (task 20.2.1) and `unreadBindings` on a scope record (task 20.2.2). Follow how `fallthroughArms` / `looseFallthroughArms` travel in the same file. Write the key into an output object only when its list is not empty, so no existing expectation moves.

## Tests

- `VALID: {a handler that opens a scope and reports one unread parameter} => the scope record holds it, the loose list is absent`.
- `VALID: {a handler that opens no scope, reports one} => looseUnreadBindings holds it`.
- `VALID: {a child reports one, the scope-opening parent reports one} => the scope holds both, parent first`.
- `EMPTY: {nothing reported} => no unread key anywhere`.
