## Contract

```ts
export const exportReachTransformer = ({
  relPath,
  exports,
  edges,
  entryRelPaths,
}: {
  relPath: string;
  exports: readonly { name: string; line: number }[];
  edges: readonly ResolvedEdge[];
  entryRelPaths: readonly string[];
}): { name: string; line: number }[]
```

It returns the exports of the file `relPath` that nothing reaches, in the order of `exports`. `relPath` and every `entryRelPaths` item are repo-relative paths, the same form `ResolvedEdge.target.relPath` uses.

## What to implement

An export is read when any one of these holds:

1. `relPath` is in `entryRelPaths`. Every export of an entry point file is read.
2. An edge whose `target.kind` is `local` and whose `target.relPath` is `relPath` names it: `edge.importedName === name`. This covers an import and a re-export alike, so a re-export further along a chain reads the export it re-exports.
3. An edge into `relPath` has no `importedName` (a namespace import, `import * as helpers from './helpers'`). A namespace import reads every export of the file.
4. The export is `default` and an edge into `relPath` has `importedName === 'default'`.

Anything else is unread. The function is pure: it reads no file and no clock. It never reads source text.
