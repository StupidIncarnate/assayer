## Contract

```ts
export const unreadBindingContract = z.object({
  name: z.string().min(1).brand<'UnreadBindingName'>(),
  kind: z.enum(['parameter', 'local']),
  startLine: z.number().int().positive().brand<'UnreadBindingStartLine'>(),
  endLine: z.number().int().positive().brand<'UnreadBindingEndLine'>(),
}).brand<'UnreadBinding'>();
export type UnreadBinding = z.infer<typeof unreadBindingContract>;
```

`startLine` and `endLine` span the whole declaration: a parameter's own line, or a local's whole statement with its initializer. Task 20.5.1 drops every branch that sits inside a local's span, so a value nobody reads owes no test.

Write the PURPOSE block in the project's style: what the record is, who produces it (tasks 20.4.1 and 20.4.2), who reads it (tasks 20.2.5 and 20.5.1). The stub defaults to `{ name: 'label', kind: 'local', startLine: 2, endLine: 2 }`.
