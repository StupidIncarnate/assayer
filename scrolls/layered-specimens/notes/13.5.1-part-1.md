## Block Reason
When attempting to create `manual-smoke-repo/packages/syntax-repository/src/happy-path/function/default-param/default-param.ts` and `default-param.test.ts`, the Antigravity PreToolUse hook (`pokayoke-agy-pre-tool`) denied the tool calls:

```
  ❌ Line 1:1 - Implementation file must have a metadata comment with PURPOSE and USAGE fields.
  ❌ Line 1:1 - Unknown folder "happy-path/". Must use one of: statics, contracts, guards, transformers...
  ❌ Line 1:23 - Function parameters must use object destructuring pattern: ({ param }: { param: Type })
  ❌ Line 3:71 - No magic number: 2.
```

And for `default-param.test.ts`:
```
  ❌ Line 15:21 - Use stub function instead of inline object/array literal.
  ❌ Line 29:22 - Implementation analyzeFileBroker called without creating analyzeFileBrokerProxy first.
```

## Root Cause
`manual-smoke-repo/**` is fixture code meant to be ignored by ESLint (per root `eslint.config.js` line 23: `ignores: ['manual-smoke-repo/**']`).
However, in Antigravity, `workspacePaths[0]` is `/home/brutus-home/projects/assayer`.
When working in a worktree, `filePath` is `/home/brutus-home/projects/assayer/worktrees/layered-specimens/manual-smoke-repo/...`.
ESLint's `isPathIgnored` resolves relative to `/home/brutus-home/projects/assayer`, where `worktrees/layered-specimens/manual-smoke-repo/**` does not match `manual-smoke-repo/**`.
Adding `'**/manual-smoke-repo/**'` to `ignores` in `eslint.config.js` (or in the hook) will allow writing the specimen files.
