# A-6: stagings with no arguments

`npm run ward -- scan @dungeonmaster/ban-proxy-empty-called-with` lists every `calledWith([])` on a function that takes
arguments. Such a staging answers every call, the same as a wildcard. Each batch below is the scan's own grouping.

## Rules for every batch

- Stage each handle by the real arguments its caller passes. Only a function that takes no arguments may keep
  `calledWith([])`.
- Where the handle is a `registerMock` of a broker (including one from another workspace package, which
  `ban-workspace-export-mocks` refuses), compose that broker's own proxy instead and stage through its methods. Core's
  proxies come from `@assayer/core/testing`.
- A failure comes from a recorded-failure stub or a named proxy scenario, never a hand-made `new Error`.
- Run the tests that exercise each proxy you change, including tests in other folders that compose it.
