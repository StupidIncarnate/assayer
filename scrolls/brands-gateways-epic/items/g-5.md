# G-5: Testing Library wrappers

Adds `#gateway/npm/testing-library__react` and `#gateway/npm/testing-library__user-event` to the npm gateway.
Both are copied from dungeonmaster's `@gateway/npm`. Neither wrapper has a proxy, because each only re-exports a
library and runs real in tests.

Names app's tests use today: `render`, `screen`, `renderHook`, `waitFor`, the types `RenderResult` and
`RenderHookResult`, and the `userEvent` default export. `export *` and the default re-export cover all of them.
