# G-6: Playwright wrapper and `#gateway/bin/npm`

Adds `#gateway/npm/playwright__test` to the npm gateway and `#gateway/bin/npm` to the bin gateway.

What app uses today from `@playwright/test`: `test`, `expect`, `_electron`, `defineConfig`, and the types
`ElectronApplication` and `Page` (the e2e harnesses, `e2e-fixtures.ts` and `playwright.config.ts`).
`export *` covers all of them. Dungeonmaster's `chromium` override is not copied, because nothing here launches
`chromium`. The wrapper is a pass-through: it runs real and has no proxy.

`app/test/e2e-global-build.ts` runs `npm run build` at the repo root. Dungeonmaster's `runBuild` always adds
`--workspace=<name>`. This `runBuild` takes `workspace` as optional. Without it the call is `npm run build`, which is
what the root build needs. With it the call is `npm run build --workspace=<name>`. `runBuild` has a real body, so its
proxy stages by exact arguments, reads calls back with `getCallsFor`, and has the named failure scenario
`setupNotFound` (npm is not installed).
