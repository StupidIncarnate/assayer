# A-4: thin-adapter callers, the hand batches

The SD-3 inliner ran on the real tree (commit `3d1af34`). Every line it could not do is in
`scripts/sd-3-inline/leftovers/leftovers-<package>.json`. This file groups those lines into batches: each batch is up to
three folders of one package, so an implementation, its proxy and its test travel together. Batches never share a file.

## Rules for every batch

- Finish each LEFT line the way its reason says. A staging with no path is restaged by its exact path. A lost
  default staging becomes an explicit stage in each test that needs it. A direct `registerMock` of an adapter becomes
  the composed gateway proxy. A test title or comment naming the adapter is renamed.
- A git caller catches `GitNotInstalledError` where it falls back silently today (`items/g-1.md`).
- Desktop's exec and detached launch use the calls in `items/g-11.md`; `stdout.isTTY` is staged with
  `stdoutProxy().setupIsTty({ value })` (G-12).
- Never mock a gateway wrapper that has a real body with `registerMock({ fn })`; compose its proxy.
- Do not delete the old adapter files; A-7 moves them out once nothing imports them.
- Other agents edit the same package at the same time. Judge typecheck by your own files only.
