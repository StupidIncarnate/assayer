# G-7: App's `__mocks__` folder and CSS mapper

Removes `packages/app/src/__mocks__/` and the CSS `moduleNameMapper` entry from app's Jest config.

Findings before editing:

- `create-package` puts only `'@dungeonmaster/testing/jsdom-polyfills'` in a jsdom package's `setupFiles`. It scaffolds
  no per-package setup file. `@gateway/browser` and `@gateway/npm` do the same.
- The published polyfills cover `ResizeObserver`, `Response`, `fetch` and friends. They do not define `matchMedia`.
- The codemirror adapter and the code-viewer widget tests already load the real `@codemirror/view`,
  `@codemirror/lang-javascript` and `@uiw/react-codemirror` under jsdom and pass (68 of 68 app files at b8378b7).
  The gateway folders for those three packages have their own tests, which G-7 runs to confirm they load.
- The only CSS import in app is `@mantine/core/styles.css` in
  `src/adapters/react-dom/mount/react-dom-mount-adapter.ts`. `src/main.tsx` is the Vite entry named by
  `index.html`. `main.test.tsx` only calls `require.resolve('./main')`, which does not execute the file, so no test
  evaluates `main.tsx`.

## Plan

1. `packages/app/src/adapters/react-dom/mount/react-dom-mount-adapter.ts`: remove the `@mantine/core/styles.css`
   import.
2. `packages/app/src/main.tsx`: add the `@mantine/core/styles.css` import as the entry's first import.

   from `setupFiles` if the app tests pass without `matchMedia`. Otherwise point it at the file's new home (item 5).
4. Move `packages/app/src/__mocks__/style-mock.cjs` to `tmp/deletions/G-7/packages/app/src/__mocks__/style-mock.cjs`.
5. Move `packages/app/src/__mocks__/jsdom-polyfills.cjs` to `tmp/deletions/G-7/packages/app/src/__mocks__/`. If tests
   need `matchMedia`, recreate it as `packages/app/test/jsdom-match-media.cjs` and list it in `setupFiles`.
6. No `.jest-mock.cjs` files unless the gateway codemirror tests fail to load their package.
